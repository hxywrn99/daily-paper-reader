## 摘要
精确的3D医学图像分割需要整合长程解剖上下文与精细边界细节。现有方法通常在不同模块或特征层级上分别建模全局与局部特征，并独立进行通道校准。这可能导致全局上下文与局部边界之间的语义不匹配、通道关系建模不足、空间-通道交互较弱以及表示冗余。我们提出CDGC-Net，一种结合协作双尺度空间注意力与分组层次通道建模的3D医学图像分割网络。在每个CDGC块内，协作双尺度自注意力（CDSA）将注意力头分配给并行的局部窗口分支与全局稀疏分支。两个分支在同一特征层级上捕获精细空间细节与长程解剖上下文。其输出被拼接为$N\times C$的空间表示，并直接传递给分组层次通道注意力（GHCA）。GHCA将通道组织为$r$组，并同时建模组内与组间依赖关系。CDSA与GHCA复用共享的键投影以维持一致的特征参考。残差特征对齐随后将精炼特征与原始表示进行整合。在Synapse、ACDC、BraTS和LA数据集上，CDGC-Net的平均Dice相似系数（DSC）分别达到86.96%、92.91%、82.56%和93.52%，分别超出次优报告值0.39、0.47、0.17和0.32个百分点。在输入尺寸为$64\times128\times128$时，CDGC-Net包含25.83M参数和28.62G FLOPs，相比UNETR++分别减少了39.87%和40.30%。这些结果表明，CDGC-Net在分割精度与计算复杂度之间实现了良好的平衡。

## Abstract
Accurate 3D medical image segmentation requires the integration of long-range anatomical context with fine boundary detail. Existing methods often model global and local features in separate modules or feature levels and perform channel recalibration independently. This may cause semantic mismatch between global context and local boundaries, insufficient channel relationship modeling, weak spatial-channel interaction, and redundant representations. We propose CDGC-Net, a 3D medical image segmentation network that combines cooperative dual-scale spatial attention with grouped hierarchical channel modeling. With-in each CDGC block, Cooperative Dual-Scale Self-Attention (CDSA) assigns attention heads to parallel local-window and global-sparse branches. The two branches capture fine spatial details and long-range anatomical context at the same feature level. Their outputs are concatenated into an $N\times C$ spatial representation and directly passed to Grouped Hierarchical Channel Attention (GHCA). GHCA organizes the channels into $r$ groups and models both within-group and cross-group dependencies. CDSA and GHCA reuse a shared key projection to maintain a consistent feature reference. Residual feature alignment subsequently integrates the refined features with the original representation. On the Synapse, ACDC, BraTS, and LA datasets, CDGC-Net achieved mean DSC values of 86.96\%, 92.91\%, 82.56\%, and 93.52\%, respectively, exceeding the next-highest reported values by 0.39, 0.47, 0.17, and 0.32 percentage points. CDGC-Net contains 25.83M parameters and 28.62G FLOPs for an input size of $64\times128\times128$, reducing these quantities by 39.87\% and 40.30\%, respectively, relative to UNETR++. These results indicate a favorable trade-off between segmentation accuracy and computational complexity.

## 1. 核心问题与整体含义（研究动机与背景）

**研究动机：**
- 3D 医学图像分割（如肿瘤评估、器官定量分析、手术导航等）要求模型同时保留全局解剖上下文与精细边界细节。
- 现有方法（如 Transformer 系列）通常存在以下问题：
  1. **全局与局部特征分离建模**：全局上下文与局部细节常在不同的模块或特征层级中提取，缺乏同层级的交互与对齐，导致**语义不匹配**。
  2. **通道关系建模不足**：常见的 SE、CBAM、ECA 等通道注意力多依赖全局统计或局部跨通道交互，未显式建模**通道子空间之间的层次关系**，对低响应但关键的细粒度区域关注不足。
  3. **空间-通道交互薄弱**：空间与通道特征多通过简单加和、拼接或卷积融合，相关性建模与特征对齐不充分。
  4. **冗余表示**：多注意力分支缺乏显式交互或约束，响应可能重叠，降低互补性。
  5. **计算开销大**：标准自注意力复杂度为 O(n²)，在 3D 体数据上内存与训练成本高。

**整体含义：** 本文提出“在同一特征层级上协同建模双尺度空间信息 + 分组结构化通道关系”的统一模块（CDGC Block），力求解决上述问题，在提升精度的同时降低计算量，实现精度与效率的更好平衡。

## 2. 方法论

### 2.1 总体架构
- 采用 UNETR++ 的 U 形编码器-解码器结构，将每个计算块替换为 **CDGC Block**。
- 输入体积先经 patch embedding 映射为嵌入特征，同时一个浅层卷积分支保留高分辨率空间信息用于最终预测。
- 编码器含 4 个层级，每个层级堆叠 3 个 CDGC Block；解码器通过上采样与跳跃连接融合编码器特征，每个解码阶段也使用 CDGC Block 精炼。
- 最终将解码器输出与浅层卷积分支的高分辨率特征融合，经 3×3×3 与 1×1×1 卷积映射为目标类别数，softmax 输出分割概率图。

### 2.2 协作双尺度自注意力（CDSA）
- 输入 X → 位置编码 + 层归一化 → 线性投影得到：查询 Qs、共享键 K、值 Vs。
- 注意力头分为两组：**局部头 Hl**（局部窗口注意力）与 **全局头 Hg**（全局稀疏注意力），Hl + Hg = Ha。
- **局部窗口分支**：将 Q/K/V 重排为窗口内 token 形式，计算带相对位置偏置 B 的窗口自注意力：
  \[
  \hat{X}_l = \text{Softmax}\left(\frac{Q_l K_l^T}{\sqrt{d_h}} + B\right) V_l
  \]
- **全局稀疏分支**：通过可学习的压缩矩阵将 K 和 V 沿 token 维度压缩（N → P，P ≪ N），再做稀疏全局注意力：
  \[
  \hat{K}_g = E_K K_g, \quad \hat{V}_g = E_V V_g
  \]
  \[
  \hat{X}_g = \text{Softmax}\left(\frac{Q_g \hat{K}_g^T}{\sqrt{d_h}}\right) \hat{V}_g
  \]
- 两分支输出沿通道拼接得到：
  \[
  \hat{X}_s = \text{Concat}(\hat{X}_l, \hat{X}_g) \in \mathbb{R}^{N \times C}
  \]

### 2.3 分组层次通道注意力（GHCA）
- 输入为 CDSA 输出的空间表示，空间引导通道查询：
  \[
  Q_c = (\bar{X} + \hat{X}_s) W_{Q_c}, \quad V_c = \bar{X} W_{V_c}
  \]
- **复用 CDSA 的共享键 K**，不再额外投影键。
- 将 Q、K、V 按通道分为 r 组（每维 d_g = C/r），先做**组内通道注意力**：
  \[
  G_i = V_c^i \, \text{Softmax}\left(\frac{(Q_c^i)^T K^i}{\sqrt{d_g}}\right)
  \]
  得到组增强特征 G = Concat(G₁,…,Gᵣ)。
- 再做**跨组注意力**：将 G 重排为 r 组，沿 token 维度做 ℓ2 归一化后，对每个空间 token 计算 r×r 的跨组注意力矩阵，非对角项传播不同组间的信息，输出通道增强特征 X̂_c。

### 2.4 残差特征对齐（RFA）
- 初始缩放向量 γ⁽⁰⁾ = 1e-6，对通道增强特征做通道级缩放并残差相加：
  \[
  X_a = \bar{X} + \gamma \odot \hat{X}_c
  \]
- 再经残差卷积精炼：
  \[
  X_{out} = X_a + \text{Conv}_{1×1×1}(\text{Conv}_{3×3×3}(X_a))
  \]

### 2.5 损失函数
- 使用 soft Dice 损失 + 交叉熵损失的组合，用于监督训练。

## 7. 优点

### 方法设计方面
- **同层级双尺度建模**：CDSA 在同一特征层内并行局部窗口注意力与全局稀疏注意力，避免跨层级融合带来的语义错位，且全局分支通过压缩 K/V 显著降低复杂度。
- **空间引导通道建模**：GHCA 以 CDSA 输出为条件生成通道查询，实现空间信息对通道校准的显式引导，交互更充分。
- **分组层次通道注意力**：同时建模组内与组间通道依赖，兼顾细粒度通道关系与全局通道结构，优于单一通道重标定策略。
- **共享键机制**：CDSA 与 GHCA 复用 K，既减少投影参数，又保证空间与通道模块在同一特征参考下工作，增强一致性、减少冗余。
- **残差特征对齐**：用初始为 1e-6 的缩放向量控制通道修正幅度，训练平稳，保留原始表示。
- **整体效率高**：以更少的参数与 FLOPs 取得更优分割性能，具有部署潜力。

### 实验设计方面
- 多个数据集覆盖了多器官、心脏、脑肿瘤、左心房等不同分割场景，泛化性证据充分。
- 与 12 种以上主流方法对比，涵盖 CNN、Transformer、混合架构，对比基准全面。
- 报告了统计显著性检验与模型复杂度对比，增强了结果可信度。
