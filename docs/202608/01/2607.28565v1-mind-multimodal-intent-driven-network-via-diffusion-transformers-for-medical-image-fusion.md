## 摘要
医学图像融合旨在整合来自不同成像模态的互补信息以支持临床诊断。现有方法通常全局应用统一的融合规则，缺乏对诊断意图和病理结构的深入理解。为解决这些局限性，我们提出了MIND，一种基于扩散Transformer（DiTs）的多模态意图驱动网络，用于医学图像融合。具体而言，我们利用BioMedGPT从源图像生成意图驱动的融合文本，以病理感知的诊断意图引导融合过程。为克服DiTs中一维序列展平导致的二维空间连续性损失，我们设计了一个多尺度潜在适配器。该模块在序列化之前显式提取源图像特征，通过严格的维度对齐将其注入网络，从而有效补充图像特征。为解决图像输出与诊断意图解耦引起的语义偏移，我们设计了一个医学语义一致性损失。该损失在保持底层物理流形重建稳定性的同时，确保融合图像与融合文本之间的深层语义锁定。在Harvard、BraTS和GFP数据集上的综合实验表明，MIND实现了优越的融合质量，显著提高了下游脑肿瘤分割精度，并支持灵活的交互式融合，为意图驱动的智能临床决策支持系统带来了重要前景。

## Abstract
Medical image fusion aims to integrate complementary information from diverse imaging modalities to support clinical diagnosis. Existing methods typically apply uniform fusion rules globally, lacking a deep understanding of diagnostic intents and pathological structures. To address these limitations, we propose MIND, a Multimodal Intent-Driven Network via Diffusion Transformers (DiTs) for medical image fusion. Specifically, we utilize BioMedGPT to generate intent-driven fusion texts from source images, guiding the fusion process with pathology-aware diagnostic intents. To combat the loss of 2D spatial continuity caused by 1D sequence flattening in DiTs, we design a Multi-scale Latent Adapter. This module explicitly extracts source image features before serialization, injecting them into the network via strict dimensional alignment to effectively supplement image features. To resolve the semantic shift caused by decoupling image outputs from diagnostic intents, we design a medical semantic consistency loss. This loss ensures deep semantic locking between fused images and fusion texts while maintaining the stability of the underlying physical manifold reconstruction. Comprehensive experiments on the Harvard, BraTS, and GFP datasets reveal that MIND delivers superior fusion quality, significantly improves downstream brain tumor segmentation accuracy, and enables flexible interactive fusion, holding significant promise for intent-driven intelligent clinical decision support systems.

## 1. 核心问题与研究动机

医学图像融合旨在整合不同模态（如MRI、CT、PET、SPECT）所提供的互补信息，以支持临床诊断。然而，现有方法存在以下关键缺陷：

- **缺乏诊断意图理解**：多数方法采用全局统一融合规则，无法根据具体病理目标和诊断需求动态调整融合策略。
- **序列化破坏二维连续性**：扩散Transformer（DiTs）将2D潜在变量展平为1D序列进行自注意力建模，破坏了医学图像所需的局部物理连续性。
- **语义偏移问题**：融合图像输出与诊断意图之间缺乏显式约束，容易在高复杂度医学特征交互中产生严重的语义漂移和临床特征丢失。
- **退化场景适应性差**：传统CNN/GAN方法在退化场景下性能下降明显，难以兼顾物理保真与复杂语义对齐。

**核心含义**：作者提出MIND框架，将医学图像融合从"刚性像素级规则"推进到"智能临床意图驱动生成"的新范式。

## 2. 方法论

### 2.1 总体框架
MIND基于OmniGen的DiT骨干网络，由Phi-3 Transformer堆叠32层构成核心融合网络。整体流程为：

```
源图像对 (I_A, I_B) → VAE编码 → 潜在表示 → Patchify/展平 → 视觉Token
BioMedGPT → 意图驱动融合文本 → Tokenizer/Embedding → 文本Token
联合输入序列 → DiT网络迭代去噪 → ODE求解 → 融合图像
```

生成过程可公式化为：
\[
I_{fused} = F_\theta(x_0 | I_A, I_B, T), \quad x_0 \sim \mathcal{N}(0, I)
\]

### 2.2 关键技术组件

#### (1) 意图驱动融合文本生成
- 利用**BioMedGPT**生成病理感知的意图驱动融合文本。
- 与"过程驱动"方法（仅描述源特征或融合过程）不同，本方法通过提示工程引导模型*预见目标融合图像的理想特征*，明确描述从解剖模态保留哪些高分辨率结构、从功能模态突出哪些代谢信号。
- 设计了结构化的提示词模板，确保文本包含诊断意图与理想融合特征描述。

#### (2) 多尺度潜在适配器（Multi-scale Latent Adapter, MLA）
- **目的**：弥补DiTs中1D序列展平导致的2D空间连续性损失。
- **结构**：在序列化之前，利用多尺度残差块在2D域显式提取解剖结构特征。
- **注入机制**：构建层级特征金字塔，通过严格维度对齐，将不同尺度的解剖先验注入不同深度的Transformer层：
  - 尺度0（高分辨率）→ 浅层（0~10层）
  - 尺度1 → 中间层（11~21层）
  - 尺度2（低分辨率）→ 深层（22~31层）
- **公式**：在自注意力和MLP模块后均以残差形式注入：
  \[
  H_{SA}^{(l)} = \text{SelfAttention}(\text{LN}(H^{(l-1)})) + H^{(l-1)} + \alpha \cdot A_{s(l)}
  \]

#### (3) 医学语义一致性损失（Medical Semantic Consistency Loss）
- **动机**：流匹配损失仅约束全局流形重建，无法保证生成细节与融合文本的细粒度对齐。
- **核心机制**：利用一阶Euler积分估计当前干净潜变量，经VAE解码后，使用**BioMedCLIP**计算融合图像与融合文本的余弦相似度。
- **时间步截断机制（Timestep-Truncation, τ = 0.5）**：仅在去噪后期（t > τ）激活语义惩罚，保护早期高噪声阶段物理骨架的稳定构建。
- **损失公式**：
  \[
  \mathcal{L}_{sem} = \mathbb{E}_t[\mathbb{I}(t > \tau) \cdot t \cdot \ell_{sem}(\hat{I}_1, T)]
  \]
- 辅助物理重建约束：融合潜伏空间L1损失 + 像素域SSIM损失，并随时间步加权。

#### (4) 总损失函数
\[
\mathcal{L}_{total} = \mathcal{L}_{FM} + \mathcal{L}_{rec} + \lambda_{sem} \mathcal{L}_{sem}
\]

### 2.3 训练策略
- 采用**连续流匹配（CFM）**作为生成动力学基础。
- 使用**LoRA**（rank=64）微调Transformer线性层，MLA全参数更新。
- 利用互补退化训练范式构建自监督训练配置。

## 6. 主要结论与发现

1. **融合质量全面领先**：MIND在EN、MI、SD指标上跨模态对全面最优。例如：
   - SPECT-MRI任务MI较TextFusion提高20.3%
   - PET-MRI任务SF较BSAFusion提高13.1%
   - CT-MRI任务AG较FILM提高5.4%

2. **性能方差显著降低**：PET-MRI的SD标准差仅为2.907，较FILM降低71.3%，确保临床应用的可靠性。

3. **下游分割精度提升**：在BraTS脑肿瘤分割中，ED和ET Dice达到最高，Mean Rank为2.000，明显优于所有对比方法。

4. **语义稳健性突出**：即使输入错误文本，MIND在核心指标（EN、AG）上仍保持高质量，优于部分方法使用正常文本的性能。这归因于流匹配与重建损失形成的视觉质量下限。

5. **组件有效性验证**：
   - MLA使PET-MRI/SPECT-MRI的EN提高46.76%/40.04%
   - 语义一致性损失使CLIP得分提升15.49%~23.88%
   - 时间截断机制在PET-MRI上带来SF提升20.39%

6. **分配策略关键性**：将多尺度特征注入与网络深度自然递进对齐（高分辨率→浅层）是最优策略，显著优于反转、均匀或单尺度方案。

## 7. 优点

### 方法设计亮点
1. **真正的意图驱动范式转变**：将融合从"描述过程"升级为"预测理想结果"，使模型具备前瞻性诊断目标理解能力。
2. **MLA巧妙解决DiTs结构性缺陷**：在序列化前显式提取2D空间特征，与Transformer深度分层对应，符合特征提取规律（浅层细节→深层语义）。
3. **损失函数设计精细**：时间步截断机制实现"先保物理骨架、后注入语义"的两阶段优化，有效缓解多目标优化冲突。
4. **理论扎实**：从Picard-Lindelöf定理出发分析ODE稳定性，验证截断机制不引入向量场不连续性。
5. **物理约束与语义引导的平衡**：在追求语义对齐的同时，通过重建损失确保临床参考价值。

### 实验设计亮点
- 跨模态对、跨数据集、跨任务的三重验证策略
- 同时考虑效率（Params/Time/FLOPs）与效果
- 鲁棒性测试设计有区分度（正确/错误/意图驱动文本对比）
- 将融合质量与下游分割任务关联，体现临床价值

## 8. 不足与局限

### 方法局限
1. **推理开销较高**：推理时间7.851s/图，在临床实时场景中仍有瓶颈。
2. **依赖大视觉语言模型**：BioMedGPT文本生成和CLIP语义对齐均依赖大规模模型，引入额外计算与存储开销。
3. **空间连续性丢失的缓解有限**：MLA仅以残差形式注入特征，对深层语义交互中的拓扑保持效果有待进一步验证。

### 实验局限
1. **场景覆盖不足**：
   - 仅涉及脑部图像（Harvard/BraTS）和细胞图像（GFP），缺少腹部、胸部等其他解剖区域验证。
   - 罕见模态（如核医学新示踪剂）泛化能力未验证。
2. **融合GT缺失问题**：多模态融合缺乏绝对真值，文中互补退化训练范式虽有效但仍是间接方案。
3. **3D体积信息未利用**：BraTS为3D数据，但通过2D切片选择降维，丢失了跨切片空间上下文。
4. **对比方法范围有限**：主要为2023-2026年方法，早期经典方法（如IFCNN等）未纳入对比。
5. **超参数敏感性较高**：α、τ、λ等超参数需要精细调节，泛化到新场景时可能需要重新调优。

### 应用限制
1. **临床落地距离**：目前仅是离线融合，与临床工作流的实时集成尚未探讨。
2. **可解释性**：意图驱动的生成路径缺乏对中间决策过程的显式解释。
3. **模型泛化到非脑部/非肿瘤病理**需要更多验证。
