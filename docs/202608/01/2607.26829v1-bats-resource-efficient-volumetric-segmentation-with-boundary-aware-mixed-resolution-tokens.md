## 摘要
许多高性能的三维分割模型维护密集的多尺度特征图，导致较高的激活内存和推理成本。我们提出了BATS（边界感知令牌选择），一种三维医学图像分割架构，将细分辨率处理集中在预测的类别边界附近。一个密集边界预测器识别需要额外分辨率的位置，而一个细优先上下文级联构建输入依赖的混合分辨率层次结构。同质区域被粗略表示，而较细的令牌保留在边界、薄结构和细小目标周围。稀疏层次结构被细化并栅格化为密集分割。BATS在每个分辨率级别独立预测边界相关性，防止错误的粗尺度决策抑制细尺度证据。父簇注意力进一步将层级祖先令牌注入局部注意力邻域，提供跨尺度上下文，而无需密集的多尺度特征图或跨尺度邻域搜索。我们使用标准化的nnU-Net Revisited协议在五个公共CT和MRI数据集上评估BATS。与所比较的方法相比，BATS在LiTS上取得了最高的Dice系数，并且在五个数据集上平均与最强密集基线MedNeXt-L的差异在0.37个Dice点以内。相对于MedNeXt-L，在KiTS、LiTS和BraTS上，它减少了超过53%的峰值分配GPU内存。在KiTS和LiTS上，推理速度上限提升30%，这些数据集保留更少的令牌，但在令牌更密集的BraTS上较慢。因此，混合分辨率处理提供了持续的内存节省，而运行时和准确性的提升取决于数据集的边界密度。

## Abstract
Many high-performing volumetric segmentation models maintain dense multi-scale feature maps, leading to high activation memory and inference cost. We present BATS (Boundary-Aware Token Selection), a 3D medical image segmentation architecture that concentrates fine-resolution processing near predicted class boundaries. A dense boundary predictor identifies where additional resolution is needed, while a fine-first context cascade constructs an input-dependent mixed-resolution hierarchy. Homogeneous regions are represented coarsely, with finer tokens retained around boundaries, thin structures, and small targets. The sparse hierarchy is refined and rasterised into a dense segmentation.   BATS predicts boundary relevance independently at every resolution level, preventing an erroneous coarse-scale decision from suppressing fine-scale evidence. Parent cluster attention further injects hierarchical ancestor tokens into local attention neighbourhoods, providing cross-scale context without dense multi-scale feature maps or cross-scale neighbour search.   We evaluate BATS on five public CT and MRI datasets using the standardised nnU-Net Revisited protocol. BATS achieves the highest LiTS Dice among the compared methods and averages within 0.37 Dice points of the strongest dense baseline, MedNeXt-L, across the five datasets. Relative to MedNeXt-L, it reduces peak allocated GPU memory by more than 53% on KiTS, LiTS, and BraTS. Inference is up to 30% faster on KiTS and LiTS, which retain fewer tokens, but slower on the more token-dense BraTS. Mixed-resolution processing therefore provides consistent memory savings, while runtime and accuracy gains depend on dataset boundary density.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：主流高性能三维医学图像分割模型（如 nnU-Net、MedNeXt、SwinUNETR、nnFormer 等）在所有空间位置上维护**密集多尺度特征图**，对每个体素分配相同的计算和分辨率。三维数据的特征位置数量随空间分辨率**立方级增长**，导致**激活内存占用高、推理成本大**，成为 3D 医学分割的主要瓶颈。
- **关键观察**：图像中不同区域的空间细节需求并不均匀——边界、小病灶、薄结构需要精细表示，而同质组织和背景可以用粗分辨率表示而不损失语义信息。现有自适应令牌方法大多使用**固定保留率或令牌预算**，只改变保留哪些令牌，不改变每个输入实际分配的计算量。
- **整体含义**：BATS 提出一种**输入依赖的混合分辨率令牌层次结构**——通过边界预测将细分辨率计算集中在真正需要它的区域，在保持分割精度的同时显著降低内存和推理成本。

## 2. 方法论

BATS（Boundary-Aware Token Selection）由以下核心组件构成：

### 2.1 总体架构

- 输入裁剪块大小为 128³，使用 **N_s = 5 级令牌尺度**，补丁大小 p_s ∈ {16, 8, 4, 2, 1}（从最粗到最细）。
- 最粗尺度（16³）的所有令牌始终保留；更细的令牌根据预测的分裂决策引入。
- 流程：**密集边界预测器** → **细优先上下文级联**（构建稀疏混合分辨率层次）→ **稀疏细化器**（父簇注意力）→ **轻量级密集分割头**（栅格化为体素级 logits）。

### 2.2 密集边界预测与令牌选择

- 使用 3D ConvNeXt 金字塔 + FPN 结构，**在四个分裂层级（16³、8³、4³、2³）并行、密集地预测分裂分数**，每个尺度一个预测头，一次前向完成。
- 相邻分裂图通过**学习的门控残差**连接，使粗尺度证据增强细尺度估计，但**不将任何细尺度输出条件化为离散的粗尺度决策**。
- **分裂阈值 τ = 0.5**：补丁的边界概率超过阈值即分裂，产生下一级细令牌。

### 2.3 细优先上下文级联（Fine-First Context Cascade）

- 分裂决策**从细到粗**执行，每个被选中的令牌都会保留其**完整祖先链**。
- 这样设计的核心优势是：**细尺度证据即使对应的粗尺度预测为负也能被保留**，避免了迭代式粗到细方法中粗尺度误判不可逆地丢弃小结构的问题。

### 2.4 令牌融合公式

每个保留令牌结合两个信号——原始图像补丁的嵌入和边界预测器 FPN 特征：

\[
f_s = g_s f^{img}_s + w_s f^{FPN}_s
\]

- g_s = σ(γ_s) 为可学习的尺度特定融合门控；
- w_s = σ(ℓ_{s−1}) 为父补丁的分裂概率（最粗尺度 w_s = 1）；
- 初始化偏向 FPN 路径，梯度可回传到边界预测器。

### 2.5 父簇注意力（Parent Cluster Attention）

- 将 AutoFocusFormer 的平衡聚类扩展到混合分辨率场景：令牌按空间顺序分组为 m = 8 的簇，每个查询令牌的局部邻域由最近的 R 个簇（R×m 个令牌）构成。
- **关键创新**：将每个令牌的祖先令牌（来自所有更粗尺度、空间对齐）直接注入其注意力键/值集合中：

\[
N_{parent}(i) = N_{local}(i) \cup A(i)
\]

- 祖先通过哈希网格直接查找（基于批次、尺度、坐标），**无需密集多尺度特征图或 token 级最近邻搜索**。
- 查询、局部邻居、祖先共享一个 softmax；使用 RoPE3D 编码位置和尺度嵌入区分分辨率级别。
- **停止梯度通过注入的祖先副本**，避免共享祖先导致的大量写竞争，但前向注意力计算不受影响。

### 2.6 训练目标与 oracle warmup

- 分割损失（Dice-CE）+ 边界预测损失（Dice-BCE）+ 两个辅助损失（权重各 0.15）。
- 辅助目标：一个在边界预测器各尺度预测补丁类别组分的 soft 交叉熵；一个在细化器各尺度令牌预测补丁类别组分的 soft 交叉熵。
- **Oracle warmup**：训练初始阶段以概率 q(t)（从 0.8 线性衰减至 0，前 25% 训练完成）使用真实标签构建的层次结构输入细化器，稳定早期训练。

## 6. 主要结论与发现

1. **精度**：BATS 在 **LiTS 上取得最高 Dice（83.39）**，比 MedNeXt-L k3 高 1.25 点；五个数据集平均仅比 MedNeXt-L k3 低 **0.37 个 Dice 点**（ACDC −0.49、BraTS −0.24、KiTS −1.23、AMOS −1.12）。
2. **内存**：在 KiTS、LiTS、BraTS 上，峰值分配 GPU 内存**减少超过 53%**（1.12–1.15 GB vs 2.45–2.49 GB），即使 BraTS 的令牌层次最密集也是如此。
3. **推理速度**：KiTS 和 LiTS 上分别比 MedNeXt-L k3 **快 30.3% 和 27.2%**；BraTS 上比 k3 **慢约 29%**（1.75 vs 1.36 秒/卷），但仍比 k5 快 24%，说明运行时收益**高度依赖数据集的边界密度**。
4. **令牌层次**：每 128³ 裁剪块保留的令牌远低于全分辨率的 2,097,152——KiTS 最稀疏（9.3k 平均），BraTS 最密集（52.3k 平均），且逐案例差异很大。
5. **构建策略**：并行边界预测 + 细优先级联的召回率显著高于迭代式方法（k=4 时 77.1% vs 71.1%），且分割精度更高（87.23 vs 84.55 HEC Dice）；随机放置降低 3.65 Dice 点，证明空间放置的作用超过令牌预算本身。
6. **跨尺度注意力**：在每一层注意力中重复注入祖先上下文（父簇注意力）优于单次单独的父级跨注意力传递（KiTS 87.23 vs 86.32）。
7. **LiTS 构成 Pareto 改进**：相比 MedNeXt-L k3 同时提高 Dice 并降低内存和推理时间。

## 7. 优点

- **方法创新性**：
  - **并行边界预测 + 细优先级联**：避免了迭代式粗到细方法的不可逆细尺度信息丢失，召回优先的设计更契合小目标分割场景；
  - **父簇注意力**：利用确定性祖先链接和哈希网格查找，在不重建密集多尺度特征图的前提下实现跨尺度上下文交互，规避了 token 级最近邻搜索的开销；
  - **输入依赖的令牌预算**：令牌数量和空间分布都随输入自适应变化，超越了固定保留率方法的灵活性上限。
- **实验规范性**：采用 nnU-Net Revisited 标准化协议，与公开基准直接对比，公平性强；详细报告了令牌分布、效率指标和失败案例。
- **实用价值**：在 LiTS 上同时获得精度提升、内存降低和加速，验证了混合分辨率处理在特定任务上的 Pareto 优势。

## 8. 不足与局限

- **效率评估覆盖有限**：峰值显存和推理时间仅在 3 个数据集上对比 1 个主要密集基线（MedNeXt-L），且仅使用单一 GPU（A100 40GB）和软件配置；稀疏算子的硬件依赖性意味着在低成本 GPU 或不同算子实现上的表现可能显著变化。
- **BraTS 上推理更慢**：令牌层次过于密集时，可变长度令牌的收集/散布开销抵消了粗区域节省的计算，说明方法的优势并非普适。
- **边界预测的精确率较低**：BATS 粗尺度精确率仅 73.8%（迭代式为 93.6%），且 LiTS 案例显示边界预测会响应非语义的强度不连续（如内部纹理边缘），保留不必要的细令牌，造成计算浪费。
- **消融实验的杠杆比例问题**：部分消融在单一数据集（KiTS）的单一折上进行，跨数据集泛化证据不足；迭代基线因使用不同的边界预测模块（注意力版而非密集 CNN），并非严格的一变量对照，结论适用于完整设计对比而非组件归因。
- **失败模式分析表明分割错误来源多元**：有些误差来自边界预测未选择足够细令牌（不可逆信息丢失），有些来自分类本身的失误，未能完全解耦。
- **应用限制**：对依赖弥漫纹理判别而非局域空间结构的目标，边界导向的混合分辨率可能优势较小；未来需在更多硬件和临床任务上验证。
