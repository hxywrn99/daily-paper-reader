## 摘要
视觉与文本表征的跨模态对齐是多模态医学图像理解的基础，但在真实临床条件下，两种模态中的不确定性仍然阻碍其应用。现有的视觉-语言分割方法依赖确定性跨模态匹配，忽略了来自模糊边界的偶然不确定性和来自有限训练数据的认知不确定性，导致在域偏移下性能脆弱。为解决此问题，我们提出 DistMedVL，一种概率视觉-语言框架，在冻结编码器上引入轻量级概率跨模态适配器（PCM-Adapter），显式建模表征不确定性。具体而言，PCM-Adapter 由两个顺序模块组成，用于渐进式概率对齐。我们首先设计马氏对齐模块（MAM），将文本标记建模为高斯分布，并通过马氏距离计算补丁-文本兼容性，产生方差条件匹配，从而降低不可靠特征维度的权重。此外，我们设计分布流模块（DFM），估计模态级置信度参数，并对文本分布进行视觉引导精化，以适应不同成像模态的分布变化。在八个医学分割基准上的大量实验表明，DistMedVL 仅用 6.3M 可训练参数即可超越最先进方法，展现出优越的数据效率、扰动鲁棒性和跨数据集泛化能力。

## Abstract
Cross-modal alignment of visual and textual representations is fundamental to multimodal medical image understanding, yet remains hindered by uncertainty in both modalities under real-world clinical conditions. Existing vision-language segmentation methods rely on deterministic cross-modal matching, which overlooks aleatoric uncertainty from ambiguous boundaries and epistemic uncertainty from limited training data, leading to fragile performance under domain shift. To address this issue, we propose DistMedVL, a probabilistic vision-language framework that introduces a lightweight Probabilistic Cross-Modal Adapter (PCM-Adapter) upon frozen encoders to explicitly model representational uncertainty. Specifically, the PCM-Adapter comprises two sequential modules for progressive probabilistic alignment. We first devise a Mahalanobis Alignment Module (MAM) that models textual tokens as Gaussian distributions and computes patch-text compatibility via Mahalanobis distance, yielding variance-conditioned matching that downweights unreliable feature dimensions. Moreover, we devise a Distribution Flow Module (DFM) that estimates modality-wise confidence parameters and performs vision-guided refinement of textual distributions, accommodating distributional variation across imaging modalities. Extensive experiments across eight medical segmentation benchmarks demonstrate that DistMedVL outperforms state-of-the-art methods with only 6.3M trainable parameters, exhibiting superior data efficiency, perturbation robustness and cross-dataset generalization.

## 1. 核心问题与整体含义（研究动机和背景）

- 医学图像分割在临床诊断、治疗规划和手术导航中至关重要，且临床场景中图像通常伴随放射学报告、诊断描述等文本信息，天然构成多模态环境。
- 现有视觉-语言模型（VLM）用于医学图像分割时，多采用确定性跨模态匹配（如余弦相似度、点积注意力），将视觉和文本特征视为固定点嵌入，忽略了以下两类不确定性：
  - **偶然不确定性（Aleatoric Uncertainty）**：由模糊边界、成像噪声、设备差异等数据固有噪声引起；
  - **认知不确定性（Epistemic Uncertainty）**：由训练数据有限、域偏移、罕见病理等模型知识不足引起。
- 这种确定性对齐在域偏移、数据稀缺、输入扰动等真实临床条件下表现脆弱，容易产生过度自信的错误预测。
- 论文的核心动机是：**将跨模态对齐从确定性点匹配提升为概率性分布对齐，显式建模表征不确定性，从而提升医学图像分割的鲁棒性与泛化性**。

## 2. 论文提出的方法论

### 2.1 总体框架
- 提出 **DistMedVL**，一个概率视觉-语言框架，基于冻结的 CLIPSeg 视觉/文本编码器（ViT-B/16 与 Transformer 文本编码器）。
- 在编码器第 {2, 4, 6, 8} 层插入轻量级 **概率跨模态适配器（PCM-Adapter）**，仅训练适配器与 CLIPSeg 解码器，总可训练参数约 **6.3M**。
- PCM-Adapter 采用瓶颈结构：先将双模态特征压缩到共享低维空间，经两个顺序模块处理后，再扩展回原维度，替代原始特征送入下一层。

### 2.2 马氏对齐模块（Mahalanobis Alignment Module, MAM）
- 将文本标记建模为高斯分布：每个 token 估计均值 μ_t 与方差 σ_t²（通过 softplus 保证正值）。
- 视觉补丁不逐像素估计方差，而是聚合为全局视觉表征，并估计图像级方差 σ_v²。
- 通过可学习参数融合文本方差与图像方差，得到双边方差 σ²，用于计算补丁-文本间的**马氏距离**：

  d²_M = (1/√D) Σ_d (Z_v,d − μ_t,d)² / σ²_d

- 距离经温度缩放 softmax 转为概率兼容矩阵 A，作为软分配权重，聚合文本特征生成语义先验，并通过门控机制融入视觉表征。
- 效果：**方差大的不可靠维度自动被降权**，实现方差条件的各向异性对齐，同时缓解偶然与认知不确定性。

### 2.3 分布流模块（Distribution Flow Module, DFM）
- 针对视觉→文本方向，不采用反向马氏匹配（因文本 token 对密集视觉补丁注意力会发散），而是进行全局语义聚合。
- 计算视觉补丁的全局均值 μ_v,g 与全局方差 σ_v²_g，通过可靠性门控 γ = sigmoid(G(σ²_v,g)) 抑制高方差（语义不一致）的视觉维度。
- 估计模态语义强度 β_v、β_t，并用可靠性门控调制 β_v。
- 通过残差分布流：β*_t = β_t + MLP_f(β_v ∥ β_t)，将视觉证据作为修正项融入文本分布。
- 最终生成视觉引导的文本特征偏移，广播到所有文本 token，实现**基于视觉证据的自适应文本分布精化**。

### 2.4 训练目标
- 总损失 = λ₁·L_seg + λ₂·L_con，其中 L_seg = ½(L_BCE + L_Dice)，L_con 为 CLIP 对比损失，λ₁=0.5，λ₂=0.1。
- 不使用任何数据增强（仅 resize），以公平评估架构本身的泛化能力。

## 3. 实验设计

### 3.1 数据集与基准
- 共 **8 个数据集、4 种成像模态**：
  - **训练与评估（5 个）**：TN3K（甲状腺超声）、BUSI（乳腺超声）、ISIC-2016（皮肤镜）、Kvasir-SEG（内镜息肉）、Covid19（胸部 X 光）。
  - **纯域外测试（3 个）**：BUID（乳腺超声）、CVC-ClinicDB（结肠镜）、PKTN（甲状腺结节超声），用于域泛化评估。
- 训练集按 **10% / 25% / 50% / 100%** 比例划分，模拟不同强度的认知不确定性。
- 文本提示来自 MedCLIPSeg 的标注，TN3K 与 PKTN 使用 Qwen2.5 生成。

### 3.2 对比方法
- **单模态方法**：UNet、DCSAU-Net、FAT-Net、Swin-Unet、TransUNet、CFFormer。
- **跨模态方法**：TGANet、LViT、CLIPSeg、LanGuideMedSeg、VLSM-Adapter、RecLMIS、CausalCLIPSeg、MedCLIPSeg（SOTA 基线）。

### 3.3 实验场景
1. **数据效率与认知不确定性分析**：在 5 个数据集上按不同训练数据比例训练，报告平均 Dice 与 NSD。
2. **域泛化**：三个源域→目标域迁移（BUSI→BUID，Kvasir-SEG→CVC-ClinicDB，TN3K→PKTN），用 PCA 与 MMD 量化域偏移程度。
3. **扰动鲁棒性（偶然不确定性）**：对图像施加高斯模糊、对文本进行方向倒置，以及联合扰动，在 TN3K 与 Kvasir-SEG 上对比 MedCLIPSeg。
4. **消融研究**：验证 MAM、DFM、顺序连接的作用。
5. **不确定性图可视化**：用 Monte Carlo Dropout（30 次前向）生成预测不确定性热图。

- DistMedVL 在**所有数据比例、所有域迁移场景、所有扰动条件**下均超越现有 SOTA 方法。
