## 摘要
免训练的开放词汇语义分割（OVSS）根据任意文本描述将图像划分为语义不同的区域，无需学习任何额外参数。然而，现有方法通常侧重于改进视觉表示，而将仅编码通用类别概念的文本嵌入视为固定的分类参考。这些通用概念与捕获目标实例特定外观的视觉表示之间产生的语义差距，常常导致不完整的掩码和非目标区域的错误预测。受感知锚定中符号-感知对应关系的启发，我们提出了用于免训练OVSS的原型引导文本校准（PTC）。在感知阶段，PTC基于初始匹配分数选择可靠的视觉证据，以构建类别特定的视觉原型。在锚定阶段，PTC利用这些原型校准相应的文本嵌入，校准强度根据视觉证据的数量自适应调整。因此，校准后的文本嵌入更准确地与实例特定的视觉表示对齐，同时保留通用类别语义和开放词汇泛化能力。此外，PTC既不需要额外训练，也不需要外部模型，可以作为现有方法的即插即用模块。在八个基准上的大量实验表明，PTC显著提升了六种代表性方法的性能，并产生更完整、更准确的分割结果。这些结果验证了PTC作为改进视觉-文本对齐的一种简单有效的方法。

## Abstract
Training-free open-vocabulary semantic segmentation (OVSS) partitions an image into semantically distinct regions based on arbitrary text descriptions, without learning any additional parameters. However, existing methods typically focus on improving visual representations while treating text embeddings that encode only generic category concepts as fixed classification references. The resulting semantic gap between these generic concepts and the visual representations that capture the specific appearances of target instances often causes incomplete masks and erroneous predictions in non-target regions. Inspired by the symbol-percept correspondence underlying perceptual anchoring, we propose Prototype-Guided Text Calibration (PTC) for training-free OVSS. In the Perceiving stage, PTC selects reliable visual evidence based on initial matching scores to construct category-specific visual prototypes. In the Anchoring stage, PTC uses these prototypes to calibrate their corresponding text embeddings, with the calibration strength adaptively adjusted based on the amount of visual evidence. Consequently, the calibrated text embeddings align more accurately with instance-specific visual representations while preserving generic category semantics and open-vocabulary generalization. Moreover, PTC requires neither additional training nor external models and can serve as a plug-and-play module for existing methods. Extensive experiments across eight benchmarks show that PTC significantly enhances the performance of six representative methods and yields more complete and accurate segmentation results. These results validate PTC as a simple and effective approach to improving visual-text alignment.

### 1. 核心问题与研究动机

- **研究背景**：开放词汇语义分割（OVSS）旨在根据任意文本描述（而非预定义的封闭类别）将图像划分为语义区域。大规模视觉-语言预训练模型（如 CLIP、ALIGN）虽具备优异的开放类别识别能力，但其天然面向图像级匹配，直接用于密集预测任务存在适配困难。
- **现有方法的不足**：免训练 OVSS 方法（如 MaskCLIP、SCLIP、ProxyCLIP 等）大多集中于改进视觉表示（如增强局部感知、空间一致性），但将类别文本嵌入当作**固定的零样本分类参考**，忽视了以下关键矛盾：
  - 文本嵌入由预训练 LLM 生成，编码的是**通用、与输入无关的类别概念**；
  - 视觉表示从输入图像提取，刻画的是**特定实例在特定姿态、视角、成像条件下的具体外观**；
  - 二者直接匹配必然存在**语义差距（semantic gap）**，导致两类典型问题：
    1. 仅激活类别高度表征性的局部区域（如只识别出狗的头），造成**掩码不完整**；
    2. 通用文本嵌入与视觉相似背景或共现类别错误匹配，造成**非目标区域的误预测**。
- **核心洞察**：借鉴认知机器人学中的**感知锚定（perceptual anchoring）**概念——将抽象符号与具体感知对象建立对应联系——论文认为类别文本嵌入不应始终作为固定参考，而应通过与输入图像中可靠的实例级视觉证据建立关联，使抽象类别概念更准确地指向目标实例。

### 2. 方法论：PTC（Prototype-Guided Text Calibration）

#### 2.1 整体框架

PTC 作为**即插即用模块**，置于 CLIP 特征提取与最终预测之间，包含两个核心阶段：

1. **感知阶段（Perceiving）**：从初始匹配结果中筛选可靠视觉证据，聚合为类别特定的视觉原型；
2. **锚定阶段（Anchoring）**：利用视觉原型校准对应文本嵌入，校准强度根据证据充分性自适应调节。

#### 2.2 关键公式与流程

- **初始匹配**：给定文本嵌入集合 T 和视觉特征 F，计算余弦相似度：S = cos(F, T)，初始预测为 S 的逐 token argmax。
- **候选集构建**：每个类别 c 的候选 token 集合 Ωc = {i | ĉᵢ = c}。

**感知阶段技术细节**：

- **基于间隔的可信度评估（Margin-based Reliability Assessment）**：定义分数间隔 Δᵢ = Sᵢ,ĉᵢ − max_{c'≠ĉᵢ} Sᵢ,c'，即最高分数与第二名分数的差值。间隔越大，说明类别分配越不模糊、token 越可靠。相比单一置信度，间隔能有效过滤"对多个类别同时高响应"的模糊 token。
- **混合证据量确定（Hybrid Evidence-Quantity Determination）**：目标证据 token 数量为 Kc = min(Nc, max(Kmin, ⌊ρNc⌋))，其中 Kmin 为最小证据数（默认关键超参数），ρ=0.1 为采样比例。小候选集用 Kmin 保底（防止原型代表性不足），大候选集按比例扩展（提供更完整的实例外观覆盖）。
- **原型构建**：选取间隔最大的 Kc 个 token，按间隔加权聚合为视觉原型：V_proto,c = Σᵢ wᵢ fᵢ，权重 wᵢ = Δᵢ / Σⱼ Δⱼ。

**锚定阶段技术细节**：

- **合格类别筛选**：证据数 n_ev_c ≥ Kmin 的类别才参与校准，不足者保持原文本嵌入不变（防止有限证据导致语义偏移）。
- **自适应校准强度**：μc = μ · αc，其中 αc = min(1, log(1+n_ev_c) / log(1+λKmin))，λ=10 为默认值。证据不足但达阈值的类别保守校准；证据充足后强度饱和，避免大目标因证据多而过度偏离原语义。
- **文本校准公式**：t_cal_c = (1−μc)·tc + μc·V_proto_c。

#### 2.3 方法特点

- 不改变现有方法的特征提取过程；
- 无需额外训练、无需外部模型；
- 可通过调整 Kmin 和 μ 适配不同数据集与基线。

### 6. 主要结论与发现

- **核心结论**：PTC 在全部 8 个基准上一致提升 6 个代表性基线，平均 mIoU 提升分别为：SCLIP +1.5、ClearCLIP +1.0、NACLIP +2.2、ResCLIP +0.8、ProxyCLIP +1.9、CorrCLIP +0.9（百分点）。其中 NACLIP 从 39.0% 提升至 41.2%，强基线 CorrCLIP 从 51.0% 提升至 51.9%。
- **机制验证**：PTC 使分割覆盖从"高度类别表征性的局部区域"扩展到完整对象，减少背景干扰和类别混淆导致的误预测，并提升小且不显著目标的识别能力。
- **泛化性验证**：PTC 在三种 VFM（SAM/DINO/DINOv2）和三种 CLIP 骨干（ViT-B/L/H）下均带来整体性能提升，说明语义差距在不同表示强度下均存在且可被 PTC 缓解。
- **设计验证**：间隔可信度优于固定置信度阈值；混合证据量策略优于固定数量和纯比例采样；证据自适应校准优于均匀校准。

### 7. 方法亮点（优点）

1. **问题视角新颖**：首次明确指出现有免训练 OVSS 方法中的"通用文本嵌入 vs 实例视觉表示"语义差距问题，并引入认知机器人学的感知锚定概念作为理论支撑；
2. **即插即用设计**：不修改现有方法的特征提取流程，无需任何训练或外部模型，可直接集成到多种基线中，实用性强；
3. **间隔可靠性度量**：相比绝对置信度，分数间隔能更直接表征类别分配模糊性，在理论上更合理，实验也验证了其稳定性；
4. **证据驱动的自适应校准**：根据证据充足性动态调节校准强度，巧妙平衡了"融入实例视觉信息"与"保持通用语义"之间的矛盾；
5. **混合证据量策略**：同时引入最小数量约束和比例采样，兼顾小候选集的代表性和大候选集的覆盖率；
6. **实验体系完整**：包含 8 基准主实验、核心设计消融、超参敏感性、跨骨干/跨 VFM 泛化验证，验证链条清晰。

---

### 8. 不足与局限

1. **对原型质量的高度依赖**：论文在结论中坦承 PTC 性能取决于视觉原型构建质量。在类别众多、背景干扰强的复杂场景中（如 COCO-Object、ADE20K），原型可靠性下降，增益明显缩小；
2. **超参数需要数据集特定调整**：Kmin 和 μ 在不同数据集上的最优值差异显著（如 VOC21 最优 Kmin=100，Cityscapes 最优 Kmin=2；COCO-Object 最优 μ=0.02，VOC21 最优 μ=0.3），实际应用中需要逐数据集调参，削弱了"即插即用"的便利性；
3. **个别场景存在性能回退**：在使用 ViT-L/14 骨干时，PTC 在 COCO-Object 上出现轻微下降（−0.4），表明在复杂场景下文本校准有时会引入反效果；
4. **部分基线增益微弱**：ClearCLIP 和 ResCLIP 的平均提升仅约 1 个百分点，部分数据集上增益趋近于零（如 ClearCLIP 在 VOC21/COCO-Object 仅 +0.1），方法对不同基线的适用性存在差异；
5. **未报告计算开销量化**：虽然免训练，但多尺度重叠裁剪（224×224 局部裁剪 + 336×336 滑窗）的推理成本未做详细分析；
6. **时间标注存在疑点**：论文标注为 2026 年 8 月发布（arXiv:2608.03991v1），实验只使用单卡 RTX 4090，未报告完整代码复现细节以外的工程性验证。
