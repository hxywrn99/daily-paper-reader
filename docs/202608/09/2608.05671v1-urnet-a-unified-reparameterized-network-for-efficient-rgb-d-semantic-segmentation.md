## 摘要
以往的RGB-D语义分割方法通常采用双编码器分别处理RGB和深度输入，并辅以专门的跨模态特征融合模块。然而，此类设计往往不能充分捕捉深度表示，从而限制了有效的跨模态交互，同时额外的编码器分支引入了冗余计算，阻碍了轻量化执行。为应对这些挑战，我们提出了URNet，一种统一的重参数化RGB-D网络，在单个编码器内同时进行多模态特征提取和跨模态融合。具体来说，我们采用重参数化策略来紧凑网络架构并促进快速推理。在每个重参数化块（RepBlock）中，引入了线性门控注意力（LGA）模块，以充分利用不同特征尺度下互补的RGB和深度线索。此外，考虑到现有RGB-D分割模型中解码器设计相对未被充分探索，我们开发了一种简洁而有效的通用解码器，称为金字塔合并解码器（PMD）。在多个RGB-D分割基准上的大量实验表明，URNet在保持高效率的同时实现了最先进的性能。代码将在https://github.com/Wild-Stephen/URNet上提供。

## Abstract
Previous RGB-D semantic segmentation methods commonly employ dual encoders to separately process RGB and depth inputs, followed by dedicated modules for cross-modal feature fusion. However, such designs often inadequately capture depth representations and consequently limit effective cross-modal interaction, while the additional encoder branch introduces redundant computation that hinders lightweight execution. To tackle these challenges, we propose URNet, a Unified Reparameterized RGB-D Network that performs simultaneous multi-modal feature extraction and cross-modal fusion within a single encoder. Specifically, we adopt a reparameterization strategy to compact the network architecture and facilitate fast inference. Within each Reparameterized Block (RepBlock), a Linear Gated Attention (LGA) module is introduced to fully exploit complementary RGB and depth cues across different feature scales. Furthermore, considering that decoder design has been relatively underexplored in existing RGB-D segmentation models, we develop a concise yet effective universal decoder, termed the Pyramid Merging Decoder (PMD). Extensive experiments on multiple RGB-D segmentation benchmarks demonstrate that URNet achieves state-of-the-art performance while maintaining high efficiency. Code will be available at https://github.com/Wild-Stephen/URNet.

## 1. 核心问题与整体含义（研究动机与背景）

RGB-D语义分割通过联合利用RGB图像（色彩、纹理等外观线索）与深度图像（几何结构、空间关系）实现逐像素的场景解析。然而，现有方法普遍存在以下三大局限：

- **双编码器结构的固有缺陷**：主流方法（如SA-Gate、CMX、Sigma等）采用双编码器分别处理RGB和深度输入，深度分支往往使用在RGB数据上预训练的编码器初始化，导致深度特征建模不充分（深度模态与预训练数据分布存在显著差异）；
- **跨模态交互不充分**：融合模块通常只在少量编码器阶段引入，稀疏的融合位置限制了多模态信息的有效互补；如DPLNet仅在部分阶段引入提示模块、GeminiFusion仅允许匹配token交互；
- **计算冗余严重**：额外的编码器分支带来大量重复计算，不利于轻量化部署和实时推理。

针对上述问题，论文提出**URNet（Unified Reparameterized Network）**，在**单个统一编码器**内同时完成多模态特征提取与跨模态融合，结合**重参数化策略**压缩网络结构、加速推理，并在每个编码块中引入**线性门控注意力（LGA）** 实现RGB与深度特征的密集交互。此外，论文还提出了一种轻量高效的**金字塔合并解码器（PMD）**，弥补现有研究对解码器设计重视不足的缺憾。

## 2. 方法论：核心思想与关键技术细节

### 2.1 整体框架

URNet采用编码器-解码器架构，训练分为两个阶段：

- **阶段一（Phase I）**：在大规模**RGB-D ImageNet-1k**数据集上进行预训练，统一编码器直接处理配对的RGB和深度图像，在每个编码块内嵌入跨模态交互；
- **阶段二（Phase II）**：在NYUDepth V2和SUN-RGBD等下游分割数据集上微调，将预训练表示适配到任务特定分布。

### 2.2 层级编码器（Hierarchical Encoder）

- 输入RGB图像 \(I_{rgb} \in \mathbb{R}^{H\times W\times 3}\) 与深度图 \(I_d \in \mathbb{R}^{H\times W\times 1}\)，分别经并行stem层（4个3×3卷积，stride=2）处理后，送入四个层级阶段（L1~L4），输出分辨率依次为原图的1/4、1/8、1/16、1/32。
- 提供四种规模配置：**URNet-T/S/B/L**，参数分别为9.2M、19.8M、44.1M、62.2M。

### 2.3 重参数化块（RepBlock）

借鉴RepViT的设计思想，用卷积操作替代自注意力，以更低的计算代价捕获全局上下文。Token Mixer采用**并行多分支结构**：

- 分支1：3×3深度可分离卷积
- 分支2：1×1深度可分离卷积
- 分支3：1×7 → 7×1分解卷积（引入7×7感受野）

公式表达为：
\[
x^{rgb}_i = Conv^d_{3\times3}(f^{rgb}_i) + Conv^d_{1\times1}(f^{rgb}_i) + Conv^d_{7\times1}(Conv^d_{1\times7}(f^{rgb}_i)) + f^{rgb}_i
\]

得益于重参数化技术，训练时的跳连分支可在推理阶段移除，消除相应计算量与内存开销。

### 2.4 线性门控注意力（LGA）

在RepBlock中间位置引入LGA模块，实现RGB与深度特征的高效融合。核心步骤：

1. 对RGB和深度特征分别进行**池化+3×3卷积**，生成模态感知描述符；
2. 通过**Sigmoid**生成门控信号，编码跨模态信息的重要性；
3. 用门控信号对另一模态进行**逐元素乘法调制**（对称交叉门控），保留原始模态特性的同时实现选择性交互：
   \[
   g^{rgb}_i = \sigma(Conv_{3\times3}(Pool(x^{rgb}_i))), \quad g^d_i = \sigma(Conv_{3\times3}(Pool(x^d_i)))
   \]
   \[
   \hat{x}^{rgb}_i = x^{rgb}_i + g^d_i \odot x^{rgb}_i, \quad \hat{x}^d_i = x^d_i + g^{rgb}_i \odot x^d_i
   \]
4. 融合后的特征分别经**SENet模块**进行通道校准，最后沿通道维拼接：
   \[
   m_i = Concat(SE(\hat{x}^{rgb}_i), SE(\hat{x}^d_i))
   \]

LGA采用线性逐元素运算，避免了注意力机制中二次复杂度的token交互，计算开销几乎可忽略。

### 2.5 金字塔合并解码器（PMD）

现有RGB-D分割模型对解码器设计重视不足，多直接用MLP或HAM（Hamburger）。PMD采用**自顶向下的金字塔渐进合并策略**：

- 对每层特征进行3×3卷积校准；
- 低层特征通过下采样与相邻高层特征逐元素相加，再经上采样自顶向下传播；
- 中间融合阶段使用**池化**缓解尺度不匹配并抑制冗余信息：
  \[
  t_k = m^c_k + Ds(t_{k-1}), \quad g_k = Us(t_k)
  \]
  \[
  s_k = Pool(s_{k-1} + g_k), \quad m_f = s_1 + s_2 + s_3 + s_4
  \]
- 最后经**金字塔池化（P-Pooling）**捕获多感受野上下文信息，并与聚合特征残差连接：
  \[
  y = m_f + PPool(m_f)
  \]

PMD仅由简单操作（上/下采样、池化、逐元素加法）构成，参数开销极小。

## 6. 主要结论与发现

1. **统一编码器优于双编码器**：在单编码器内同时进行多模态特征提取与融合，能显著缓解RGB预训练编码器对深度建模不足的问题，RGB-D联合预训练比RGB-only预训练带来+1.2% mIoU的提升。
2. **重参数化设计兼顾精度与效率**：RepBlock在接近自注意力的精度水平下（53.17% vs 53.45%），将参数量从18.40M降至9.26M、FLOPs从20.89G降至15.35G，推理速度提升超过5倍。
3. **LGA实现高效融合**：对称交叉门控机制优于简单的加法和拼接融合，在几乎不增加计算负担的情况下显著提升分割精度。
4. **PMD解码器有效**：相比MLP和HAM，PMD在提升精度的同时保持轻量，填补了解码器设计的研究空白。
5. **跨任务泛化能力强**：在RGB-D显著性检测上同样表现出色，验证了统一RGB-D表示的通用性。
6. **轻量化优势突出**：在NYUDepth V2上URNet-L（58.8% mIoU，73.0G FLOPs）超过DFormerV2-L（58.4% mIoU，124.1G FLOPs），以约40%的计算量实现了更高精度。

## 7. 优点

- **架构创新性**：将双编码器压缩为统一单编码器，从根本上消除了深度分支的冗余计算，同时通过每个block内的密集交互弥补了融合位置稀疏的问题；
- **重参数化的巧妙应用**：在训练阶段保留多分支结构，推理阶段合并为单一卷积，兼顾性能与部署效率，特别适合移动端/机器人等资源受限场景；
- **LGA设计的简洁性与有效性**：仅用池化+卷积+Sigmoid门控就实现了高效的跨模态交互，避免了注意力机制的高计算负担，设计优雅；
- **关注解码器设计**：首次在该任务中系统研究了解码器的影响，PMD以极小成本带来明显性能提升，具有通用参考价值；
- **实验体系完整**：从预训练到分割、从消融到跨任务泛化（SOD），验证链路清晰，提供了不同规模的模型配置供实际应用选择；
- **代码开源**：承诺提供开源实现，便于复现与后续研究。
