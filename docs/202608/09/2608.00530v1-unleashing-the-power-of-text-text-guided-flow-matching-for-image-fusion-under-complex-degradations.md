## 摘要
在真实退化场景下的红外-可见光图像融合是一项具有挑战性的任务，因为退化不仅导致观测图像中可靠的模态特定信息丢失，还会阻碍融合过程。近期研究表明，文本能够提供关于退化特征的先验信息，补充受损输入图像中有限的证据，从而促进融合。然而，现有方法通常将固定的全局文本表示注入视觉特征，使得文本引导难以适应空间变化的退化、局部结构和热显著性。为此，我们提出了TGFusion，一个文本引导的潜在空间流匹配框架，统一了退化抑制和跨模态融合。TGFusion将任务、退化和生成线索编码为结构化提示。为了充分利用这些先验，我们设计了一个提示条件多流联合流Transformer，将文本作为与融合、可见光和红外流并列的独立语义流。联合注意力实现了语义与视觉表示之间的token级双向交互和逐层更新，使退化语义能够动态指导可靠信息的选择和融合潜在生成。在公共基准和复杂退化场景上的大量实验表明，TGFusion在感知质量、图像自然度、结构细节保留和红外显著性保持方面取得了优越或具有竞争力的性能，同时在多样化的单一和复合退化下保持鲁棒性。

## Abstract
Infrared-visible image fusion under realistic degradation scenarios is a challenging task, as degradations not only cause a loss of reliable modality-specific information in observed images but also hinder the fusion process. Recent studies indicate that text can provide prior information about degradation characteristics, complementing the limited evidence available from corrupted input images and facilitating fusion. However, existing methods typically inject fixed global text representations into visual features, making it difficult for textual guidance to adapt to spatially varying degradations, local structures, and thermal saliency. To this end, we propose TGFusion, a text-guided latent-space flow matching framework that unifies degradation suppression and cross-modal fusion. TGFusion encodes task, degradation, and generation cues into structured prompts. To fully exploit these priors, we design a Prompt-conditioned Multi-stream Joint Flow Transformer that represents text as an independent semantic stream alongside fusion, visible, and infrared streams. Joint attention enables token-level bidirectional interaction and layer-wise updating among semantic and visual representations, allowing degradation semantics to dynamically guide reliable information selection and fusion latent generation. Extensive experiments on public benchmarks and complex degradation scenarios demonstrate that TGFusion achieves superior or competitive performance in perceptual quality, image naturalness, structural-detail preservation, and infrared-saliency retention, while remaining robust across diverse single and compound degradations.

## 2. 论文提出的方法论

**核心思想：**
将 IVIF 视为条件生成问题：从噪声出发，在紧凑 VAE 潜空间中生成融合结果，整个生成轨迹由文本语义先验和退化输入共同引导。文本不再是固定条件，而是作为独立语义流，与融合、可见光、红外三种视觉流通过联合注意力逐层动态交互。

**关键组成：**

- **结构化提示构建：**
  - 提示 p = qtask ⊕ qdeg ⊕ qgoal（文本拼接），分别编码任务描述、模态特定退化类型与严重程度、生成目标。
  - 使用 ChatGPT 生成多样化语言变体；训练时随机采样与标注退化状态一致的提示变体，推理时使用固定变体保证可复现性。
  - 用冻结的 CLIP 文本编码器 τ(·) 将提示映射为 token 级表示 c = [c1, c2, ..., cL]。

- **潜空间流匹配（Conditional Flow Matching）：**
  - 定义线性概率路径：Zt = (1−t)Z0 + tZ1，目标速度 ut = Z1 − Z0。
  - 优化目标为学习条件速度场 vθ 逼近目标速度：Lflow = E[∥vθ(Zt, t, C) − (Z1−Z0)∥²]。
  - 推理时用 Euler ODE solver 从 t=0 积分到 t=1，将高斯噪声逐步转化为融合潜变量，再用冻结 VAE 解码器重建融合图像。

- **Prompt-conditioned Multi-stream Joint Flow Transformer（核心架构）：**
  - **四流设计**：M = {fuse, vis, ir, text}，融合流为生成状态，可见光/红外流为视觉条件，文本流为语义条件。
  - **全局条件构建**：对时间嵌入与三条件流（vis/ir/text）进行池化投影求和，得到全局条件 gt 用于 AdaLN 调制。
  - **联合注意力（Joint Attention）**：各流经 AdaLN 调制后生成 QKV，沿 token 维度拼接进行联合自注意力，输出再按原始 token 范围切分并分别经输出投影、门控残差连接和 FFN 更新。
  - **逐层交互**：文本 token 与视觉 token 在每层都进行双向交互，使退化语义能动态定位到空间区域并指导融合生成；融合流最终投影预测条件速度 ût。

- **训练损失：**
  - 流匹配目标 Lflow 完成潜空间速度场学习。
  - 像素级融合正则：强度损失 Lint（融合结果与两源图亮度最大值的 L1 距离）+ 梯度损失 Lgrad（融合结果与两源图最大 Sobel 梯度幅值的 L1 距离）。
  - 总损失 Ltotal = Lflow + λpix·Lpixel，λpix=4，λg=3。
  - 训练时使用伪融合目标 Z1：由冻结的 Text-IF 模型从对应干净源图像对生成。

- **推理：**
  - 从标准高斯噪声 Z0 出发，25 步 Euler ODE 求解，classifier-free guidance scale 为 3.0，最终解码得到融合图像。

## 6. 论文的主要结论与发现

1. **文本先验可以超越静态条件**：将文本作为独立语义流与视觉流进行逐层联合注意力交互，使文本引导能定位到空间退化的具体区域，实现动态、区域敏感的条件生成，而非固定全局调制。
2. **潜空间流匹配有效统一退化抑制与融合**：相比像素空间扩散/流匹配，潜空间方案避免了亮度放大、结构冲刷和颜色伪影，同时保持较低计算开销。
3. **综合性能全面领先**：在 MSRS、LLVIP、M3FD、TNO 及 DDL-12 退化基准上，TGFusion 在 EN、AG、CLIP-IQA、TReS、NIQE、MUSIQ 等无参考指标上取得最优或次优；在退化场景下的优势尤其明显。
4. **下游任务受益**：在 MFNet 语义分割评估中取得最高 mIoU（71.83%）和 mAcc（81.47%），有效抑制了对比方法中出现的虚假响应。
5. **联合交互机制有效**：注意力可视化显示，浅层为广泛的模态间交互，深层逐渐转为结构追踪（VIS）、热目标聚焦（IR）和内容感知的空间文本响应，表明文本引导随生成演进。

## 7. 优点

## 8. 不足与局限

**实验覆盖局限：**

- **仅合成退化**：DDL-12 为合成退化数据集，与真实世界的退化复合方式（传感器噪声、大气条件、运动模糊等复杂耦合）存在差距，论文未在真实退化场景上验证。
- **下游任务单一**：仅评估语义分割，未覆盖 IVIF 最重要的应用场景之一——目标检测，降低了"下游效用"结论的通用性。
- **CC 指标系统性偏低**：论文解释为"保留退化内容导致高 CC"，但这同时意味着 TGFusion 可能过度偏离源图像内容，在源信息保真度上存在潜在风险；缺乏对"信息选择正确性"的更强验证。
- **退化类型覆盖有限**：训练与评估仅覆盖 DDL-12 中定义的退化类型，对未见过的退化组合、未知退化类型的泛化能力未充分说明。

**方法论局限：**

- **依赖伪标签生成**：训练需要 Text-IF 从干净源图像对生成伪融合目标，存在伪标签质量的上界限制——若 Text-IF 本身产生伪影或丢失信息，TGFusion 的训练目标也随之受限。
- **提示依赖人工设计**：退化描述需要预先知道退化的类型与严重程度，在实际应用中若退化未知或提示不准确，文本引导的效果会打折。
- **推理开销**：25 步 ODE 采样 + 潜空间编解码，相比单前向融合网络仍有明显计算开销，对实时性要求高的应用（如自动驾驶）可能受限。
- **部分消融指标矛盾未充分解释**：如去像素损失配置（IV）获得了最高 AG，像素空间流匹配（III）获得了次优 CLIP-IQA 和 TReS，但论文对这些高分主要归因于伪影/过度增强，缺乏判别性定量证据来完全支撑这一解读。

**潜在偏差风险：**

- DDL-12 训练与评估同源，模型对特定退化分布的过拟合风险未被充分讨论。
- 对比方法中两阶段管线使用的预增强模型并非为融合任务专门调优，可能未达到其最优性能，存在对比不公平的可能。
