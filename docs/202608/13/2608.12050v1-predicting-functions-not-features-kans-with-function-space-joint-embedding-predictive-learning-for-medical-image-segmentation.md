## 摘要
Kolmogorov–Arnold网络（KAN）通过将每条网络边参数化为可学习的单变量函数，引入了显式的函数表示。然而，现有的基于KAN的分割模型仅通过边聚合后定义的损失来优化边函数，使得单个函数缺乏明确的聚合前学习目标。为解决这一局限，我们提出了用于医学图像分割的函数空间联合嵌入预测学习（FS-JEPA）。我们的FS-JEPA框架将预测学习移至KAN的聚合前函数空间。掩码在线分支预测由全上下文指数移动平均目标分支生成的采样KAN边函数的结构化签名，而共享的边索引保持了预测与目标之间的对应关系。我们并非预测孤立的边响应，而是使用由输入锚点周围函数评估组成的多半径签名来表示每个采样的边函数。这种结构化表示捕获了单一响应无法表征的局部函数变化，并提供了更具信息量的预测目标。在训练过程中，函数空间目标与分割损失联合优化，而在推理时移除预测分支。在五个医学图像分割基准上的实验表明，我们的FS-JEPA取得了最佳平均Dice，并比最强的竞争性基于KAN的方法高出+2.25个百分点。

## Abstract
Kolmogorov--Arnold Networks (KANs) introduce explicit functional representations by parameterizing each network edge as a learnable univariate function. However, existing KAN-based segmentation models optimize edge functions only through objectives defined after edge aggregation, leaving individual functions without an explicit pre-aggregation learning target. To address this limitation, we propose Function-Space Joint-Embedding Predictive Learning (FS-JEPA) for medical image segmentation. Our FS-JEPA framework moves predictive learning into the pre-aggregation function space of KANs. A masked online branch predicts structured signatures of sampled KAN edge functions generated by a full-context exponential moving average target branch, while shared edge indices preserve correspondence between predictions and targets. Rather than predicting an isolated edge response, we represent each sampled edge function using a multi-radius signature composed of function evaluations around its input anchor. This structured representation captures local functional variations that cannot be characterized by a single response and provides a more informative predictive target. The function-space objective is jointly optimized with the segmentation loss during training, while the predictive branch is removed at inference. Experiments on five medical image segmentation benchmarks show that our FS-JEPA achieves the best average Dice and outperforms the strongest competing KAN-based method by +2.25 percentage points.

## 1. 论文的核心问题与整体含义

- **研究背景**：Kolmogorov–Arnold Networks（KAN）将每条网络边参数化为可学习的单变量函数，为神经网络提供了显式函数表示。现有 KAN 分割模型（如 U-KAN、KAT 等）仅通过边聚合后的节点输出计算损失，单条边的函数行为只能被“间接、隐式”地约束，缺乏明确的聚合前学习目标。
- **核心问题**：不同边函数组合可能产生相同聚合输出，导致边函数配置冗余；且单个输入锚点上的函数响应不足以刻画局部函数变化。论文试图回答：能否将 JEPA 预测学习从特征空间扩展到 KAN 的“函数空间”，直接对边函数本身进行结构化监督？
- **整体含义**：提出 FS-JEPA（Function-Space Joint-Embedding Predictive Learning），在 KAN 边聚合之前，通过在线分支预测 EMA 目标分支生成的多半径边函数签名，为每条被采样边提供显式的预聚合学习信号，从而提升医学图像分割性能，且推理时零额外开销。

## 2. 论文提出的方法论

- **核心思想**：采用联合嵌入预测学习框架，将预测目标从特征嵌入替换为 KAN 边函数的“结构化签名”。在线分支接收部分掩码的上下文，预测由全上下文 EMA 目标分支产生的签名；两个分支共享相同的采样边索引，保证预测与目标对应同一输入-输出边函数。
- **关键技术细节**：
  - **KAN 边函数与采样**：每条边函数用 B 样条参数化：  
    ϕ_{j,i}(u) = wb_{j,i}·SiLU(u) + s_{j,i}·Σ ws_{j,i,ℓ}B_p^ℓ(u)。  
    为控制计算量，随机采样 K 个边对 (i_k, j_k)，通过“selected-edge operator”只计算采样边响应，复杂度从 O(BN d_in d_out) 降至 O(BNK)。
  - **多半径函数签名**：对每个采样边，在输入锚点 u 的邻域取 6 个偏移量（±0.025, ±0.05, ±0.10），将函数在多个位置上的取值拼接为签名向量：  
    s_e = [ϕ(u−0.10), ϕ(u−0.05), ϕ(u−0.025), ϕ(u+0.025), ϕ(u+0.05), ϕ(u+0.10)]。  
    该表示能刻画局部函数变化，比单点响应更具信息量。
  - **确定性边对应**：由于随机采样，同一位置在不同迭代可能对应不同边。用输入/输出节点的规范坐标 (p_i, p_j) 编码边的身份，并与签名拼接作为预测器条件，解决对应关系，同时不引入额外可学习参数。
  - **预测目标**：在线预测器 q_ψ 从掩码上下文表示、边响应、锚点和坐标编码中预测签名 ŝ_e；目标签名为 EMA 分支的停止梯度输出。损失采用 SmoothL1：L_sig = SmoothL1(ŝ_e, s_e^+)。
  - **联合优化**：总损失 = 主分割损失 + 深度监督损失 + 各 KAN 块的签名预测损失加权和。模型从随机初始化端到端训练；EMA 分支和预测器仅训练时使用，推理时移除，不改变原分割网络。

## 6. 论文的主要结论与发现

- **性能提升**：FS-JEPA 在 5 个基准上平均 Dice 达 0.8337、IoU 达 0.7504，优于所有对比方法；相比 Matched Scaffold 提升 0.85 个百分点 Dice，相比最强 KAN 方法 UUEKAN 提升 2.25 个百分点 Dice，且参数更少（7.74M vs 35.02M）。
- **预测空间的重要性**：函数空间预测优于特征级/节点级预测；单点边响应预测甚至可能带来负面效果，而多半径签名显著有效。
- **多半径签名的有效性**：Raw multi-point 签名在函数预测质量和分割性能上均优于其他变体，表明结构化局部函数描述是函数空间预测学习的关键。
- **机制验证**：FS-JEPA 对补偿扰动敏感，证明其提供了传统聚合后损失无法提供的边级约束，并确实重塑了 KAN 边函数表示。
