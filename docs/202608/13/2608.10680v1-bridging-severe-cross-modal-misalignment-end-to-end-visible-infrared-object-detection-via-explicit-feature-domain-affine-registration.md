## 摘要
可见光-红外目标检测依赖于RGB与热成像的互补线索，但跨模态空间错位常导致其性能下降。现有大多数方法依赖隐式特征自适应来处理弱错位场景，而大偏移几何差异仍未得到充分解决。本文提出一种联合特征域配准与检测网络（JFRDet），这是一种专为严重跨模态几何差异设计的端到端可见光-红外有向目标检测器。JFRDet引入跨模态仿射对齐（CMAA）模块，估计图像级仿射变换以实现显式的多级特征对齐。考虑到光照变化直接影响RGB线索的可靠性，光照引导互补融合（IGCF）模块在不同光照条件下自适应利用模态可靠性进行跨模态融合。随后，对齐质量-一致性门控（AQCG）策略通过根据对齐可靠性和梯度一致性调节检测监督来稳定联合优化。我们进一步构建了DroneVehicle Misaligned（DVMA）基准，用于评估严重跨模态几何错位下的可见光-红外有向目标检测。所提JFRDet在DVMA上达到69.7%的mAP50，代表了当前最先进的性能。代码和数据集将在GitHub上发布。

## Abstract
Visible-infrared object detection relies on complementary RGB and thermal cues, but its performance is often degraded by cross-modal spatial misalignment. Most existing methods rely on implicit feature adaptation to handle weakly misaligned scenarios, while large-offset geometric discrepancies remain insufficiently addressed. In this paper, we propose a Joint Feature-domain Registration and Detection network (JFRDet), an end-to-end visible-infrared oriented object detector tailored for severely cross-modal geometric discrepancies. JFRDet introduces a Cross-Modal Affine Alignment (CMAA) module to estimate an image-level affine transformation for explicit multi-level feature alignment. Note that illumination changes directly affect the reliability of RGB cues, an Illumination-Guided Complementary Fusion (IGCF) module adaptively exploits modality reliability under varying illumination conditions for cross-modal fusion. Then, an Alignment Quality-Consistency Gating (AQCG) strategy stabilizes joint optimization by modulating detection supervision according to alignment reliability and gradient consistency. We further construct DroneVehicle Misaligned (DVMA), a benchmark for evaluating visible-infrared oriented object detection under severe cross-modal geometric misalignment. The proposed JFRDet achieves 69.7\% $\mathrm{mAP}_{50}$ on DVMA, which represents state-of-the-art (SOTA) performance. The code and dataset will be available on GitHub.

- **研究动机**：可见光-红外目标检测（VIOD）利用RGB与热成像的互补线索，在低光照或恶劣天气下具有明显优势。然而，由于传感器位置、视角或平台运动的差异，可见光-红外图像对经常出现空间错位（平移、旋转、尺度变化），严重削弱跨模态特征融合的效果。
- **现有方法的不足**：
  - 大多数现有方法依赖隐式特征自适应来处理**弱错位**场景，对于大偏移（数十甚至上百像素）的几何差异缺乏有效建模。
  - 主干网络下采样会将微小偏移映射为低分辨率特征图上难以区分的位移，使模型在训练时近似“对齐”，从而无法真正学习解决内在的跨模态空间差异。
  - 现有数据集（如DroneVehicle）的偏移量大多在1~5像素内，难以评估模型在严重错位下的鲁棒性。
- **本文目标**：提出一种端到端框架JFRDet，通过**显式特征域仿射配准**来桥接严重跨模态错位，同时构建一个具有更大偏移量的基准数据集DVMA，以推动该方向的研究。

## 2. 方法论

### 总体架构
- 采用双流骨干网络提取多尺度模态特定特征，以可见光分支为参考，CMAA估计仿射变换并对齐红外特征，IGCF在光照自适应条件下融合对齐后的特征，最后送入S2A-Net检测头进行有向目标预测；AQCG在训练中调节检测监督权重。

### 核心模块一：Cross-Modal Affine Alignment (CMAA)
- **粗粒度匹配（Coarse-Grained Matching）**：在1/16分辨率特征上，经过位置编码和自/交叉注意力后，计算温度缩放的相似度矩阵S，通过双向softmax（RGB→IR和IR→RGB）得到置信度，筛选出高于阈值θ_c的候选对应关系，建立鲁棒的初始匹配M_c。
- **细粒度匹配（Fine-Grained Matching）**：对每个粗匹配，在1×1、3×3、5×5三层局部窗口中从粗到细逐步精化，通过局部双softmax选出高置信度对应，再用轻量回归器预测坐标偏移以降低离散化误差，得到精化匹配M_f。
- **特征仿射配准**：基于精化匹配，通过置信度加权的最小二乘拟合估计仿射变换T_ir→rgb：
  - \( T = \arg\min_T \sum_n w_n \| p_n^{rgb} - T \bar{p}_n^{ir} \|_2^2 \)
  - 将变换应用于红外特征金字塔的每一层，通过双线性采样（可微）得到对齐后的特征金字塔\(\tilde{F}_{ir}\)。

### 核心模块二：Illumination-Guided Complementary Fusion (IGCF)
- 从可见光图像计算光照分数η（归一化平均强度），并据此得到暗度因子d(η)。
- 对每个特征层，从RGB与IR响应的差异生成空间门控图G_l，乘以全局暗度因子d(η)控制抑制强度，从而在低光照下抑制不可靠的可见光响应。
- 通过逐元素乘积和绝对差建模共享与互补线索（R_cc），融合公式为：
  - \( F_{fus}^l = F_{rgb}^l + \tilde{F}_{ir}^l + (1-G_l) \odot (E_{rgb}^l + E_{ir}^l) + R_{cc}^l \)
- IR特征仿射变换产生的无效区域在计算中被掩蔽。

### 核心模块三：Alignment Quality-Consistency Gating (AQCG)
- **对齐质量评估**：对对齐损失维护指数移动平均\(\bar{L}_{align}\)，计算质量分数\( Q_t = \exp(-\bar{L}_{align}/(L_{ref}+\epsilon)) \)，再映射到符号门控信号\( Q_t^s = \tanh(\kappa(Q_t - \theta)) \)。
- **梯度一致性**：计算对齐损失与检测损失关于仿射变换的梯度余弦相似度\( C_t \)。
- **检测权重计算**：\( s_t = (1-\lambda_c)Q_t^s + \lambda_c C_t \)，\( \alpha_t^{det} = 2^{s_t} \)，范围在[0.5, 2.0]。
- 总体目标函数：\( L = L_{align} + \alpha_t^{det} L_{det} \)，门控权重在反向传播中截断，仅作为训练阶段的调节器。

## 3. 实验设计

- **数据集/基准**：
  - **DroneVehicle Misaligned (DVMA)**：从DroneVehicle构建，包含28,439对无人机可见光-红外图像，5个车辆类别（car、freight car、truck、bus、van），带有向标注。训练集17,990对，验证集1,469对，测试集8,980对。
  - 构造方式：可见光图像居中裁剪，红外图像施加旋转（15°~30°）、各向异性缩放（[0.90, 1.10]）和平移的组合变换，仅保留变换后有效区域IoU在[0.70, 0.80]的配对，从而产生数十到数百像素的偏移。
- **对比方法**：包括单模态检测器（RetinaNet、R3Det、S2ANet、KFIoU，分别使用RGB或IR输入）和多模态检测器（C2Former + Faster R-CNN/S2ANet、DMM + Faster R-CNN/S2ANet、COMO），全部采用OBB检测头。
- **评估指标**：mAP50和mAP50:95。

## 6. 主要结论与发现

- 显式仿射特征配准能有效降低严重跨模态错位带来的负面影响，比隐式特征自适应更为有效。
- JFRDet在DVMA上达到**69.7% mAP50**和**36.1% mAP50:95**，超越所有对比方法（最好的多模态方法DMM+S2ANet为66.7% mAP50）。
- 消融实验显示，三个模块（CMAA、IGCF、AQCG）均有正向贡献，且彼此互补：
  - 基线66.0%；+CMAA为67.3%；+IGCF为68.0%；+AQCG为68.2%；三者全加为69.7%。
- 红外单模态检测器表现优于可见光单模态探测器，说明在挑战性场景下红外信息更可靠。
- 可视化分析证实CMAA能有效将红外特征激活区域对齐到可见光参考坐标，减少跨模态不一致性。

## 7. 优点

- **方法层面**：
  - 首次针对**严重跨模态错位**提出显式的特征域仿射配准方案，而非仅依赖隐式适应，具有明确的问题针对性。
  - 端到端可微设计，仿射变换估计和多尺度特征配准可在统一框架中联合优化。
  - AQCG的设计巧妙，利用对齐质量和梯度一致性动态调控检测监督权重，解决了早期训练中配准不稳定导致优化被误导的问题。
  - 光照引导融合符合物理直觉，暗度因子+局部差异门控的设计简洁有效。
- **实验层面**：
  - 构建DVMA基准填补了严重错位数据集的空白，且保留了完整变换参数，可自动生成跨模态对应标注，便于后续研究。
  - 组件的消融和参数敏感性分析较全面。

## 8. 不足与局限

- **实验验证范围有限**：仅在一个经过合成变换的数据集（DVMA）上评测，未在真实自然错位数据或弱错位数据集上验证，泛化性存疑。DVMA的错位虽大但属于已知参数控制的合成变换（旋转+缩放+平移），真实场景中的错位可能更复杂（如局部非刚性形变）。
- **方法适用性限制**：CMAA估计的是**全局仿射变换**，对每个图像对只估计一个变换，无法处理同一图像内不同区域错位不一致的情况（如视差导致的局部差异）。
- **计算效率未报告**：粗-细匹配+注意力机制的计算开销未与对比方法进行比较，实际部署中的时效性未知。
- **标签选择偏差**：训练时使用红外模态的标注作为真值，这在红外提供了更完整标注的前提下是合理的，但光照充分时可见光标注可能更准确，统一选择红外标注可能存在一定偏差。
- **对比范围有限**：未与最新（2024-2026）的其他错位校准方法（如DAMSDet、CF-Defo-DETR等）进行直接对比。
- **与单模态方法对比的门槛**：DVMA是合成构建的，红外单模态S2ANet已达到61.6% mAP50，多模态方法的增益相对有限，提示在严重错位下几何校正之外可能还有更本质的信息利用问题。
