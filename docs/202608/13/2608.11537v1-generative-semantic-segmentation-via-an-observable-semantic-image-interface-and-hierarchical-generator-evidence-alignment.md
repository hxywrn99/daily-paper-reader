## 摘要
生成式语义分割将结构化预测暴露为图像，但直接的颜色解码易受颜色漂移和边界混合的影响，而预测独立输出分布的潜在特征解码器可能将渲染图像降级为中间可视化。我们提出Semantic Prism，一种具有确定性推理的条件语义图像生成与细化框架。扩散蒸馏的单步生成器渲染语义RGB图像；渲染颜色到固定类颜色码本的逐像素距离定义了一个显式概率接口。层次化生成器证据对齐在空间上对齐多级生成器特征，并使用零初始化输出投影在接口对数空间预测加性残差，保留图像定义的接口作为最终分布的参考。该接口和细化分布进一步支持上下文接口-层次不一致性（C-IHD），这是一种固定读出机制，无需辅助预测器或额外前向传播即可对剩余像素误差进行排序。在包含500张图像的Cityscapes验证集上，Semantic Prism实现了72.07%的平均交并比，比直接接口解码高11.39个mIoU百分点，预期校准误差为0.41%。匹配容量的消融实验在三个种子上支持联合对齐多级证据的益处。单独训练的模型在BDD100K上达到62.22%的mIoU，而Cityscapes训练的模型在源冻结迁移到带对应关系的恶劣条件数据集（ACDC）时达到46.89%的mIoU，无需目标域自适应。在所有三个数据集上，C-IHD在相同分割预测上的像素误差排序中，相较于最大软概率，始终提高了精确率-召回率曲线下面积；在ACDC上，它将AUPR从0.6580提升到0.7557。

## Abstract
Generative semantic segmentation exposes structured predictions as images, but direct color decoding is susceptible to color drift and boundary mixing, whereas latent-feature decoders that predict a separate output distribution may relegate the rendered image to an intermediate visualization. We present Semantic Prism, a conditional semantic-image generation-and-refinement framework with deterministic inference. A diffusion-distilled one-step generator renders a semantic RGB image; per-pixel distances from the rendered colors to a fixed class-color codebook define an explicit probabilistic interface. Hierarchical Generator Evidence Alignment spatially aligns multi-level generator features and uses a zero-initialized output projection to predict an additive residual in the interface logit space, retaining the image-defined interface as the reference for the final distribution. The interface and refined distributions further enable Contextual Interface--Hierarchy Disagreement (C-IHD), a fixed readout for ranking remaining pixel errors without an auxiliary predictor or additional forward pass. On the 500-image Cityscapes validation set, Semantic Prism achieves 72.07% mean intersection over union, 11.39 mIoU points above direct-interface decoding, with 0.41% expected calibration error. Matched-capacity ablations over three seeds support the benefit of jointly aligned multi-level evidence. A separately trained model attains 62.22% mIoU on BDD100K, while the Cityscapes-trained model reaches 46.89\% mIoU under source-frozen transfer to the Adverse Conditions Dataset with Correspondences, without target-domain adaptation. Across all three datasets, C-IHD consistently improves the area under the precision--recall curve for pixel-error ranking over maximum softmax probability on the same segmentation predictions; on ACDC, it raises AUPR from 0.6580 to 0.7557.

## 1. 论文的核心问题与整体含义

生成式语义分割（Generative Semantic Segmentation）试图将结构化预测（如分割掩码）直接编码为图像输出，从而提供一种可见、可独立评估的预测界面。然而，现有方法存在一个核心两难问题：

- **直接颜色解码**（Direct Color Decoding）：从渲染的 RGB 语义图中直接恢复类别标签，虽然保持了预测与图像之间的透明关系，但容易受到 **颜色漂移（color drift）、边界混合（boundary mixing）和模糊** 的影响，导致在语义过渡区域和细薄结构处出现类别分配错误。
- **潜在特征解码**（Latent-Feature Decoding）：利用潜在特征解码器可以恢复细粒度空间细节，但当最终分布通过一条独立于图像定义接口的路径生成时，渲染出的语义图像实际上退化为仅用于中间可视化的副产品，丧失了作为可独立评估接口的价值。

因此，本文的核心动机是：**如何在保留语义图像作为显式、可独立评估的概率接口的同时，恢复细粒度的空间精度**，从而打破上述两难。

作者提出 **Semantic Prism** 框架，其核心思路是：渲染的语义图像定义逐像素类别分布并作为最终预测的参考，而层次化生成器特征仅在其对数空间（logit space）上施加加性修正，而不是建立一条独立的预测路径。

## 2. 论文提出的方法论

### 2.1 总体框架

Semantic Prism 是一个**单步语义图像生成与精化框架**，推理过程完全确定性。整个流程分为三个核心环节：

1. **单步语义图像生成**：使用扩散蒸馏（diffusion-distilled）的 pix2pix-Turbo 生成器，将输入图像 x 确定性地渲染为语义 RGB 图像 s，同时暴露多层内部特征图。
2. **可观测概率接口**：通过固定的基于距离的颜色码本解码器，将渲染图像转换为完整的逐像素类别分布 p_I。
3. **层次化精化**：HGEA 在接口对数空间上预测加性残差，并与图像定义的接口耦合得到最终分布 p_H。

### 2.2 可观测语义-图像接口（Observable Semantic-Image Interface）

给定固定类别颜色码本 C = {c_k}（K 个类别，每个类别一个 RGB 原型），以及温度参数 τ_I，固定解码器对每个像素 u 计算：

- 距离：d_Ik(u) = ‖s(u) − c_k‖²
- 接口对数：z_Ik(u) = −d_Ik(u)/τ_I
- 接口分布：p_I(u) = softmax(z_I(u))

该接口具有**可观测性**（operationally observable）：
- Top-1 标签可直接从渲染图像恢复：ŷ_I(u) = arg min_k d_Ik(u)，即渲染色所属的欧氏 Voronoi 单元；
- 任意两个类别之间的成对对数几率（pairwise log-odds）具有闭式形式：Λ_Iab(u) = (d_Ib(u) − d_Ia(u))/τ_I。

因此，不需要访问任何潜在特征，仅凭渲染图像和固定码本即可完整恢复接口分布。

### 2.3 层次化生成器证据对齐（HGEA）

HGEA 的作用是在不破坏接口参考地位的前提下，利用生成器多级特征修正接口：

- 从生成器中选取 3 个特征层级（|J|=3），各层级经 1×1 卷积投影到 24 通道，依次经过组归一化（GN）、SiLU 激活和双线性重采样，对齐到输出分辨率；
- 将多级对齐特征与输入图像 x、渲染图像 s、接口分布 p_I 拼接，送入残差头 R_φ；
- 残差头由两个 3×3 Conv–GN–SiLU 块加上**零初始化** 1×1 输出投影组成，输出 K 类对数残差 Δz_H；
- 最终分布：p_H = softmax(z_I + Δz_H)。

关键设计在于：
- **零初始化**保证训练开始时 p_H = p_I，接口作为参考不被破坏；
- **加性残差**约束意味着 HGEA 只是修改接口的对数几率（ΔΛ_Hab = Δz_Ha − Δz_Hb），而不是建立独立的输出分布路径；
- 生成器权重冻结，仅训练一个仅含 **190,891 个可训练参数** 的轻量 HGEA 模块。

### 2.4 上下文接口–层次不一致性（C-IHD）

C-IHD 是一个**固定读出机制**，用于像素级错误排序，不需要辅助预测器或额外前向传播。它由三个分量组成：

1. **点态不确定性**：U_MSP(u) = 1 − max_k p_H,k(u)（最大软概率补数）；
2. **局部上下文**：U_loc(u) = A_{5×5}[U_MSP](u)（5×5 局部平均）；
3. **接口–层次不一致性**：D_IHD(u) 为归一化的 ρ 加权 Jensen–Shannon 散度（ρ=0.8），量化 HGEA 对接口分布的修正程度，取值范围 [0,1]。

最终分数为标准化的加权组合：U_C-IHD(u) = w⊤[(g(u) − μ_tr) ⊘ σ_tr]，其中权重 w = (1, 0.5, 0.2)⊤，统计量在源训练集上预先估计后固定。C-IHD 不改变任何分割预测，仅在固定预测上进行错误倾向排序。

## 6. 论文的主要结论与发现

1. **接口本身独立可评估**：固定码本解码即可达到 60.68% mIoU，证明语义图像可直接解码为有效预测；
2. **HGEA 显著提升精度**：Cityscapes 上 mIoU 从 60.68% 提升至 72.07%（**+11.39 点**），同时 ECE 从 5.69% 降至 **0.41%**；
3. **多级证据联合对齐有效**：ML-HGEA（71.43±0.47%）一致优于 CM-Flat（69.75±0.40%）和 SL-HGEA_mid（70.54±0.59%），配对差异分别达 1.68±0.11 和 0.89±0.23 个 mIoU 点；
4. **精化具有选择性**：HGEA 在 93.48% 的有效像素上保持接口原始预测，修正了 48.68% 的接口错误，精度增益主要集中于边界区域（+18.85 点 vs 内部 +1.67 点）；
5. **C-IHD 一致改进像素错误排序**：在三个数据集上均优于 MSP（固定 p_H 不变），ACDC 上 AUPR 从 0.6580 提升至 **0.7557**；Cityscapes 上 C-IHD 获得最高 AUPR（0.4812）；
6. **跨域迁移具有竞争力**：源冻结转移到 ACDC 达到 46.89% mIoU，低于 DDP-CNXT-T（51.24%）但高于多个判别式基线，且获得最低 ECE（8.48%）。

## 7. 优点

1. **概念创新性强**：首次系统性地将"可观测概率接口"（像素分布可从渲染图像完全恢复）与"同空间残差精化"（层次化特征只修正接口对数，不建立独立路径）结合起来，解决生成式分割的关键难题；
2. **接口可解释性出色**：top-1 标签对应欧氏 Voronoi 单元，成对对数几率有闭式解，接口与最终预测的差异可由 HGEA 修正显式量化；
3. **工程巧妙性**：零初始化输出投影保证训练开始时精化恒等；C-IHD 复用已有分布，零训练参数、零额外前向传播实现错误排序；
4. **实验严谨性突出**：受控容量匹配、多种子重复、预注册统计量、固定端点不调参、配对 Bootstrap 置信区间，方法学上非常规范；
5. **评估全面性**：覆盖精度、校准、边界质量、错误排序、计算开销、跨域泛化、机制干预等多个维度。

## 8. 不足与局限

1. **闭集码本限制**：固定类别数 K 的码本使得模型无法处理开放类别或新类别的场景，扩展性受限；
2. **计算成本仍偏高**：尽管是单步生成，端到端时延（635 ms，1.57 FPS）仍明显高于轻量判别式方法，峰值显存需求也较大（6.40 GiB）；
3. **跨域证据有限**：论文仅做了 Cityscapes→ACDC 的源冻结迁移，且源模型在城市街景上训练，夜间的 mIoU 崩塌至 27.81%，跨域泛化能力未见充分的域自适应方法对比；
4. **精度仍有差距**：Cityscapes 上 72.07% mIoU 落后于强判别式基线（如 Mask2Former-SwinT 77.92%、DDP-CNXT-T 79.10%），生成式框架在纯精度上尚未达到最优；
5. **IHD 单独效果有限**：固定预测读出分析显示，接口–层次不一致性单独作为错误排序信号时效果较弱（AUPR 仅 0.3014），其主要价值在于补充组合而非独立检测；
6. **架构选择依赖**：框架依赖 pix2pix-Turbo 的特定生成器架构及其内部特征分布，更换生成器后 HGEA 的对齐机制需要重新适配；
7. **C-IHD 依赖训练集统计量**：源冻结迁移时直接复用源统计量，若目标域数据分布偏移极大（如 ACDC 的夜间场景），标准化的有效性可能下降。

总体而言，Semantic Prism 为生成式语义分割提供了一种新颖且严谨的框架设计——既保留了渲染图像的显式可评估性，又通过层次化证据对齐达成了细粒度精度和出色校准，并在像素级错误排序方面提供了轻量实用的工具。然而，其在纯精度上相较最强判别式模型仍有差距，且闭集码本与计算开销制约了其实用化边界。
