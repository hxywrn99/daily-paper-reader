## 摘要
联合使用RGB和红外（IR）图像可以改善无人机视角的目标检测，但大多数现有方法以静态或固定权重融合多模态特征，因而忽视了空间变化的模态可靠性。我们提出EGM-Det，一种用于RGB-IR目标检测的熵引导多模态自适应融合框架。EGM-Det采用双流架构以保留模态特定表示，并引入熵偏移门控融合模块实现自适应多尺度融合。该模块从输入强度、局部熵和跨模态差异中导出浅层熵先验，并利用这些先验指导局部偏移对齐和空间-通道门控融合。因此，它选择性地聚合可靠的RGB和红外线索，而非统一组合异构特征。我们还引入跨模态蒸馏来正则化所学融合门控并减少融合退化。每个学生分支从与主干分支匹配的跨模态教师分支中提取互补知识，而熵自适应监督则强调不确定的模态决策。在DroneVehicle、LLVIP和VEDAI上的实验表明，EGM-Det在所有三个基准上均达到最先进性能；尤其是在VEDAI上，EGM-Det比先前方法提高了超过10个百分点。

## Abstract
Joint use of RGB and infrared (IR) imagery can improve UAV-view object detection, but most existing methods fuse multimodal features with static or fixed weights and therefore overlook spatially varying modality reliability. We propose EGM-Det, an entropy-guided multimodal adaptive fusion framework for RGB-IR object detection. EGM-Det employs a dual-stream architecture to preserve modality-specific representations and introduces an Entropy Offset Gate Fusion module for adaptive multi-scale fusion. The module derives shallow entropy priors from input intensity, local entropy, and cross-modal discrepancy, and uses them to guide local offset alignment and spatial-channel gated fusion. It therefore selectively aggregates reliable RGB and infrared cues instead of uniformly combining heterogeneous features. We further introduce cross-modal distillation to regularize the learned fusion gates and reduce fusion degradation. Each student branch extracts complementary knowledge from the cross-modality teacher branch matched to the main branch, while entropy-adaptive supervision emphasizes uncertain modality decisions. Experiments on DroneVehicle, LLVIP, and VEDAI demonstrate state-of-the-art performance across all three benchmarks; in particular, EGM-Det outperforms prior approaches by more than 10 percentage points on VEDAI.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究领域**：无人机（UAV）视角下的RGB-红外（RGB-IR）多模态目标检测，主要面向交通监控、城市安防和应急救援等应用场景。
- **核心挑战**：相比地面视角，无人机航拍图像中的目标通常尺寸小、分布密集、方向任意，且易受复杂背景和光照变化影响。虽然有可见光和热红外互补优势，但两种模态的可靠性在空间上是**内容相关**且**动态变化**的——同一区域在RGB中可能清晰可辨，在IR中却模糊不清；反之亦然。现有方法大多使用静态或固定权重对多模态特征进行融合，**没有显式建模"在哪些位置、在什么条件下应该更信任哪个模态"**，导致不可靠或冗余的模态响应被传播到检测结果中。
- **论文主张**：可靠的多模态检测器不仅应学习**如何**融合跨模态特征，还应学习**何时何地**应信任哪个模态。EGM-Det以信息熵为核心指导，将场景自适应模态选择作为显式监督目标，动态感知场景属性以确定主导模态。

## 2. 提出的方法论

### 2.1 核心思想
EGM-Det 以**信息熵**为引导线索，构建了一套"先验构建→局部对齐→门控融合→蒸馏正则"的多模态融合闭环。它训练时依赖双教师蒸馏，推理时仅保留双流学生检测器，无额外开销。

### 2.2 熵引导双流架构（Entropy-Guided Dual-Stream Architecture）
- 采用**双流对称分支**分别提取RGB和红外多尺度特征（`F_rgb_l` 和 `F_ir_l`），保留模态特有表示。
- 跨模态交互仅在选定的特征层（P3–P5）通过熵偏移门控融合模块进行，避免早期融合导致不可靠响应的过早混合。

### 2.3 熵偏移门控融合模块（Entropy Offset Gate Fusion, EOGF）
EOGF 是论文的核心创新模块，包含以下三个关键步骤：

1. **浅层熵先验构建（Entropy Prior）**
   - 输入：两张模态的归一化强度图 `I_rgb/I_ir`、局部熵图 `H_rgb/H_ir` 以及跨模态差异 `I_rgb - I_ir`。
   - 通过轻量先验估计器输出多尺度熵先验 `P_l`，编码局部结构复杂度、模态显著性以及跨模态差异，用于条件化后续对齐和门控。

2. **局部偏移对齐（Offset Alignment）**
   - 将RGB和IR特征投影到共享嵌入空间，预测**偏移场 Δ_l** 和**对齐置信度 C_l**（利用先验P_l作为引导）。
   - 通过可微翘曲操作将RGB特征对齐到IR参考特征，进行特征空间的局部校正，缓解弱对齐问题。不同于全局图像配准。

3. **空间-通道门控融合（Spatial-Channel Gated Fusion）**
   - 在对齐基础上，预测**双向空间模态门控** `G_l = [g_rgb_l, g_ir_l]`，满足 `g_rgb_l + g_ir_l = 1`，即软选择每个空间位置上RGB/IR的贡献比例。
   - 同时预测**通道门控** `c_rgb_l/c_ir_l`，估计各特征通道的重要性。
   - 融合特征按公式 `F_fus_l = g_rgb_l ⊙ c_rgb_l ⊙ F̃_rgb_l + g_ir_l ⊙ c_ir_l ⊙ F_ir_l` 生成。

### 2.4 选择性多模态蒸馏（Selective Multimodal Distillation）
训练时，两个独立训练并冻结的**单模态教师**（RGB教师、IR教师）用于监督学生的空间门控。

- **软模态偏好目标**：由教师分类输出的密集置信度图 `M_l^m(x,y)` 归一化得到 `Q_l = [q_rgb_l, q_ir_l]`，表示每个空间位置的模态相对可靠性。
- **教师可靠性权重**：`R_l(x,y) = max(M_rgb_l, M_ir_l)`，即取两个教师中响应较强者的置信度，用于降低两个教师都较弱的区域对门控蒸馏的贡献。
- **学生门控熵与自适应权重**：计算学生空间门控的归一化熵 `H_l(x,y)`（值越大表示不确定性越高），将其映射为像素级自适应权重 `ω_l`（通过 `clip` 函数和 `sg()` 停止梯度），使不确定区域的监督信号更强。
- **自适应门控蒸馏损失**：`L_adapt_gate` 以 `R_l × ω_l` 为权重，对学生门控 `G_l` 和教师偏好目标 `Q_l` 计算KL散度。
- **特征蒸馏**：同模态分支蒸馏（`L_branch`，channel-wise spatial KL divergence）和跨模态特征蒸馏（`L_cross`，teacher-attention 加权的 Pearson correlation），分别保留模态特有表示并传递互补知识。
- **总损失**：`L_total = L_det + αλ(e)(L_branch + L_cross + L_adapt_gate)`，其中 `αλ(e)` 是随训练epoch衰减的全局蒸馏权重。

- **组件贡献明确**：消融实验表明熵引导融合架构是主要性能来源（mAP<sub>50-95</sub> 贡献约 3 个百分点），双教师蒸馏和熵自适应权重分别贡献约 1 个百分点的提升；熵权重对 truck 和 van 等模糊类别提升尤为明显。
- **定性结果支持设计动机**：可视化显示学生门控具有清晰的空间自适应性——红外在热对比显著或低照度区域权重更高，RGB在可见结构丰富的区域保持主导；高熵区域集中在目标边界、密集簇和跨模态不一致处，与模态选择困难区域高度吻合。
- **标注一致性对多模态检测至关重要**：DroneVehicle 原始标注的跨模态不一致和类别混淆会显著影响训练和评估，细化协议为公平比较提供了基础。

## 7. 优点

- **问题建模有新意**：将"模态偏好选择"显式化为可监督的分布目标，而不是隐式依赖检测损失，这比单纯改进融合网络更直接地解决模态可靠性变化问题。
- **熵先验设计巧妙且轻量**：直接从输入强度、局部熵和跨模态差异构建先验，无需额外大型网络，兼顾了物理意义和计算效率。
- **蒸馏机制有选择性**：不盲目模仿教师所有预测或融合特征，而是聚焦于空间门控，并通过学生门控熵动态调节监督权重，避免"教师不可靠区域强行监督"和"学生已自信区域过度蒸馏"两个问题。
- **标注细化工作严谨**：通过系统性审核修正了跨模态不一致和类别级错误，并发布了细化的标注记录（包含切分、图像ID、模态、原始/精化标签、校正类型），对社区有实际贡献。
- **实验协议公正**：主实验在统一细化协议下重训练所有方法，避免因数据划分或评估脚本差异带来的不公平比较；组件的消融清晰分离。

- **不确定性的覆盖不完整**：门控熵仅描述模态选择的不确定性，不覆盖传感器噪声、域偏移或标注歧义等更广泛的不确定性来源。
