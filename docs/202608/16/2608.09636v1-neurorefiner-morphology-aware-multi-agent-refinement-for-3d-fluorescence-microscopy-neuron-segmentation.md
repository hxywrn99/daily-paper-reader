## 摘要
荧光显微镜中的精确三维神经元分割对于神经科学至关重要。然而，神经元稀疏且细长的形态对现有分割方法提出了重大挑战。这些方法难以同时保留局部细节和全局拓扑，导致分割结果碎片化。为解决这一问题，我们提出了NeuroRefiner，一种多智能体系统，它将人类专家的迭代全局观察与局部编辑工作流程形式化。具体而言，NeuroRefiner包含三个协作智能体，分别负责诊断拓扑错误、生成修正指令和验证细化质量。为了促进智能体指令引导的分割细化，我们提出了TopoRefineNet，一种专用的基于3D U-Net的工具，通过跨模态特征融合生成细化掩膜。通过多轮智能体推理和体素级编辑，NeuroRefiner生成拓扑更准确且可解释性更强的分割结果。在BigNeuron、CWMBS和ZBFWB数据集上的实验表明，NeuroRefiner优于现有最先进方法，尤其在具有挑战性的ZBFWB数据集上，F1分数提升了3.02%。

## Abstract
Accurate 3D neuron segmentation in fluorescence microscopy is critical for neuroscience. However, the sparse and elongated morphology of neurons poses significant challenges to existing segmentation methods. These methods struggle to preserve both local details and global topology, leading to fragmented results. To address this, we propose NeuroRefiner, a multi-agent system that formalizes the human expert workflow involving iterative global observation and local editing. Specifically, NeuroRefiner comprises three collaborative agents dedicated to diagnosing topological errors, generating correction instructions, and validating refinement quality. To facilitate agent instruction-guided segmentation refinement, we propose TopoRefineNet, a dedicated 3D U-Net-based tool that leverages cross-modality feature fusion to generate refined masks. Through multi-round agent reasoning and voxel-level editing, NeuroRefiner produces topologically more accurate segmentations with enhanced interpretability. Experiments on the BigNeuron, CWMBS, and ZBFWB datasets demonstrate that NeuroRefiner outperforms state-of-the-art methods, notably achieving a 3.02% improvement in F1 score on the challenging ZBFWB dataset.

## 2. 方法论：核心思想、关键技术细节、算法流程

### 核心思想
- 模仿神经科学家的认知范式：在整体形态评估与局部精细编辑之间交替进行，通过多轮“诊断 → 指令 → 编辑 → 验证”闭环实现渐进式优化。
- **解耦高层推理与底层体素操作**：利用自然语言作为中间媒介，让LLM智能体负责空间推理与决策，让专用分割工具负责体素级掩膜编辑。

### 系统组成：三个智能体 + 一个执行工具

1. **Global Inspector（全局检查器）**
   - 输入：初始3D分割掩膜、图像、0阶Betti数 β₀。
   - 对分割掩膜沿z轴做最大强度投影（MIP）得到2D投影，划分为若干非重叠子块。
   - 计算每个子块的 β₀(bᵢ) = CC(Mᵢ)（连通分量数），作为拓扑不规则性度量。
   - 输出需要修复的子块集合 B_fix 及误报（FP）/漏报（FN）标签。

2. **Refinement Advisor（细化建议器）**
   - 输入：目标子块在xy平面和yz平面的双视角MIP投影（图像 + 掩膜）。
   - 输出：结构化自然语言修正指令 tᵢ，包含**空间位置**（如“左上前方”）和**编辑操作**（如“连接”“移除”）。
   - 例如：“连接位于中上后侧区域的神经元”“移除左上前方区域的孤立噪声”。

3. **Change Validator（变更验证器）**
   - 对比初始掩膜与细化后掩膜，依据两个标准判定是否接受修正：
     - **指令遵循度**：修改是否准确执行了 tᵢ 的空间与操作意图；
     - **拓扑改进度**：细化结果碎片减少或噪声被抑制，且未引入新伪影。
   - 不接受则触发重新生成指令；多次失败后升级给人工专家处理。

4. **TopoRefineNet（拓扑细化网络）——执行工具**
   - 以3D U-Net为基础架构，将分割细化建模为**指令引导的图像编辑任务**。
   - 视觉编码器对 [图像; 掩膜] 的拼接输入编码生成特征金字塔；文本编码器（Qwen3 Embedding 0.6B）对指令编码。
   - 通过瓶颈层**交叉注意力（Cross-Attention）**融合视觉与文本特征，动态定位指令指定的区域和操作，最终解码生成细化掩膜。
   - 核心公式：M_refined = F_θ(Iᵢ, Mᵢ, tᵢ) = D ∘ CrossAttn(E_θ([Iᵢ; Mᵢ]), T_φ(tᵢ))

### 两阶段训练策略
- **第一阶段**：利用合成形态缺陷数据（针对真实掩膜做腐蚀生成断点、随机复制粘贴或添加高斯噪声生成假阳性），训练跨模态对齐能力。
- **第二阶段**：使用多个不同分割网络（3D U-Net、V-Net、UNETR、nnFormer、SwinUNETR）在训练集上推理产生的**真实缺陷样本**（共5,310个128×128×64体积），用 Qwen3-VL 合成指令，提升真实泛化能力。

### 算法流程（伪代码核心逻辑）
```
初始化掩膜 M⁰
循环（t < T_max）：
  Global Inspector 计算MIP、子块、Betti数 → 识别问题块B_fix及类型τᵢ
  若 B_fix 为空 → 终止
  对每个问题块：
    Refinement Advisor 生成指令 tᵢ
    TopoRefineNet 执行细化 → M_refined
    Change Validator 验证
    接受则合并更新，拒绝则重试（最多T_retry次）
  迭代次数 t+1
```

## 6. 主要结论与发现

- **NeuroRefiner 显著优于所有SOTA方法**：
  - **CWMBS弱信号子集**：3D U-Net掩膜上F1从74.94%→90.07%（+15.13%），nnUNet掩膜上F1从79.83%→91.85%；SD从25.97→7.26。
  - **CWMBS强噪声子集**：F1最高达86.37%（3D U-Net基础）。
  - **ZBFWB**：F1分数86.13%，比最优语义分割方法GBP-Net高出**3.02%**，比初始3D U-Net提升13.19%。
  - **BigNeuron**：F1达90.05%，MES提升5.20%，SSD降低4.33。
- **多智能体协作的价值**：消融实验证实三个智能体功能解耦与协作能带来逐步增益——单独立即可提供提升，全系统最优；部分“修复”迭代会引入不稳定，Change Validator过滤不可靠细化后F1再获提升（ZBFWB +2.66%、CWMBS +1.68%）。
- **迭代次数**：首轮迭代增益最大，5轮后改善趋于平稳，T_max=5合理。
- **框架对基础模型无关**：即使替换为更弱的VLM仍有显著提升，说明增益主要来自系统架构和TopoRefineNet，而非特定大模型。
- **两阶段课程学习有效**：单阶段训练导致验证器拒绝率增加23.57%，F1下降1.17%（ZBFWB）和1.89%（CWMBS）。

## 7. 优点

- **问题定位准确**：针对神经元分割中真正瓶颈——拓扑断裂、碎片化，而非单纯边界优化，切中实际需求。
- **创新的系统设计**：首次将LLM多智能体引入神经元分割细化，形成“全局诊断-语言指令-局部编辑-验证”闭环框架，且智能体无需训练即可部署。
- **语言作为中间表示**：将高层推理与体素级操作解耦，兼具推理灵活性和操作的精确性，同时提供**透明的、可审计的**推理过程，改善可解释性。
- **技术细节扎实**：
  - 使用0阶Betti数作为拓扑异常量化指标简单有效；
  - MIP双视角投影（xy/yz）辅助VLM适应3D空间推理；
  - 两阶段课程学习（合成→真实缺陷）稳定了跨模态训练过程；
  - TopoRefineNet的交叉注意力设计针对性强，有效执行指令指定的局部修正。
- **框架通用性**：对基础模型无关、对初始分割网络无关（可应用于任意分割掩膜），易于扩展。
- **实验全面**：3个数据集、5组消融、多角度分析，验证了各模块的独立贡献。

### 8. 不足与局限（续）

- **依赖指令质量**：Refinement Advisor 生成的指令依赖 VLM 对 2D MIP 投影的解读质量。若初始掩膜缺陷过于复杂或空间描述产生歧义（例如多个相似断点在相邻子块同时出现），生成的指令可能不准确或漏检，TopoRefineNet 即使完全遵循指令也无法修正真正的缺陷。论文未系统量化指令错误率及其对最终分割的连锁影响。
- **掩膜编辑范围的碎片化风险**：全局检查器将体积划分为非重叠子块，但神经元纤维可能跨越子块边界，某个缺陷可能被割裂到不同子块，导致各子块独立修复的指令无法协同恢复跨越边界的完整形态。虽然迭代可部分缓解，但局部编辑与全局拓扑之间的张力并未完全消除。
- **合成数据与现实域差距**：第一阶段使用合成形态缺陷进行预训练，第二阶段使用多个网络的真实缺陷进行微调，但合成缺陷的形态分布（腐蚀断点、高斯噪声块）与真实复杂神经元的断裂/假阳性模式仍存在差异，这在其他成像协议上可能引发性能下降。
- **评估指标对重构管线敏感**：体素级 F1 与拓扑级 SD/SSD 均依赖 APP2 重构结果，APP2 本身的分割误差和参数敏感性可能影响评估公平性，论文未讨论该因素。
- **缺少失败案例分析**：虽然对成功场景给出可视化，但未系统展示系统在哪些情况下失效（如高度纠缠的神经毡区域、严重低信噪比区域），这对实际部署中的预期管理很重要。

## 9. 文中相关引用

- **Ophiuchus / IBISAgent / GenCellAgent**：作为 LLM 多智能体医学图像分割的代表作，被用于说明现有智能体方法局限于单次工具调用、依赖 2D 基础模型逐切片处理、缺乏迭代细化能力，与 NeuroRefiner 形成对照。
- **3D U-Net / V-Net / UNETR / nnFormer / SwinUNETR**：作为初始分割器与 3D 分割基线，提供真实缺陷样本来源和对比对象。
- **APP2**：作为标准神经元重构算法，被用于将分割掩膜转换为神经元形态并计算拓扑指标。
- **Qwen3-VL / Qwen2.5-VL / Intern-VL3**：作为多模态语言模型，承担全局检查器、细化建议器和变更验证器的视觉语言推理功能。
