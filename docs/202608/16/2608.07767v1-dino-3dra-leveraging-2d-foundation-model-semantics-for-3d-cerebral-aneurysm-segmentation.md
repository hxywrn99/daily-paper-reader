## 摘要
三维旋转血管造影（3DRA）中的精确动脉瘤分割受到极端类别不平衡、与血管形态相似以及缺乏大规模三维预训练的限制。2D视觉基础模型从17亿张图像中编码了密集的结构先验，但朴素的逐切片迁移会破坏解剖连续性并导致优化不稳定。我们提出DINO-3DRA，一种双路径框架，通过Room-Lite空间混合和校准残差融合将冻结的DINOv3特征注入3D U-Net骨干，实现有效的跨维度语义迁移。在多中心3DRA数据上，DINO-3DRA仅用5.72M可训练参数即达到最先进的动脉瘤分割性能（Dice：0.758；HD95：2.75 mm；较nnU-Net提升13%）。消融研究证实，性能提升源于结构化的跨维度迁移而非仅损失函数设计，桥接的基础特征改善了动脉瘤与载瘤血管之间的解剖连续性。无需在CADA和SHINY-ICARUS上微调，DINO-3DRA即消除了基线架构中观察到的所有灾难性失败案例，展示了在异构成像协议下的稳健泛化能力。

## Abstract
Accurate aneurysm segmentation in 3D rotational angiography (3DRA) is hindered by extreme class imbalance, morphological similarity to vessels, and absent large-scale 3D pretraining. 2D vision foundation models encode dense structural priors from 1.7 billion images, yet naïve slice-wise transfer fragments anatomical continuity and destabilises optimisation. We propose DINO-3DRA, a dual-path framework achieving effective cross-dimensional semantic transfer by injecting frozen DINOv3 features into a 3D U-Net backbone via Room-Lite spatial mixing and calibrated residual fusion. On multi-centre 3DRA data, DINO-3DRA achieves state-of-the-art aneurysm segmentation (Dice: 0.758; HD95: 2.75 mm; +13% over nnU-Net) with only 5.72M trainable parameters. Ablation studies confirm that gains arise from structured cross-dimensional transfer rather than loss design alone, with bridged foundation features improving anatomical continuity between aneurysms and parent vessels. Without fine-tuning on CADA and SHINY-ICARUS, DINO-3DRA eliminates all catastrophic failure cases observed in baseline architectures, demonstrating robust generalisation across heterogeneous imaging protocols.

## 1. 核心问题与整体含义（研究动机与背景）

- **临床背景**：颅内动脉瘤影响3–5%人群，破裂后死亡率高。3D旋转血管造影（3DRA）是详细血管成像的金标准，但其自动分割面临重大挑战。
- **技术挑战**：① 极端类别不平衡（背景~94%、血管~5%、动脉瘤<1%）；② 动脉瘤与正常血管形态相似，边界模糊；③ 医学影像领域缺乏大规模3D预训练模型，3D模型难以学到丰富的结构先验。
- **核心矛盾**：2D视觉基础模型（VFM，如DINOv3）已在17亿自然图像上通过自监督蒸馏学习到密集语义特征（物体边界、部分-整体关系、结构先验），且能有效迁移到CT、X光等医学模态；但三维体积模型因数据稀缺而缺乏等效预训练。
- **现有不足**：朴素的逐切片（slice-wise）2D→3D迁移会破坏切片间的解剖连续性，且自然图像与医学图像的域差异容易导致混合优化不稳定。已有的DITR方法依赖RGB-D点云投影，不适用于无相机、无点云的3DRA模态。
- **研究意义**：本文旨在探索一种轻量级、有效的跨维度迁移范式——在不进行昂贵3D预训练的前提下，将冻结2D基础模型的语义先验注入3D分割网络，同时保持体积连贯性与优化稳定性。

## 2. 方法论

### 核心思想
- 采用**双路径架构**：一条可训练的3D U-Net主干处理体积输入，另一条**冻结的DINOv3-Small分支**从2D轴向切片提取语义特征，二者在多个分辨率层级经由专门设计的桥接模块融合。
- 核心观点：**结构化的跨维度迁移**（而非单纯损失设计或特征拼接）是实现性能提升的关键。

### 关键技术细节
1. **双路径编码器**：
   - 3D分支：4个编码器阶段，通道从32扩至256，分辨率从64³下采样至8³，每阶段含两个3×3×3卷积+GroupNorm+GELU，对称解码器使用转置卷积和跳跃连接，约5.6M参数。
   - 2D分支：DINOv3-Small（ViT-S/16，384维嵌入，在LVD-1689M上预训练），处理64张轴向切片，每张复制为RGB并缩放至224×224；196个patch token全局平均为单条384维语义嵌入，广播到{64², 32², 16²}空间支持，经1×1卷积投影为{24, 48, 96}通道，再用三线性插值转为各向同性3D体积。

2. **Room-Lite空间混合器（恢复体积连贯性）**：
   - 由于DINOv3逐切片处理，堆叠出的体积缺乏层间连续性。Room-Lite通过**可学习的深度位置偏置** B(z)∈R^{C×D×1×1} 编码切片解剖位置，并采用**深度可分离3D卷积**恢复空间连贯性：
   
   `Y = X + GELU(GN₁(Conv₁×₁×₁(Conv₃×₃×₃(X + B(z)))))`

3. **校准残差融合（对齐统计分布）**：
   - DINO与U-Net特征统计分布差异大，直接拼接性能反而下降。采用**单组GroupNorm（GN₁）归一化** + 1×1×1卷积投影 + **残差连接**：
   
   `F_fused = F_U + GELU(GN₁(W₁×₁×₁[F_U; GN₁(F_D)]))`
   
   - 残差连接在DINO特征无益时保留原始U-Net特征，起到“自适应门控”效果。

4. **训练目标（组合损失）**：
   - `L = 0.3·L_vessel + 0.5·L_aneurysm + 0.2·L_CE`
   - 血管Dice使用血管+动脉瘤联合类别以保持血管连续性；动脉瘤Dice单独优化病灶分割；类别加权交叉熵（权重{0.1, 1.0, 2.0}，归一化逆频率+截断防梯度爆炸）。

5. **后处理**：重叠patch预测多数投票聚合；动脉瘤阈值0.005（网格搜索选出，最大化Dice同时保持>90%体素级召回）；候选按 S = P_max + log₁₀(V) 评分，过滤最小尺寸（≥40体素）和血管邻近性。

## 6. 主要结论与发现

- **性能SOTA**：在多中心@neurIST上达到动脉瘤Dice 0.758（较nnU-Net提升13%）、HD95 2.75mm，血管Dice 0.897，且方差显著低于所有基线（σ=0.033 vs 基线0.097–0.138）。
- **消融归因**：性能提升源于**结构化的跨维度迁移**而非损失设计——失去Room-Lite或Calibration后Dice骤降至0.385/0.492，随机特征、DINOv2替换也明显劣化，证明预训练语义+桥接机制缺一不可。
- **解剖一致性**：完整模型产生跨越整个动脉瘤的高置信、连续预测，将动脉瘤视为“病理性血管扩张”而非孤立异常，为下游表面网格化和血流动力学建模提供更佳几何起点。
- **跨数据集鲁棒性**：在SHINY-ICARUS上Dice提升10.4%、HD95降低75.8%（15.52→3.76mm）；CADA上方差减半；**两个数据集上的所有灾难性失败（Dice<0.5）全部消除**（CADA 11.1%→0%; SI 3.3%→0%），变异系数降低52–70%。
- **已知偏差**：对大型或形态不典型动脉瘤（尤其是CADA中的梭形动脉瘤）倾向于欠分割——模糊边界被保守归类为血管，这反映模型学到的强血管先验。作者认为这是“可靠定位优先于体积完整性”的有意权衡。

## 7. 优点

- **轻量高效**：仅5.72M可训练参数（冻结DINO分支复用，新增约120K），远超nnU-Net 31M参数量，却获得更高性能。
- **创新桥接设计**：Room-Lite（深度位置偏置+深度可分离3D卷积）和校准残差融合（GN₁+残差门控）各自解决了一个关键问题（体积连续性、分布对齐），概念清晰且验证充分。
- **消融设计科学**：包含随机特征控制（证明预训练语义不可替代）和DINOv2替换（证明DINOv3较好），归因分析有说服力。
- **跨域验证扎实**：不微调地在两个异构外部数据集评估，并报告失败率、CV等多维指标而非单一均值，展示真实鲁棒性。
- **临床可解释性**：通过置信图可视化证明模型学到解剖连续性（动脉瘤是血管扩张而非独立物体），与后续血流动力学建模需求一致。
- **损失设计合理**：血管Dice采用联合类别保持连续性，动脉瘤Dice单独优化，类别加权交叉熵防梯度爆炸——三重机制协同解决极端类别不平衡。

## 8. 不足与局限

- **外部验证规模有限**：CADA n=45、SHINY-ICARUS n=30，结论需在更大外部队列确认；CADA平均Dice提升无统计显著性（p=0.607），仅方差改善。
- **训练时长大报缺失**：主实验未明确epoch数、总训练时间或GPU利用率，难以全面评估计算成本。
- **既有偏差未解决**：对大型/梭形动脉瘤的系统性欠分割是方法的内在局限，训练数据以小型囊状动脉瘤为主，限制了形态多样性。推测需要更多样化训练数据或形态感知损失来缓解。
- **未与其他2D→3D迁移方法直接对比**：仅对比了传统分割架构，未与DITR、MedDINOv3等同类迁移框架等比较，桥接设计的绝对优越性缺乏横向论证。
- **统计报告不够完整**：只报告p值，未报告效应量和置信区间；多重比较未做校正。
- **阈值敏感性**：动脉瘤阈值0.005在验证集网格搜索选择，虽统一应用，但跨数据集的阈值迁移性能未系统分析。
- **泛化边界**：未覆盖CT、MR等其他三维神经影像模态，结论仅适用于3DRA。
