## 摘要
视觉LSTM（ViL）能够实现高效的全局建模，但其成本仍然随空间标记数量而扩展，因此现有分割器将ViL限制在粗糙的瓶颈处，丢失了精细的解剖细节。将2D特征栅格化为1D序列进一步破坏了正交扫描轴上的邻接性。我们提出了MaLViL，一种多轴低秩视觉LSTM网络，将ViL扩展到解码器分辨率。双向低秩ViL（Bi-LRViL）在紧凑的标准正交子空间上进行推理，并通过正交残差保留细节；尺度感知的SaLViL在序列化之前恢复跨轴邻居；跨方向混合器（CDM）融合正交的水平与垂直遍历路径。统计引导的跳跃调制（SGSM）进一步保留编码器跳跃中的边界线索。在皮肤病变、超声和多器官CT基准上，MaLViL达到了竞争性或最先进的分割精度，同时在高分辨率解码器上将ViL算子内存减少高达83倍。代码可在以下网址获取：https://github.com/xmindflow/malvil。

## Abstract
Vision-LSTM (ViL) enables efficient global modeling, but its cost still scales with the number of spatial tokens, so existing segmenters confine ViL to a coarse bottleneck and lose fine anatomical detail. Rasterizing 2D features into a 1D sequence further breaks adjacency across the orthogonal scan axis. We propose MaLViL, a Multi-axis Low-rank Vision-LSTM network that extends ViL across decoder resolutions. Bidirectional low-rank ViL (Bi-LRViL) reasons on a compact orthonormal subspace and preserves detail through an orthogonal residual; scale-aware SaLViL restores cross-axis neighbors before serialization; and a Cross-Directional Mixer (CDM) fuses orthogonal horizontal and vertical traversal paths. Statistics-Guided Skip Modulation (SGSM) further retains boundary cues in encoder skips. On skin-lesion, ultrasound, and multi-organ CT benchmarks, MaLViL achieves competitive or state-of-the-art segmentation accuracy, while reducing ViL operator memory by up to $83\times$ at fine decoder resolutions. Code is available at: https://github.com/xmindflow/malvil.

## 1. 核心问题与研究动机

视觉LSTM（Vision-LSTM, ViL）由于采用类似xLSTM的矩阵记忆机制，能够对视觉序列进行双向全局建模，在医学图像分割中具有潜力。但ViL的计算成本随空间token数量（N=H×W）线性增长（每个block的序列相关开销为O(N·d²)），导致：

- **现有方法**通常只在低分辨率的**粗瓶颈层**使用ViL，以避免高分辨率解码阶段的高昂计算与激活内存开销；
- 但这样做会**丢失精细解剖细节**，限制了多尺度重建能力；
- 此外，将2D特征图**栅格化为一维序列**时，会破坏扫描方向正交轴上的空间邻接性，进一步削弱边界敏感分割的局部性。

MaLViL（Multi-axis Low-rank Vision-LSTM）旨在将ViL高效地扩展到**所有解码器分辨率**，同时保留空间局部性和全局上下文，实现高精度与低内存开销的统一。

## 2. 方法论

MaLViL采用分层编码器-解码器架构，核心由以下模块组成：

- **整体流程**：使用ImageNet预训练的PVTv2-B2作为编码器，产生1/4到1/32分辨率的特征；四个MaLViL Block从粗到细重建分割图；三个编码器skip通过SGSM融合。

- **Bi-LRViL（双向低秩ViL）**  
  将稀疏空间token投影到一个**紧凑的标准正交子空间**（V∈R^{N×p}, p≪N, V^T V=I），在p个压缩系数上执行ViL操作，再映射回图像网格。  
  关键公式：
  - 投影：Z = V^T X, X̂ = V V^T X, X_⊥ = X − X̂；
  - 双向混合：Z̄ = α⊙ViL_f(Z) + (1−α)⊙ViL_b(Z)，Y = X + V(Z̄−Z) − ω⊙X_⊥；
  - 正交残差X_⊥保留子空间外的细节，可学习的门控ω控制其贡献；
  - 重建正则化损失ℓ_rec = MSE(X, X̂)确保基能够保留有效空间信息。

- **SaLViL（尺度感知低秩ViL）**  
  在序列化之前，将通道划分为多个尺度组，每组使用不同感受野的**轴对齐卷积**（如1×1, 3×1, 5×1, 7×1）沿与ViL扫描正交的方向聚合上下文，恢复因栅格化而断裂的跨轴邻居。

- **CDM（跨方向混合器）**  
  对原始特征和90°旋转后的特征分别运行SaLViL，得到水平（FH）和垂直（FV）遍历路径的响应。CDM保留共享结构并注入方向性差异：  
  μ = 1/2(FH+FV)，A = 1/2(|FH−μ|+|FV−μ|)，F_CDM = μ + γ_h⊙A。  
  辅以3×3残差路径提供各向同性邻域信息。

- **SGSM（统计引导的跳跃调制）**  
  将编码器skip分解为低频平滑部分（Sl=AvgPool(S)）和高频细节部分（Sh=S−Sl）。利用解码器特征和skip的统计量（均值、方差、最大值）通过MLP生成门控g，融合方程：  
  SGSM(D,S) = D + g⊙Sl + β⊙Sh，  
  从而抑制语义噪声、保留边界细节。

- **SQ-FFN与目标函数**  
  全局建模后使用空间二次FFN（含深度卷积和二次激活s⊙ReLU(x)²+b）恢复局部细节。总损失为分割损失加低秩重建损失（系数λ=0.01）。

## 6. 主要结论与发现

- 在**Synapse**上，MaLViL以37.49M参数、6.56G FLOPs取得85.48%平均DSC，超过此前最佳GLM-SFNet（84.82%）约0.66%，并大幅超过仅在瓶颈使用ViL的UxLSTM-Bot（78.45%），证明**将低秩ViL扩展到解码器各分辨率**的有效性。
- 在皮肤病变上，PH2 DSC 95.68%、HAM10000 95.17%，ISIC2018达到SOTA（91.23%），ISIC2017为92.08%且准确率最高（97.15%）。
- 在BUSI上，DSC 81.76%，显著优于既有方法（如UWT-Net 79.65%）。
- 效率方面：在全分辨率解码阶段，低秩ViL相比完整ViL可将**算子内存降低83倍**，同时保持或提升精度；组件的渐进消融表明每加入一个模块（低秩、双向、SaLViL、CDM、SGSM、重建损失）都有收益。

## 7. 优点

- **创新性强**：将低秩投影与标准正交基引入ViL，使全局序列建模可在所有解码器分辨率上以极低代价进行，这是对现有ViL分割方法的重要改进。
- **空间-频率联合优化**：SaLViL恢复正交邻接、CDM融合双向遍历、SGSM分离低频/高频，从多个维度补充了栅格化丢失的局部细节。
- **清晰的模块化设计**：各组件可独立拆解、消融分析，便于理解贡献。
- **效率收益显著**：在同等或更高精度下，激活内存和FLOPs大幅下降，实用性强。
- **代码开源**，便于复现。

## 8. 不足与局限

- **未验证3D医学数据**：所有实验均为2D图像分割，未涉及CT/MRI的三维体积输入，而许多临床场景需要3D上下文；低秩ViL在3D token下的表现有待验证。
- **训练时长和硬件消耗未报告**：缺少具体训练时间、单epoch时间等信息，不利于他人评估复现成本。
- **部分基线为引用值，未统一重训**：皮肤和BUSI上的部分对比方法（如DermoSegDiff、EGE-UNet）直接引用原文结果，可能因数据划分、预处理不一致导致偏差；虽然作者说明retrained基线使用相同划分，但仍存在风险。
- **低秩之代价**：低秩投影会丢失子空间外的信息，虽然用正交残差和重建损失缓解，但极端情况下（p过小）仍可能限制全局上下文表达能力，论文对p的选择缺乏敏感性分析。
