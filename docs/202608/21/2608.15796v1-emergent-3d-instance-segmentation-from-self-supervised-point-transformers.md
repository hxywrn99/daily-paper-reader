## 摘要
户外LiDAR扫描的无监督3D实例分割传统上依赖于手工设计的几何先验，如基于密度的聚类、运动线索或投影的2D检测。在这项工作中，我们研究了一个冻结的、自监督的点云Transformer是否已经包含了在没有手工几何先验情况下分离对象实例所需的结构信息。仅将该Transformer用作特征提取器，我们在SemanticKITTI、nuScenes和Waymo Perception数据集上探查了其内部表示。我们的分析得出了四个核心见解：（1）实例信号集中在注意力查询和键中，而不是值或最终输出特征中；（2）输出特征在语义上坍缩，合并了相邻的同类对象，而这些对象在查询和键中保持区分；（3）该实例信号在深度上呈双峰分布，在最浅和最深编码器阶段最强；（4）该信号主要由旋转位置编码（RoPE）驱动，移除它会消除其优势。我们将这些发现应用于我们的方法TokenGraph3D，这是一种免训练的分割器，通过在键相似性图上使用连通分量对点进行分组，既不使用基于密度的聚类，也不使用邻近先验。在相同的无先验条件下，我们大幅优于基于输出特征的基线，使涌现的3D实例结构变得可见。

## Abstract
Unsupervised 3D instance segmentation of outdoor LiDAR scans has traditionally relied on handcrafted geometric priors such as density-based clustering, motion cues, or projected 2D detections. In this work, we investigate whether a frozen, self-supervised point transformer already contains the structural information required to isolate object instances without any handcrafted geometric prior. Using this transformer purely as a feature extractor, we probe its internal representations across the SemanticKITTI, nuScenes, and Waymo Perception datasets. Our analysis yields four core insights: (1) the instance signal concentrates in the attention queries and keys rather than in the values or final output features; (2) output features semantically collapse, merging adjacent same-class objects that the queries and keys keep distinct; (3) this instance signal is bimodal in depth, strongest at the shallowest and deepest encoder stages; and (4) this signal is driven predominantly by the rotary position encoding (RoPE), whose removal collapses its advantage. We put these findings into our method TokenGraph3D, a training-free segmenter that groups points via connected components on a key-similarity graph, using neither density-based clustering nor proximity priors. Under identical prior-free conditions, we substantially outperform output-feature baselines, making the emergent 3D instance structure visible.

### 2. 方法论

- **核心思想**：自监督点云Transformer（Utonia）为满足掩蔽重建或对比对齐的扫描级目标，必须隐式编码"哪些点属于同一物理实体"的对象级分组。该分组可从冻结网络的内部表示中直接读出。
- **TokenGraph3D整体流程**（三道流水线）：
  1. **特征提取**：冻结Utonia（137M参数）对完整LiDAR扫描做单次前向传播（含地面点），得到逐点表示——默认使用编码器enc4块的后RoPE注意力键
  2. **地面门控**：TerraSeg（自监督地面分割器，46M参数，变体B）将点分为地面/非地面两类，仅非地面点参与分组
  3. **点分组**：对非地面点构建无向余弦相似度图——边连接条件为：
     \[
     \langle \hat{g}_i, \hat{g}_j \rangle > \tau, \quad \tau \in [0,1)
     \]
     ——即两点特征余弦相似度超过固定阈值则连边；每个连通分量报告为一个实例
- **关键设计决策**：
  - 不使用密度阈值（无min_cluster_size）、无空间邻近约束、无运动或2D先验
  - 变体TokenGraph3D-Feat：用最终输出特征作为边特征，作为消融对比
  - 邻近门控消融：额外要求 \(\|p_i - p_j\|_2 \le r_{max}\)，仅用于量化几何先验的作用
  - 选择enc4而非enc0：两者性能接近（平均Sassoc 0.632 vs 0.630），但enc4簇数远少（nuScenes 466 vs 1364/扫描）、阈值更稳健，且粗token可抑制连通分量的传递性过合并
- **表示探针（seed-IoU）**：对每个真实实例均匀采样最多50个种子点，选取余弦相似度超过阈值的所有点，计算与真实实例的IoU，在不同表示间对比，隔离特征本身的分割能力

### 8. 局限性

- **骨干网络单一性**：所有实验均基于自监督点云Transformer Utonia。未验证该现象是否在PointBERT、Point-MAE、ACT等同类自监督点云模型中出现。因此“涌现式实例分割”的普适性仅在一个模型家族中成立，无法确认是否为自监督点云Transformer的普遍特性。
- **地面门控依赖额外模型**：尽管声称“无先验”，但整个分割流程依赖TerraSeg这一自监督地面分割器。地面门控本身虽不依赖实例标签，但引入了额外的网络组件与训练复杂度。若地面分割出现误差，将直接影响后续实例分组质量（尤其对小型物体）。
- **阈值敏感性**：TokenGraph3D采用固定余弦相似度阈值τ构建图，且τ需要针对数据集在小型标注池上搜索。尽管作者强调阈值稳健（在[0.90, 0.99]区间内性能变化平缓），但最优阈值仍随传感器密度、场景类型漂移，这属于一种隐式的超参数先验。
- **缺乏时序与多视角信息利用**：方法仅处理单帧点云。LiDAR序列中的运动一致性、多帧叠加信息均未利用，而这类信息通常能大幅提升无监督分割的鲁棒性。方法放弃这些线索虽彰显了“无先验”的纯粹性，但也限制了其在稀疏点云上的性能上限（如nuScenes上Sassoc仅0.517）。
- **Waymo评估标签粗糙**：Waymo无点级实例标签，使用3D框内所有点作为实例真值，但框内可能包含非物体点（如地面、背景），且框间重叠区域存在标签冲突，导致评估信号有噪声，可能轻微高估或低估真实性能。
- **计算负担未详细报告**：虽然推理是冻结前向+图分割，但未报告运行时间、内存消耗与扫描大小的关系。在64线LiDAR全扫描（约12万点）上构建全连接相似度图并做连通分量标记，实际开销可能与宣称的“轻量”不符。

### 9. 影响与启示

- **为无监督3D感知提供新范式**：本文证明了“先自监督预训练，再直接读取内部表示”即可完成复杂的实例分割任务，无需任何几何启发式。这为点云自监督学习赋予了新的价值——预训练模型不仅提供下游微调的初始化，其冻结表示本身就具备高级语义结构。
- **对现有无监督方法的降维打击**：传统方法（DBSCAN、HDBSCAN、运动分割）需要精心设计的距离尺度、密度参数或时间窗口，TokenGraph3D用一个固定阈值+连通分量即可超越它们。这提示基于密度或运动的启发式很可能只是对深层特征的粗糙近似，当特征足够好时可通过更简单的图算法直接利用。
- **重新审视位置编码的作用**：RoPE最初为Transformer的位置感知设计，本文发现它意外地成为实例分组的关键。这为后续点云Transformer的设计提供了明确指导：若需要实例级感知，应保留并强化位置编码，而非单纯依赖token内容。
- **对自动标注与数据引擎的潜在价值**：由于方法无需任何标注、可处理任意传感器配置，可直接用于大规模LiDAR数据的预标注（如为半自动标注系统提供初始实例提案），有望降低自动驾驶数据标注成本。
