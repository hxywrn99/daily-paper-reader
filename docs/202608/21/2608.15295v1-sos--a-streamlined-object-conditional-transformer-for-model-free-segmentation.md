## 摘要
基础分割模型擅长生成高质量、类不可知的掩码，但它们难以将这些提议与特定目标对象关联起来。这种语义鸿沟严重阻碍了它们在机器人操作等下游应用中的部署，这些应用需要精确的未见对象分割。现有方法试图通过依赖详尽的3D对象模型先验来解决这个问题，这固有地带来了高昂的计算开销和复杂的多阶段流水线。为了解决这些限制，我们提出了SOS（用于无模型分割的精简对象条件Transformer）。SOS完全消除了对3D模型的依赖，每个目标对象仅需一张参考图像。我们框架的核心是一种新颖的对象条件Transformer，它学习身份锚定查询，将掩码生成和目标识别统一到单次前向传播中。这种精简的设计极大地提高了结构和计算效率。在多个基准上的广泛评估表明，SOS在无模型未见对象分割方面建立了新的最先进水平，提供了准确且高效的性能。项目页面和代码可在https://sos-seg.github.io/获取。

## Abstract
Foundation segmentation models excel at generating high-quality, class-agnostic masks, but they struggle to associate these proposals with specific target objects. This semantic gap severely hinders their deployment in downstream applications like robotic manipulation, which demand precise unseen objects segmentation. Existing approaches attempt to resolve this by relying on exhaustive 3D object model priors, inherently introducing prohibitive computational overhead and complex, multi-stage pipelines. To address these limitations, we propose SOS (Streamlined Object-conditional Transformer for model-free Segmentation). SOS completely eliminates the reliance on 3D models, requiring only a single reference image per target object. Central to our framework is a novel Object-Conditional Transformer that learns identity-anchored queries, unifying mask generation and target identification into a single feed-forward pass. This streamlined design drastically improves both structural and computational efficiency. Extensive evaluations across multiple benchmarks demonstrate that SOS establishes a new state-of-the-art for model-free unseen objects segmentation, delivering accurate and high-efficiency performance. The project page and code are available at https://sos-seg.github.io/.

## 1. 论文的核心问题与整体含义

- **研究动机**：以 SAM 为代表的基础分割模型虽然能生成高质量的类别无关（class-agnostic）掩码，但无法将这些掩码与场景中特定的目标实例关联起来。这种"语义鸿沟"严重制约了机器人在操作、抓取等下游任务中的感知能力——这些任务要求对训练时未见过的新物体进行精确的实例级分割。
- **现有方法的缺陷**：
  - **模型驱动的两阶段流水线**（如 CNOS、SAM6D、MUSE、NIDS-Net）：先由 SAM 等模型生成掩码提议，再用 DINO 等描述子与 CAD 模型渲染的多视图模板进行特征匹配。该范式将定位和识别硬性解耦，引入启发式匹配误差，且渲染模板带来巨大的离线计算开销。
  - **模型驱动的单阶段方法**（如 OC-DiT）：以扩散模型直接预测掩码，但依然依赖密集的 3D CAD 多视图渲染，且迭代去噪导致严重推理延迟。
- **核心目标**：提出一种**完全无模型（model-free）**的解决方案，仅需每类目标一张参考图像即可完成未见对象的实例分割，消除 CAD 模型依赖和复杂多阶段流水线，同时保证精度和推理效率。

## 2. 方法论

### 2.1 核心思想
- 提出**身份锚定查询（Identity-Anchored Query）**范式：将 DETR 中"先生成类别无关提议、再分类"的解耦范式，转变为"参考身份注入 + 场景定位"统一推理的单阶段范式。
- 将参考图像视为显式视觉条件，通过**对象条件 Transformer（Object-Conditional Transformer）**，在一次前向传播中同时完成掩码生成与目标识别。

### 2.2 网络架构
- **特征编码器（Feature Encoder）**：
  - 使用冻结的 DINOv3-L/16 骨干网络提取场景特征图 \(F_s \in R^{h \times w \times d}\) 和条件特征图 \(F_c \in R^{N \times h' \times w' \times d}\)。
  - **场景嵌入器**：将场景特征展平为 token，并添加可学习的空间位置编码。
  - **条件嵌入器**：为条件 token 添加两类位置编码——空间位置编码（保持参考图内部布局）和身份编码（区分不同目标条件）。
- **对象条件 Transformer**：
  - 初始化：可学习的通用语义探针 \(q \in R^{1 \times d}\) 复制 \(N\) 份，生成与条件数量匹配的初始查询 \(Q \in R^{N \times d}\)。
  - 每个 block 内依次执行：
    1. **掩码交叉注意力（Masked Cross-Attention）** 与条件 token \(T_c\) 及其前景掩码 \(M_c\)：提取目标身份信息，防止条件间串扰；
    2. **掩码交叉注意力** 与场景 token \(T_s\)，由前一层生成的注意力掩码 \(A^{(l-1)}\) 限制注意力范围（首层全局关注）：实现空间定位并抑制干扰物；
    3. **自注意力（Self-Attention）**：解决多个目标重叠和遮挡问题；
    4. **前馈网络（FFN）**：输出精炼的身份锚定查询 \(\hat{Q}^{(l)}\)。
- **掩码解码器（Mask Decoder）**：
  - 每层后，查询经 MLP 与场景 token 做空间点积得到掩码 logits：\(P^{(l)} = \text{MLP}(\hat{Q}^{(l)}) \otimes T_s\)；
  - 经 sigmoid 和阈值二值化得到当前层掩码预测，并构造下一层的布尔注意力掩码；
  - 最后一层将 logits 上采样至原始图像分辨率，输出最终掩码。

### 2.3 训练目标
- 无需 DETR 的匈牙利匹配（因为查询与条件一一对应），直接使用 Mask2Former 风格的掩码损失（BCE + Dice）。
- 在 blocks 2、4、6、8 层施加深度监督，总损失为各层损失之和。

## 3. 实验设计

- **数据集/Benchmark**：BOP challenge 的四个核心数据集——YCB-Video（YCB-V）、TUD-L、LineMod Occlusion（LM-O）、HomebrewedDB（HB），共 65 个对象，覆盖有纹理/无纹理、对称/非对称、家庭/工业等多种属性。
- **评估指标**：COCO 风格的 Average Precision（AP），IoU 阈值 0.50–0.95。
- **对比方法**：
  - 模型驱动基线：CNOS、SAM6D、NIDS-Net、MUSE、OC-DiT（使用完整 CAD 模板）；
  - 单参考设置下：将 CNOS 和 SAM6D 适配为仅输入单张参考图像，使用与 SOS 完全相同的参考图进行公平对比。
- **训练数据**：FoundationPose 提供的大规模合成数据集（Objaverse + GSO，约 4.1 万物体，约 68 万场景），并采用几何/光度数据增强和动态条件采样（每个样本随机选取 1–20 个正负条件）。

## 6. 主要结论与发现

- **精度**：单参考设置下，SOS 平均 AP 达 **58.8**，较最强基线 SAM6D（47.6）绝对提升 **+11.2 AP**；在严重遮挡的 LM-O（50.3 AP）和 HB（65.6 AP）上超越所有模型驱动基线，创下新 SOTA。
- **效率**：推理延迟仅 **0.120 秒/图**，约为 CNOS（0.221s）的 1/2、MUSE（0.505s）的 1/4；且模型驱动的基线还需额外 18.82 秒/物体的离线模板渲染开销，SOS 将此成本降为零。
- **身份判别能力**：在真实场景中能区分高度相似的同类别干扰物（如豌豆罐头 vs 玉米罐头、特定洗涤剂瓶 vs 一排相似清洁用品）。
- **视角敏感性**：对称物体对参考视角变化鲁棒（波动仅 1.1 AP），非对称物体则较敏感（波动最大 16.0 AP），但总体平均精度波动不超过 3.1 AP。
- **视图扩展**：将参考视图从 1 个增加到 3–4 个即可达到饱和，显著早于基线方法所需的密集模板数。

## 7. 优点

1. **范式创新**：身份锚定查询将"分割一切"的类别无关提议与后续分类解耦的传统范式，改为条件驱动、直接输出身份感知掩码的统一流水线，在结构上消除了两阶段启发式匹配和扩散迭代去噪两大瓶颈。
2. **极简输入**：仅需单张参考图像，完全免除 CAD 模型获取、多视图渲染和模板特征提取等繁琐离线环节，大幅降低实际部署门槛。
3. **效率突出**：单次前馈推理，20 FPS（单条件）/10 FPS（10 条件），GPU 内存占用低，适合实时机器人应用。
4. **无需匈牙利匹配**：由于查询天然与条件锚定，无需 DETR 系列的二部图匹配，简化了训练流程。
5. **训练设定务实**：动态条件采样（1–20 个正负条件）使模型天然支持多目标并行处理和负条件（目标不存在时输出空掩码）场景。

## 8. 不足与局限

- **单实例假设**：论文明确承认，模型假设每个参考条件在场景中至多对应一个目标实例，**无法处理同一查询图像中出现多个相同目标实例的情况**。限制源于现有训练数据缺乏多实例标注。
- **非对称物体对视角敏感**：当参考视角不能展现目标的关键几何特征时，非对称物体的分割精度显著下降（最大波动 16.0 AP），对用户提供的参考图像质量有一定依赖。
- **合成训练域**：模型仅在 Objaverse/GSO 的合成渲染数据上训练，虽然真实场景定性实验表现良好，但未提供量化评估以验证合成到真实的域差距。
- **应用范围局限**：实验仅聚焦刚性物体（BOP 基准），对可变形物体（如布料、食物）的适用性未做探讨；对遮挡的定量分析仅限 LM-O 数据集。
- **公平对比的边界**：与模型驱动基线进行单参考对比时，基线方法本身是为多模板设计的两阶段框架，强行使之适配单视角可能无法完全体现其算法潜力；而全模型对比（SOS vs CNOS 完整版）在部分数据集上仍有差距（如 YCB-V 和 TUD-L）。
