## 摘要
现代深度学习架构在牙科 CBCT 分割中展现出了强大的性能。一个仍然关键的挑战是在缺失或错位牙齿的病例中进行准确的牙齿标注，这与牙科实践高度相关。基于 Transformer 的架构理论上应能利用全局解剖上下文来解决此类歧义。然而，由于 CBCT 体积的高分辨率以及牙齿在体积内的广泛空间分布，基于密集补丁的体积处理面临固有的权衡。计算成本限制了可用于自注意力的补丁数量，因此，要么增加自注意力中捕获的上下文范围，要么通过使用小补丁来捕获细粒度的结构细节，但两者不可兼得。在这项工作中，我们提出了 Teeth2Point，一种基于点的高效 Transformer 框架，用于牙科 CBCT 语义分割，可以避免这种权衡。Teeth2Point 首先使用卷积模型定位牙齿周围的体积感兴趣区域（ROI），然后通过自适应采样将 ROI 转换为点标记。Transformer 模型使用点标记预测精确的分割，这允许在保持高分辨率的同时捕获全局上下文。该 Transformer 首先使用自监督学习（SSL）进行预训练，采用 DINO 风格但使用特定领域的增强策略，然后进行监督微调。SSL 预训练包括随机标记掩蔽，提供了对复杂解剖变异的鲁棒性。与最强的两阶段基线相比，Teeth2Point 在四个数据集上将异常病例的性能平均提高了 1.44 个 DSC 点；相对于第一阶段的 nnU-Net，增益为 1.9 个点。

## Abstract
Modern deep learning architectures have demonstrated strong performance in dental CBCT segmentation. One remaining crucial challenge is accurate tooth labeling in cases with missing or malpositioned teeth, which are highly relevant for dental practice. Transformer-based architectures should in theory be able to resolve such ambiguities using global anatomical context. However, due to the high resolution of CBCT volumes and the wide spatial distribution of teeth within volumes, dense patch-based volumetric processing faces an inherent trade-off. Computational costs limit the number of patches that can be used in self-attention and thus, one can either increase the extent of the context captured in self-attention or capture fine-grained structural details by using small patches, but not both. In this work, we present Teeth2Point, an efficient point-based transformer framework for dental CBCT semantic segmentation that can avoid this trade-off. Teeth2Point first localizes volumetric regions of interest (ROIs) surrounding teeth using a convolutional model, then converts ROIs into point tokens using adaptive sampling. A transformer model predicts accurate segmentations using the point tokens, which allow capturing global context while retaining high resolution. The transformer is first pretrained using self-supervised learning (SSL), in the style of DINO but using domain-specific augmentation strategies, followed by supervised finetuning. The SSL pretraining, which includes random token masking, provides robustness to complex anatomical variations. Compared with the strongest two-stage baseline, Teeth2Point improves abnormal-case performance by 1.44 DSC points on average across four datasets; relative to the first-stage nnU-Net, the gain is 1.9 points.

## 1. 论文的核心问题与整体含义

- **研究背景**：牙科 CBCT 分割是定量分析与治疗规划的重要步骤，深度学习模型在该任务上已取得较好效果。但临床实践中常存在**牙齿缺失或错位**等异常病例，此时仅靠局部外观难以准确标注每颗牙齿，需要借助全局解剖上下文（如左右对称、上下颌咬合关系）来消除歧义。
- **核心问题**：CBCT 体积分辨率高、牙齿在体积中分布稀疏且分散，导致传统**密集体素/补丁式**处理方法面临固有矛盾：
  - 扩大自注意力上下文范围 → 需要降采样或增大补丁，损失边界细节；
  - 保留精细结构 → 必须使用小补丁，无法建模长程解剖关系；
  - 两者难以兼得，计算成本过高。
- **本文含义**：提出 **Teeth2Point**，一种两阶段“ROI 到点”分割框架，通过将 ROI 转化为点云表示并利用 Transformer 建模，**在保持高分辨率的同时捕获全局上下文**，从而提升异常病例的牙齿实例级分割精度。

## 2. 论文提出的方法论

### 2.1 总体流程（两阶段）
1. **第一阶段：ROI 提取**
   - 使用卷积模型（nnU-Net）对完整 CBCT 体积进行初始分割，得到牙齿前景掩膜。
   - 对前景掩膜进行 3D 6-连通膨胀，得到扩展后的 ROI（包含少量背景边界）。
   - 收集 ROI 内的所有体素作为点集。
2. **第二阶段：点级分割**
   - 对 ROI 点云进行**自适应采样**（GGAS），降低计算量并聚焦边界区域。
   - 将采样后的点转换为点标记（token），输入基于 Transformer 的点云分割网络。
   - 输出点级预测后，通过 K 近邻插值传播到未采样点，并体素化回体积空间。

### 2.2 点表示与特征
- 每个点 `x_i` 由三部分特征组成：
  - 体素坐标 `c_i ∈ R³`；
  - 归一化 CT 强度 `I_i`（截断至 [-1000, 3512]，全局 z-score 归一化）；
  - 强度梯度向量 `g_i`。

### 2.3 Gradient-Guided Adaptive Sampling（GGAS）
- 动机：分割关键判别信息集中在结构边界附近。
- 方法：
  1. 计算所有 ROI 点的梯度幅值，进行 min-max 归一化；
  2. 将空间划分为粗网格（每格 `ε³` 个体素）；
  3. 在每格内统计梯度幅值的直方图（固定 bin 宽度 `α`）；
  4. 对每个非空 bin 以正比于梯度幅值的概率采样 1 个点。
- 效果：在高梯度变化区域（边界）分配更多点，在均匀区域每格只采样少量点，实现自适应稀疏化。

### 2.4 Transformer 架构
- 线性嵌入层将点属性映射为 token；
- 采用编码器-解码器结构（借鉴 Point Transformer v3 等），包含空间池化（体素内最大特征池化）与反池化（最近邻插值），配合跳跃连接实现多级特征融合。

### 2.5 自监督预训练（DINOv2 风格）
- 采用学生-教师自蒸馏框架：学生网络 `θ_s` 学习匹配 EMA 教师网络 `θ_t` 的输出。
- 构造局部视图与全局视图，使用域特定的强度与空间增广（随机旋转、弹性变换等）。
- **点级蒸馏**：将学生局部视图特征与其在全局视图中的最近邻特征配对，计算 KL 散度作为损失。
- 使用 Sinkhorn-Knopp 中心化和聚类分配归一化防止表示坍缩。
- **掩蔽预测**：随机掩蔽部分点（掩蔽比例从 0.3 逐步增至 0.7），插入可学习的掩蔽 token，要求学生预测被掩蔽点的特征，增强上下文建模与鲁棒性。

### 2.6 域特定增广
- 常规强度增广：gamma 校正、亮度缩放。
- **对称性增广**：水平翻转点云并重映射牙齿标签，利用双侧对称结构。
- **伪影增广**：随机选取某类牙齿，增强其相关点强度，模拟金属伪影。

### 2.7 渐进式微调
- 第一阶段：在 GT ROI 标注的前景点上进行微调（仅前景标签）。
- 第二阶段：在预测 ROI 上进行微调（包含背景和不完整结构标签），使模型适应第一阶段的误差。
- 损失函数为 Dice Loss 与交叉熵损失的加权和。

### 2.8 推理
- 第一阶段滑动窗口推断得到 ROI；
- 第二阶段单次前向传播，输出点级预测并体素化，ROI 外的体素直接沿用第一阶段背景标签。

## 3. 实验设计

### 3.1 数据集与 Benchmark
- **STS2024**（27 个样本，异常占比 82.5%）
- **ToothFairy2**（480 个样本，异常占比 80.8%）
- **ToothFairy3**（532 个样本，异常占比 23.1%）
- **内部数据集**（1170 个样本，异常占比 9.0%）
- 所有体积重采样至 0.3 mm 各向同性分辨率。
- 评价指标：Dice Similarity Coefficient（DSC），并区分 **DSC-R（常规病例）** 与 **DSC-A（异常病例）**。

### 3.2 对比方法
- 全体积单阶段方法：nnU-Net、ToothSeg、MedNeXt、VideoTeeth、U-Mamba1、U-Mamba2。
- ROI 裁剪两阶段方法：ROI-cropped nnU-Net、Point-UNet。
- 同样采用 70/30 训练/测试划分，并使用小成分移除后处理。

### 3.3 主要结果
- Teeth2Point 在 DSC-A（异常病例）上取得最优平均结果，比最强 ROI 裁剪基线提升 **1.44 DSC 点**。
- 相比第一阶段 nnU-Net：DSC-R 提升 0.6 点，DSC-A 提升 1.9 点，常规-异常差距缩小约 26%。
- 推理效率：第二阶段单次前向仅 0.9 秒，完整流程约 13.7 秒。

## 6. 主要结论

- 点基 Transformer 结合自监督预训练可有效规避 CBCT 分割中“全局上下文 vs 高分辨率”的权衡。
- Teeth2Point 在缺失/错位等异常病例上的分割精度显著优于当前最强基线，同时保持高效推理。
- 自监督预训练（DINOv2 风格 + 随机掩蔽）能捕获解剖对称性和上下颌关系，提升标签效率——仅用 10 个标注样本即可达到 86.7 DSC，接近从头训练 100 个样本的水平。
- 渐进式微调（GT-ROI → 预测 ROI）能有效补偿第一阶段 ROI 提取误差，防止性能大幅下降。

## 7. 优点

- **方法设计新颖**：将两阶段粗到精与点云 Transformer 结合，合理利用牙齿稀疏性。
- **GGAS 采样策略**：根据梯度分布自适应分配点数，在保持边界细节的同时降低计算量。
- **域特定自监督预训练**：对称性增广与伪影增广贴近牙科临床场景，掩蔽预测增强上下文建模。
- **渐进式微调**：设计周到，缓解训练-推理 ROI 不一致问题。
- **结果全面**：在多个数据集、异常/常规病例、效率、标签效率、消融与可视化方面均有报告，验证较为充分。
