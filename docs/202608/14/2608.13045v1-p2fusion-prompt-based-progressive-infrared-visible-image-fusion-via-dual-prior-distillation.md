## 摘要
红外-可见光图像融合（IVIF）对多模态感知至关重要，但协调热特征与纹理特征之间的固有信息差异仍是一个基本挑战。现有的先验引导方法通常依赖静态约束，这会引发优化冲突，或者利用来自大规模基础模型（如CLIP/DINO）的外部语义先验，而这些方法往往无法利用对高保真融合至关重要的内在模态特征。为解决这些问题，我们提出了P2Fusion，一种基于先验引导蒸馏的框架，通过双内在提示重塑IVIF。我们不是施加硬编码惩罚，而是将图像内在先验、热显著性和空间质量蒸馏到可学习的动态调节器中。具体而言，一种“教到融合”机制提供双粒度的渐进式指导，并配合门控动态专家重校准（GDER）模块实现解耦特征细化。这种设计使网络能够通过专家特化自适应地调节模态竞争。大量实验表明，P2Fusion在五个主流数据集上实现了最先进的性能。值得注意的是，我们的框架在融合质量方面表现出持续的性能优势，在5个基准的20个关键评估指标中的14个上取得了最先进的结果。此外，它有效提高了下游感知的鲁棒性，例如在MSRS上目标检测的mAP提高了3.2%，在M3FD上提高了0.5%，在DroneVehicle上提高了0.9%。我们的代码将在 https://github.com/YiShi99/P2Fusion 上公开。

## Abstract
Infrared-visible image fusion (IVIF) is pivotal for multimodal perception, yet reconciling the inherent information disparity between thermal and textural features remains a fundamental challenge. Existing prior-guided methods often rely on static constraints that induce optimization conflicts or utilize extrinsic semantic priors from large-scale foundation models (e.g., CLIP/DINO), which frequently fail to exploit the intrinsic modality characteristics essential for high-fidelity fusion. To address these issues, we propose P2Fusion, a prior-guided distillation-based framework that reformulates IVIF via dual intrinsic prompts. Instead of imposing hard-coded penalties, we distill image-intrinsic priors, thermal saliency and spatial quality, into learnable dynamic regulators. Specifically, a Teach-to-Fuse mechanism provides dual-granularity progressive guidance, coupled with a Gated Dynamic Expert Recalibration (GDER) module for decoupled feature refinement. This design enables the network to adaptively mediate modal competition through expert specialization. Extensive experiments demonstrate that P2Fusion achieves state-of-the-art performance across five mainstream datasets. Notably, our framework demonstrates consistent performance advantages in fusion quality, achieving state-of-the-art results in 14 out of 20 key evaluation metrics across 5 benchmarks. Furthermore, it effectively contributes to the robustness of downstream perception, such as +3.2% mAP on MSRS, +0.5% mAP on M3FD and +0.9% mAP on DroneVehicle for object detection. Our code will be available at https://github.com/YiShi99/P2Fusion

### 一、核心问题与整体含义（研究动机与背景）

红外-可见光图像融合（IVIF）旨在整合热辐射信息与可见光纹理细节，是多模态感知领域的关键基础任务，广泛应用于自动驾驶、目标再识别和医学影像等场景。由于缺乏成对的真实融合标签，该任务本质上是无监督生成任务，其性能高度依赖网络架构和损失函数的启发式设计。

论文指出现有先验引导方法存在三条技术路线的根本性瓶颈：

- **显式硬约束路线**（如STDFusionNet）：将分割掩码或显著图作为静态正则项，迫使网络优先拟合先验分布而非像素级特征融合，导致细粒度纹理被牺牲。
- **下游任务联合优化路线**（如TarDal）：引入目标检测或分割作为辅助任务，但多目标优化易产生冲突，在视觉质量与任务精度之间形成持久折中。
- **外部语义先验路线**（如SAGE、CMFS）：借用CLIP/DINO等基础模型的高层语义，但其抽象表征与像素级融合任务存在粒度不匹配，无法精确指导底层纹理重建。

**核心立意**：论文主张先验知识应源于数据本身且具备动态性，提出"教到融合"（Teach-to-Fuse）范式，将图像内在的物理先验（热显著性、空间质量）蒸馏为可学习的动态调节器，以替代静态约束和外部语义先验，实现自适应模态竞争调解。

### 二、方法论：核心思想与关键技术

#### 2.1 核心思想：双内在提示蒸馏

论文选取两个互补的内在先验作为验证实例，而非追求"最佳"理论教师，框架具有先验无关性，可扩展至深度、语义等其他辅助线索：

| 先验 | 来源 | 角色 |
|------|------|------|
| **红外热显著性先验（T_ir）** | SegFormer-B2在MSRS和FMB数据集上预训练，作为红外显著性教师（IST），行人/车辆为前景，其余为背景，经二值化处理生成显著图 | 定位高辐射目标（行人、车辆） |
| **可见光空间质量先验（T_vis）** | 基于BRISQUE无参考质量评估器的可见光质量教师（VQT），得分标准化为T_vis = (100−s)/100 | 评估纹理可靠性，标识欠曝/过曝区域 |

先验通过蒸馏损失（MSE和BCE）注入网络，特征经元素级求和增强：F_m = f_m + Embed(P_m)，而非作为刚性空间约束。

#### 2.2 GDER模块：门控动态专家重校准

这是融合架构的核心组件，不同于传统MoE的容量扩展目的，GDER专注于**特征解耦与自矫正**：

- **先验响应模态专家（E_mod）**：显式消费动态提示，强化模态特有显著性信息（热目标、高对比纹理），确保先验知识有效注入。
- **先验无关注意力专家（E_att）**：独立于提示运行，利用CBAM全局注意力挖掘内在长程依赖和细粒度结构细节，补偿先验焦点之外的纹理完整性。

门控网络G(·)计算动态权重w = softmax(G(F′, P))，精炼特征表示为：
**F′′ = F′ + w₁·E_mod(F′) + w₂·E_att(F′)**

该机制实现多视角互补的自适应特征细化：专家共识时协同增强，分歧时门控平衡，实现"柔性的动态调节而非刚性约束"。

#### 2.3 优化目标

总损失包含三类约束：

- **感知约束**：梯度损失（边缘保持）、强度损失（热/纹理信息平衡）、SSIM损失（结构一致性，权重根据各模态平均梯度幅值自适应计算）
