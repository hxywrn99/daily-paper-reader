## 摘要
我们提出了DOME-HDR，一种双输出多曝光HDR重建框架，通过增益图逆色调映射联合生成感知平衡的SDR图像和一致的HDR图像。给定三个包围式LDR输入，DOME-HDR首先使用LoRA适配的潜在扩散模型合成基础SDR。双交叉注意力融合模块从欠曝光和过曝光图像中注入互补的结构和颜色线索，同时以中间曝光为锚点以保持稳定性。然后，合成的SDR引导我们的HDR先验引导增益图网络HPGM预测空间变化的增益图，以实现可靠的动态范围扩展。我们在Kalantari、Tel和Challenge123上使用全参考和无参考指标进行评估，DOME-HDR取得了最先进的HDR重建质量；消融研究进一步证实了双交叉注意力和SDR引导增益图估计的有效性。

## Abstract
We propose DOME-HDR, a dual-output multi-exposure HDR reconstruction framework that jointly produces a perceptually balanced SDR image and a consistent HDR image via gain map inverse tone mapping. Given three bracketed LDR inputs, DOME-HDR first synthesizes a base SDR using a LoRA-adapted latent diffusion model. A dual cross-attention fusion module injects complementary structural and color cues from the under- and over-exposed images while anchoring on the mid exposure for stability. The synthesized SDR then guides HPGM, our HDR Prior-guided Gain Map network, to predict a spatially varying gain map for reliable dynamic-range expansion. We evaluate on Kalantari, Tel, and Challenge123 using both full-reference and no-reference metrics, where DOME-HDR achieves state-of-the-art HDR reconstruction quality; ablations further confirm the effectiveness of dual cross-attention and SDR-guided gain map estimation.

## 论文详细总结

### 1. 核心问题与整体含义（研究动机与背景）

- 自然场景的动态范围远超常规 SDR 成像系统的捕获与显示能力，多曝光融合（MEF）与 HDR 重建是两种主要的动态范围扩展策略，但二者目标不同、彼此割裂：
  - **MEF** 生成感知上均衡的 SDR 图像，但不恢复真实辐射度；
  - **HDR 重建** 直接预测线性域 HDR 辐射度，但需要后续色调映射才能显示，最终观感依赖色调映射算子与显示设备，且需要额外的 HDR 域生成模型适配；
  - **增益图逆色调映射（GM-ITM）** 通过预测 SDR 与 HDR 之间的乘性残差来重建 HDR，其前提是输入 SDR 质量足够好；如果 SDR 存在过曝或饱和，信息已不可逆丢失，增益图无法补全内容。

- 论文强调，现有方法各自输出单一模态，没有一个框架能同时给出**感知均衡的 SDR**和**一致的 HDR**。为此提出 DOME-HDR，将 SDR 融合与基于增益图的 HDR 重建统一到一个联合优化的双输出框架中。

### 2. 方法论

#### 核心思想
- 将问题解耦为两个互补阶段：**先合成高质量基础 SDR**，再**基于该 SDR 预测增益图**，从而同时获得 SDR 输出与 HDR 输出，且两者共享优化过程，避免级联带来的误差传播。

#### Stage 1：基础 SDR 合成（LoRA 适配的潜在扩散模型）
- 基于 UltraFusion，将其扩展为三曝光输入，以中间曝光 `I_me` 为结构锚点。
- **双交叉注意力融合**：从欠曝 `I_ue` 与过曝 `I_oe` 分别提取结构/颜色引导特征，通过两个独立交叉注意力分支注入中间曝光的潜表示，避免简单求和导致的信息损失。公式：
  `X_out = X_me + Conv_1x1( softmax( Q K^T / τ ) V )`
  其中 Q 来自中间曝光潜特征，K、V 来自各自曝光引导特征。
- 训练时仅用 LoRA 适配交叉注意力中的 `to_q, to_v`（秩 8），U-Net 与 VAE 冻结。

#### Stage 2：增益图估计与逆色调映射（HPGM）
- **HDR 先验构造**：
  - 对三张输入做 γ=2.2 伽马解码与曝光归一化：`X_k = I_k^γ / 2^{ev_k}`；
  - 计算交叉曝光比 `R_ue = X_ue / X_me`，`R_oe = X_oe / X_me`；
  - 用 sigmoid 生成高光/阴影软掩膜 `S_hi`、`S_lo`；
  - 合成饱和度感知的线性 HDR 估计：`I_prior_hdr = S_hi · X_ue + (1 - S_hi - S_lo) · X_me + S_lo · X_oe`；
  - 先验增益图 `G_prior = log(I_prior_hdr + ε) / log(SDR + ε)`。
- **HPGM 网络**：U-Net，输入为 11 通道（SDR、两个曝光比、两个掩膜）。瓶颈处注入由 `G_prior` 与掩膜编码得到的先验特征；解码器使用 Sobel 边缘引导的上采样块以锐化边界；两个预测头分别输出增益图残差 `Δg` 和全局 HDR 尺度 `Q_max`。
- 重建公式：`I_hdr = (SDR + ε)^{g_hat} · Q_max - ε`，其中 `g_hat = G_prior + Δg`。

#### 训练损失与策略
- 图像级损失：μ-law（μ=5000）下的 L1 + VGG19 感知损失（权重 0.01）；
- 增益级损失：Charbonnier 损失（增益图）+ 1 范数约束全局尺度（权重 0.3）；
- **两阶段训练**：Phase 1 联合训练扩散模块（LoRA）与 HPGM 30k 迭代；Phase 2 用 Phase 1 生成的 MEF 输出作为 SDR 输入，继续优化 HPGM 30k 迭代，以缩小训练/推理域 gap。

### 6. 主要结论与发现

- DOME-HDR 在 HDR 重建的全参考与无参考指标上均达到 SOTA（如表 1：PU-PSNR 44.63、PU-SSIM 0.9878、LPIPS 0.0156、DISTS 0.0147、CLIPIQA 0.4137、NIQE 3.56、BRISQUE 22.18），全面优于 AFUNet 等最强基线；
- 在 SDR 融合质量上与专用 MEF 方法相当或更好（表 2：MANIQA 0.4129、CLIPIQA 0.5233、BRISQUE 16.52），同时额外获得 HDR 输出；
- 级联 UltraFusion+GMNet 效果很差（PU-PSNR 仅 22.96），说明联合优化是必要的；
- 双交叉注意力分支优于特征求和；完整三曝光输入显著优于部分输入；两阶段训练中 Phase 1+2 组合最优；
- 直接输出的 SDR 比 HDR 经任意色调映射算子得到的结果在无参考质量上更稳定、更优（CLIPIQA 0.4984 vs. 0.35~0.40 区间），证明双输出设计的实用价值。

### 7. 优点

- **统一框架、双输出**：一个框架同时产出感知均衡 SDR、增益图与 HDR，桥接了 MEF、HDR 重建和 GM-ITM 三个方向，实用性强；
- **联合优化设计**：SDR 合成与增益图估计端到端联合训练，避免级联误差传播，设计思路清晰；
- **双交叉注意力**：针对性解决多曝光特征融合中的信息丢失问题，比简单求和更有效；
- **HDR 先验引导**：利用输入曝光堆栈构造饱和感知的物理先验，并用残差形式预测增益图，降低学习难度、提高稳定性；
- **逐像素全局尺度建模**：引入全局 HDR 尺度 `Q_max`，兼顾局部增益与整体亮度范围；
- **两阶段训练策略**：减少训练与推理时 SDR 输入分布不一致导致的性能下降，具有很强的工程方法论意义；
- **直接输出 SDR 的显示一致性**：避免了 HDR 经色调映射后视觉质量随算子漂移的问题，评估视角新颖。

### 8. 不足与局限

- **实验形式局限**：只有合并数据集汇总指标，缺少各数据集单独结果；无统计检验，难以判断指标差异的可靠性；
- **对比范围不足**：未直接比较独立 GM-ITM 方法（如 Gain-MLP、Gmodiff），也没有与最新的 MEF 与 HDR 重建方法之外的更广泛基线对比；
- **训练成本报告不完整**：仅给出 GPU 型号与迭代数，未说明总训练时长、batch size、显存/能耗等，可复现性受限；
- **HDR 先验依赖启发式参数**：阈值（0.95/0.05）与 sigmoid 尖锐度 α=50 为固定值，可能在不同光照分布或极端场景下不鲁棒；
- **未明确讨论运动对齐/去鬼影**：虽然使用了含动态场景的数据集，但论文未说明框架如何处理大位移或遮挡，扩散模型的交叉注意力是否能隐式对齐仍缺乏专门分析；
- **潜在部署成本**：基于潜在扩散模型的 SDR 合成计算开销较大，对实时或移动端应用不友好；
- **应用范围局限**：增益图框架假设 SDR 能提供基本结构信息，若输入严重欠曝/过曝且缺乏可用的多曝光信息，先前验也可能失效；此外，论文未评估真实显示设备上的端到端主观体验。
