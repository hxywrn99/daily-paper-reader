## 摘要
在极端光照条件下实现可靠的单次高动态范围（HDR）成像仍然是一个长期挑战，然而目前尚无全面的基准来评估多传感器机器人系统中的HDR感知。为填补这一空白，我们通过定制的机器人视觉平台和iPhone 13 Pro引入了一个大规模数据集：涵盖121个真实世界场景，覆盖中等和超高动态范围条件，以及来自CARLA模拟器的20个合成视频序列。作为该数据集的参考流程，我们提出了深度引导的多视角曝光包围（DMEB），这是一种单次HDR方法，将差异极大的曝光分布到多视角低比特深度相机上，并通过深度引导的置信度感知融合进行融合。在我们数据集上的评估表明，DMEB建立了一个强有力的参考点，并突显了该传感器配置在多种相机和深度传感器系统中实现鲁棒HDR感知的潜力。

## Abstract
Achieving reliable single-shot high dynamic range (HDR) imaging under extreme illumination conditions remains a long-standing challenge, yet no comprehensive benchmark exist for evaluating HDR perception in multi-sensor robotic systems. To fill this gap, we introduce a large-scale dataset collected via a custom robotic vision platform and an iPhone 13 Pro: 121 real-world scenes spanning modest and ultra-high dynamic range conditions, alongside 20 synthetic video sequences from the CARLA simulator. As a reference pipeline for this dataset, we propose Depth-guided Multi-view Exposure Bracketing (DMEB), a single-shot HDR method that distributes drastically different exposures across multi-view low-bit-depth cameras and fuses them via depth-guided confidence-aware fusion. Evaluations on our dataset show that DMEB establishes a strong reference point and highlight the promise of this sensor configuration for robust HDR perception in diverse multi-camera and depth sensor system.

## 1. 核心问题与整体含义

现代机器人平台普遍搭载多相机与深度传感器，但在极端光照条件下实现可靠的单次高动态范围（HDR）感知仍面临巨大挑战。现有的主流方案——时间曝光包围（Temporal Exposure Bracketing）——对动态场景会产生运动伪影，而常用的光流对齐方法要求各帧曝光量相近，严重限制了可恢复的动态范围。另一方面，专用的高比特深度HDR传感器成本高昂，难以大规模部署。

此前的相关研究虽有过利用多相机分发不同曝光的尝试，但都因为需要依赖光度一致性进行图像对齐，被迫限制了相机间的曝光差异，导致动态范围扩展有限。更关键的是，**学术界始终缺乏一个"多视角变曝光 + 对齐深度"的公开基准数据集**，使得多传感器HDR成像这一方向难以被系统性地评估与推动。

本文正是基于这一空白，提出：利用机器人平台已有的**多视角低比特相机与外部深度传感器**，将极端不同的曝光同时分配给不同相机，以深度信息替代光度匹配进行跨视角对齐，实现**单次拍摄**下的高动态范围重建。整体含义在于：为多传感器机器人HDR感知提供了一套**完整的数据集基准 + 参考算法管线**，开启了以"空间曝光分配取代时间曝光包围"的新范式。

## 2. 方法论

本文提出的 DMEB（Depth-guided Multi-view Exposure Bracketing，深度引导的多视角曝光包围）方法，核心流程包括三个步骤：

### 2.1 多视角曝光控制
- 根据上一帧多视角图像的亮度统计，确定当前帧各相机的曝光设置，使各相机分别覆盖动态范围的不同亮度区间。
- 目标平均强度 **mᵢ** 在对数域上按几何级数分布在 **m₁ = 0.05**（低亮度）到 **m_N = 0.8**（高亮度）之间：
  ```
  log mᵢ = log m₁ + ((i-1)/(N-1)) · (log m_N - log m₁)
  ```
- 曝光值受硬件上下限裁剪，并进一步转换为曝光时间 τ 与增益 g：
  ```
  τᵢ = min(ξᵢ, τ_max)，gᵢ = max(1, min(g_max, ξᵢ/τᵢ))
  ```

### 2.2 稠密深度估计与置信度计算
- 将深度传感器获取的稀疏深度（LiDAR 或主动立体）分别投影到各相机视角，获得逐相机深度图。
- 利用预训练单目深度先验（Depth Anything V2）估计稠密深度，并通过稀疏深度进行尺度校准，保留度量尺度。
- 计算每个像素的置信度，用于在融合阶段降低饱和、欠曝噪声以及遮挡等不可靠测量带来的影响：
  ```
  Cᵢ = f_trapezoid(Iᵢ) · f_CNN(Iᵢ, D̂ᵢ)
  ```

### 2.3 深度引导的置信度感知融合
- 将各源视角的图像、深度和置信度通过参考视角的稠密深度**几何投影**到参考视角。
- 融合后的 HDR 图像与深度为：
  ```
  Ḋₜ = (Σᵢ Cᵢ→ₜ D̂ᵢ→ₜ) / (Σᵢ Cᵢ→ₜ + ε)
  Hₜ = (Σᵢ Cᵢ→ₜ Vᵢ→ₜ Iᵢ→ₜ / (τᵢ gᵢ)) / (Σᵢ Cᵢ→ₜ Vᵢ→ₜ + ε)
  ```
  其中 Vᵢ→ₜ 是软可见性掩码，基于深度一致性计算：
  ```
  Vᵢ→ₜ = σ( (Ḋₜ + δ − D̂ᵢ→ₜ) / (τ_rel · (Ḋₜ + ε)) ) + w_floor
  ```

### 2.4 细化与训练
- 将融合的 HDR 结果以三个不同 μ 值的 μ-law tone mapper 映射到色调映射域（μ = 10³, 5×10⁴, 10⁶），随后通过一个 transformer 网络进行细化，再转换回线性域。
- 训练包含置信度网络与细化网络两部分；先在 40k 合成场景上预训练 50 epoch，后在 10k 真实场景上微调 10 epoch。损失函数包括 HDR 的 ℓ1 损失、SSIM、梯度损失，以及深度估计的 ℓ1 + SILog 损失。

## 6. 主要结论与发现

1. **多视角单次曝光 > 时序多次曝光**：将曝光从时间维度转移到空间维度（多相机），仅改变输入配置就可以给现有方法带来稳定的性能提升（如 HDRTransformer PSNR-μ 从 31.26 dB 提升至 33.61 dB）。
2. **深度引导是核心**：DMEB 使用多视角 LiDAR 融合深度时（39.40 dB）明显优于光流引导（35.84 dB），甚至在光流完全失效的情况下（大曝光差），深度依然能提供可靠对齐。
3. **相机数量的增加有效扩展动态范围**：从 N=3 到 N=8，动态范围持续扩展，SSIM 保持稳定；N=3 时高亮光源仍饱和，N=8 时能恢复灯源内部细节。
4. **在极端动态范围（150 dB+）下依然鲁棒**：合成基准中 DMEB 的 PSNR-μ 为 34.72 dB，超过所有对比方法，且无伪影/鬼影。
5. **下游感知受益**：更好的 HDR 重建直接转化为更优的目标检测性能（召回率 0.83 vs 对比方法的 0.78/0.81；F1 0.73 vs 0.63/0.67），尤其在强光源眩光场景中意义显著。
6. **泛化能力强**：零样本迁移到 iPhone 和外部两视角数据集仍取得最优结果。

## 8. 不足与局限

1. **依赖视场重叠**：所有多视角相机和深度传感器必须拥有重叠视场才能进行融合，这限制了系统的适用场景（如广域分布式的多相机配置将无法使用本方法）；
2. **深度传感器性能成为天花板**：在深度缺失或深度噪声较大的区域（如远距离、低反射率物体、透明/反光表面），融合质量会直接受影响；论文未讨论深度失败情况下的鲁棒性；
3. **实验环境仍然有限**：真实数据集主要在室内/园区环境采集，未涉及极端户外光照或恶劣天气（雨、雾、雪）条件；
4. **评估偏重指标而非任务**：虽然做了目标检测验证，但对更广泛的下游任务（如 3D 检测、语义分割、SLAM）未展开评估；
5. **未报告训练算力成本**：细化网络使用 transformer 结构，在 40k+10k 样本上训练的计算开销未被披露，可复现性方面打了折扣；
6. **零样本泛化验证的覆盖面有限**：外部数据集仅验证了两视角立体 HDR 场景，对三视角、不同深度传感器类型（如 ToF）的迁移效果未知；
7. **"单次拍摄"的前提条件**：严格来说需要所有相机被同步触发，这对大多数现有机器人平台的硬件同步能力提出了一定要求；此外，各相机之间的基线距离若过大，会导致遮挡区域增多，融合权重下降。
