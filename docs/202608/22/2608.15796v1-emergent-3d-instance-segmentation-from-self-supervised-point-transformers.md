## 摘要
室外LiDAR扫描的无监督3D实例分割传统上依赖于手工设计的几何先验，如基于密度的聚类、运动线索或投影2D检测。在本工作中，我们研究冻结的自监督点云Transformer是否已包含分离对象实例所需的结构信息，而无需任何手工几何先验。仅将其用作特征提取器，我们跨SemanticKITTI、nuScenes和Waymo Perception数据集探测其内部表示。我们的分析得出四个核心见解：(1) 实例信号集中在注意力查询和键中，而非值或最终输出特征中；(2) 输出特征在语义上发生坍缩，将查询和键保持区分的相邻同类对象合并；(3) 该实例信号在深度上是双峰的，在编码器最浅和最深阶段最强；(4) 该信号主要由旋转位置编码(RoPE)驱动，去除它会使其优势消失。我们将这些发现应用于我们的方法TokenGraph3D——一种无需训练的分割器，通过键相似性图上的连通分量对点进行分组，既不使用基于密度的聚类，也不使用邻近性先验。在相同的无先验条件下，我们大幅优于输出特征基线，使涌现的3D实例结构可见。

## Abstract
Unsupervised 3D instance segmentation of outdoor LiDAR scans has traditionally relied on handcrafted geometric priors such as density-based clustering, motion cues, or projected 2D detections. In this work, we investigate whether a frozen, self-supervised point transformer already contains the structural information required to isolate object instances without any handcrafted geometric prior. Using this transformer purely as a feature extractor, we probe its internal representations across the SemanticKITTI, nuScenes, and Waymo Perception datasets. Our analysis yields four core insights: (1) the instance signal concentrates in the attention queries and keys rather than in the values or final output features; (2) output features semantically collapse, merging adjacent same-class objects that the queries and keys keep distinct; (3) this instance signal is bimodal in depth, strongest at the shallowest and deepest encoder stages; and (4) this signal is driven predominantly by the rotary position encoding (RoPE), whose removal collapses its advantage. We put these findings into our method TokenGraph3D, a training-free segmenter that groups points via connected components on a key-similarity graph, using neither density-based clustering nor proximity priors. Under identical prior-free conditions, we substantially outperform output-feature baselines, making the emergent 3D instance structure visible.

## 6. 主要结论与发现

- **四大发现**：
  1. 实例信号集中在注意力查询和键中，而值（values）和最终输出特征都很弱；在所有阶段和数据集上，query/key 的 seed-IoU 显著高于输出特征（平均超过 0.10）。
  2. 输出特征在大物体上发生语义坍缩，会合并相邻同类对象；相较之下，注意键在物体由小到大时几乎保持稳定的判别力。
  3. 实例信号在编码器深度上是双峰分布：最浅（enc0）和最深层（enc4）最强，中间阶段（如 enc3）明显更弱。
  4. 该信号主要由旋转位置编码（RoPE）驱动：移除 RoPE 后，键的 seed-IoU 跌至 0.01–0.05（浅层）甚至与值无异（深层），分割性能也低于输出特征。
- **方法效果**：
  - 在无先验条件下，TokenGraph3D（enc4 key）在 SemanticKITTI、nuScenes、Waymo 上分别达到 0.726、0.517、0.646 Sassoc，而输出特征基线只有 0.486、0.273、0.455（提升 +0.24、+0.24、+0.19）。
  - 无先验版本已在 SemanticKITTI 上超过所有已发表无监督方法（0.726 vs UNIT 0.715），在 nuScenes 上也明显领先（0.517 vs 0.390），并追平 Waymo 上密度聚类水平。
  - 然而，一旦加入近邻门控（几何先验），表示之间的差距被“吸收”，key 和 Feat 几乎打平（如 nuScenes 0.546 vs 0.547），且与 DBSCAN 相当——这说明“无先验”条件正是让涌现实例结构可见的必要环境。

## 7. 优点

- **分析先行、定位清晰**：系统地探测了 query/key/value 在不同深度上的表现，指出了信号载体（RoPE 后的键）和网络深度分布（双峰），为后续方法设计提供了可靠依据。
- **完全免训练、免先验**：所有模块均冻结自监督模型，用连通分量直接分组，不使用密度阈值、聚类算法、运动线索或 2D 投影，真正实现了“零几何先验”的实例分割。
- **跨传感器鲁棒性**：在 64 线、32 线和 Waymo 64 线三种不同 LiDAR 配置上使用同一组超参数，展示了良好的迁移性。
- **公平的对比设计**：与 DBSCAN/HDBSCAN 共享相同的地面门控，只改变分组机制；统一调参协议降低了过拟合单数据集的风险。
- **写作清晰、表格丰富**：用表 1–4 清楚展示先验有无、特征来源、几何门控等关键变量的影响，结论可复现性强。

## 8. 不足与局限

- **骨干唯一性**：所有实证来自单个自监督 Transformer（Utonia），未验证其他点 Transformer 或体积 Transformer 是否具有类似涌现现象，结论可能受架构和预训练数据影响。
- **并非完全无标签调参**：余弦阈值 τ 和特征选择（enc4 key）依赖有标注的 250 扫描子集，严格来说引入了一定程度的人工/标注信息；论文也承认“无标签选择规则”仍是开放问题。
- **尺度分析的混淆**：用点在物体上的数量近似物体大小，但 LiDAR 点密度随距离下降，导致“尺寸”和“稀疏度”相互混淆；精确区分需要物体面积标注。
- **无先验模式的失败案例**：没有近邻门控时，极易过分割大物体（如浅层 key 导致高簇数），也容易通过特征相似链把远距离同类物体错误合并；近邻门控虽能补救，却削弱了“无先验”的优势。
- **数据集局限性**：Waymo 缺乏逐点实例标注，实验只能基于 3D 框派生的标签，质量比手动全景标签粗糙，可能高估或低估真实分割性能。
