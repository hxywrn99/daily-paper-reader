## 摘要
在3D高斯泼溅（3DGS）中进行开放词汇指称分割需要神经模型根据自由形式的语言表达式选择高斯原语。现有基于3DGS的方法通常依赖全局文本-区域相似性，这在涉及属性、参考对象、空间关系和细粒度部件的查询中表现较弱，常导致目标-参考混淆、粒度不匹配、部分-整体泄漏和关系违反。我们提出QAGaussian，一种用于语言引导的高斯原语选择的查询自适应神经推理框架。QAGaussian首先学习查询条件的多尺度高斯槽作为可微分候选，其感受野由输入表达式塑造；然后构建具有语言条件边权重的关系感知槽图，以传播目标-参考、属性、部分-整体和上下文证据；粒度自适应路由器软性结合区域级、对象级、部件级、属性感知和关系感知掩码分支，随后进行关系约束细化以保证空间、部分-整体、属性和几何一致性。QAGaussian仅在Mosaic3D-5.6M上预训练以进行高斯-文本对齐，并在独立基准上评估，无需目标数据集微调。它实现了47.2的平均mIoU和63.2的平均F1，比最强的3DGS指称基线高出2.7个mIoU点和2.9个F1点；还将Part-mIoU从38.6提高到43.4，Rel-mIoU从44.4提高到50.8，并将目标-参考混淆从10.8降低到7.4。这些结果表明，查询条件槽学习、关系感知图推理和自适应路由为3DGS中的开放词汇指称分割提供了有效的神经建模策略。代码可在https://github.com/zqeslwyz/QAGaussian获取。

## Abstract
Open-vocabulary referring segmentation in 3D Gaussian Splatting (3DGS) requires a neural model to select Gaussian primitives according to free-form language expressions. Existing 3DGS-based methods usually rely on global text-region similarity, which is weak for queries involving attributes, reference objects, spatial relations, and fine-grained parts. This often causes target-reference confusion, granularity mismatch, part-whole leakage, and relation violations. We propose QAGaussian, a query-adaptive neural reasoning framework for language-guided Gaussian primitive selection. QAGaussian first learns query-conditioned multi-scale Gaussian slots as differentiable candidates whose receptive fields are shaped by the input expression. It then builds a relation-aware slot graph with language-conditioned edge weighting to propagate target-reference, attribute, part-whole, and contextual evidence. A granularity-adaptive router softly combines region-level, object-level, part-level, attribute-aware, and relation-aware mask branches, followed by relation-constrained refinement for spatial, part-whole, attribute, and geometric consistency. QAGaussian is pretrained only on Mosaic3D-5.6M for Gaussian-text alignment and evaluated on independent benchmarks without target-dataset fine-tuning. It achieves 47.2 Avg. mIoU and 63.2 Avg. F1, outperforming the strongest 3DGS referring baseline by 2.7 mIoU points and 2.9 F1 points. It also improves Part-mIoU from 38.6 to 43.4, Rel-mIoU from 44.4 to 50.8, and reduces target-reference confusion from 10.8 to 7.4. These results demonstrate that query-conditioned slot learning, relation-aware graph reasoning, and adaptive routing provide an effective neural modeling strategy for open-vocabulary referring segmentation in 3DGS. The code is available at https://github.com/zqeslwyz/QAGaussian.

### 1. 核心问题与整体含义（研究动机和背景）

- **研究背景**：3D高斯泼溅（3DGS）作为一种显式原语级场景表示，近年来被广泛应用于语言引导的3D场景理解。开放词汇指称分割要求模型根据自由形式的自然语言表达式（如"显示器左边的红色杯子"、"水壶的把手"、"靠近墙的木凳"），在3DGS场景中准确选择对应的Gaussian原语集合。
- **现有方法的核心缺陷**：现有3DGS分割方法大多将语言表达式压缩为一个全局文本嵌入，然后通过文本-区域相似性匹配选择目标区域。这种策略对简单类别名有效，但无法处理包含属性、参照对象、空间关系、部分-整体结构的复杂查询，具体表现为四类可观测的失败模式：
  1. **目标-参照混淆**（target-reference confusion）：目标对象与语句中提到的参照对象同时被激活；
  2. **粒度不匹配**（granularity mismatch）：查询要求部件或属性约束子集，模型却预测整个对象或过大的区域；
  3. **部分-整体泄漏**（part-whole leakage）：预测的部件掩码溢出到其父对象之外，尤其影响PartNet等细粒度部件基准；
  4. **关系违反**（relation violation）：预测掩码在语义上合理但与查询中的空间关系不一致。
- **核心论点**：Gaussian级指称分割应被建模为**查询条件下的神经推理**（query-conditioned neural reasoning over primitives），而非静态相似性匹配。语言表达式本身应参与候选形成、关系建模和粒度决策的整个过程。

### 2. 提出的方法论

#### 2.1 总体框架
QAGaussian将任务形式化为查询条件下的原始语选择：给定Gaussian场景 $G = \{g_i\}_{i=1}^N$ 和表达式 $Q$，预测概率掩码 $M \in [0,1]^N$。框架遵循两条设计原则：所有中间表示保持在Gaussian或slot级别以支持任意视角渲染；直到最终输出阶段才做硬决策，整个流程可端到端训练。

#### 2.2 查询条件层次槽生成（Query-Conditioned Hierarchical Slot Generation）
- **结构查询提取**：轻量解析器将表达式分解为结构化语义线索 $Z_Q = \{z_{tar}, z_{attr}, z_{rel}, z_{ref}, z_{part}\}$，分别对应目标、属性、关系、参照和部件信息。解析器不提供查询类型标签，只提供软语义线索用于条件化后续模块。
- **多尺度槽生成**：将Gaussian原语池化为三个尺度的token（细/中/粗），以可学习的槽查询加上全局查询上下文 $Q^s_c = Q^s_0 + MLP_s(z_Q)$ 为条件，通过槽注意力（Slot Attention）生成多尺度槽 $S^s = SlotAttn_s(Q^s_c, H^s_V)$。
- **槽的语义**：每个槽表示一个软的Gaussian候选，大小可对应部件、完整实例或上下文区域，取决于查询。每个槽预测Gaussian分配矩阵 $A_{j,i}$ 和活跃度分数 $o_j$，低活跃度槽允许模型在不同复杂度的场景中使用固定槽预算。

#### 2.3 关系感知图推理与自适应路由（Relation-Aware Graph Reasoning and Adaptive Routing）
- **关系感知槽图**：在活跃槽上构建轻量图，边描述子编码相对位置、重叠、包含关系、尺度比和特征相似性。边权重由语言条件调制：
  $$a_{ij} = \sigma(MLP_{rel}([r_{ij}, z_{rel}]))$$
  这使得相同的空间配置在不同关系词（如"next to"、"beneath"、"in front of"）下获得不同的解释。
- **图编码器**：图编码器 $H_Q = GEnc(S, E_Q, Z_Q)$ 传播结构先验，目标类槽从参照类和上下文类槽接收信息，与查询关系不一致的干扰槽被抑制。图是查询特定的，同一场景在不同表达下产生不同的有效边。
- **粒度自适应路由器**：路由器在五个分支上预测软权重 $\pi_b$：区域级、对象级、部件级、属性感知和关系感知分支。每个分支估计槽的贡献 $p^b_j = \sigma(MLP_b([h^Q_j, z_Q, o_j]))$。
- **初始掩码组装**：$M_0 = \sum_b \pi_b \left(\sum_j p^b_j A_j\right)$，将"查询要求什么"（路由权重）与"目标如何分割"（分支级槽聚合）分离。

#### 2.4 关系约束细化与学习目标
- **细化阶段**：初始掩码 $M_0$ 可能包含零散高斯或违反查询关系的候选，通过四个轻量一致性先验进行细化：空间关系一致性、部分-整体一致性、属性兼容性、Gaussian几何连续性，形成细化损失 $L_{ref}$。
- **训练目标**：完整目标为 $L = \sum_{u \in \Omega} \beta_u L_u$，其中 $\Omega = \{slot, route, seg, align, ref\}$。槽级学习采用匈牙利匹配将预测槽与GT高斯掩码对齐；路由器使用由表达式结构和掩码几何导出的软伪标签进行训练，允许组合查询同时利用多个推理模式。
- **推理**：最终离散掩码由阈值化 $\hat{M} = I(M_{final} > \tau)$ 得到，阈值和所有超参数在预训练后固定，跨基准共享。

- **语言鲁棒性**：在各类查询扰动下性能保持率优于ReferSplat，尤其在组合重写和干扰丰富表达上优势显著。

### 7. 优点

- **方法设计的创新性**：将指称分割从"相似性匹配"提升为"结构化推理"，查询条件槽（query-conditioned slot）让语言参与候选形成本身，而非在固定候选集上做匹配。
- **粒度自适应的显式建模**：通过多尺度槽和自适应路由器，模型可动态调整分割粒度以匹配查询需求，首次系统性地处理了对象级、属性级、部件级、关系级和组合式查询的统一建模。

- **诊断性实验设计**：不仅报告整体指标，还针对失败模式设计了细粒度诊断指标（TR-conf、Part-mIoU、Rel-mIoU），直接验证了设计的四个动机（解决四类失败模式）。

### 8. 不足与局限

- **对重建质量的依赖**：方法性能高度依赖3DGS场景重建质量。在遮挡、透明物体、反射表面或视图不足导致的噪声/不完整/不准确的Gaussian表示下，预测掩码会退化。
- **极细粒度目标的挑战**：非常小的部件和薄结构仍具挑战性，需要同时具备高质量几何和细粒度语义对齐。
- **复杂关系推理的边界**：高度复杂的多跳表达式、模糊指代以及"between"、"inside"、"aligned with"等关系仍可能困难。
- **计算开销**：相比直接相似性匹配方法更慢且更耗内存（中等场景查询时间0.82s vs ReferSplat的0.66s，内存9.8GB vs 9.1GB）。对于对延迟敏感的应用可能构成瓶颈。
- **算力门槛**：使用8张2080Ti即可训练，算力要求相对友好，但未报告总训练时长，读者难以精确评估训练成本。
- **对象中心基准上的相对劣势**：在ScanRefer和ReferIt3D等偏简单对象级查询的基准上略低于ReferSplat，说明框架的复杂度优势主要体现在复杂查询上，简单查询场景中结构化推理的相对收益不明显。
- **预训练数据依赖**：虽然零样本评估表现好，但性能仍依赖Mosaic3D-5.6M的预训练质量，对大规模高斯-语言对齐数据的可得性有依赖。
