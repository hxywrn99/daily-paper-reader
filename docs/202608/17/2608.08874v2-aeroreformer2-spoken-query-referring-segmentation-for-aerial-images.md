## 摘要
口语语言为在密集的遥感图像中指定任意目标提供了一种自然、免提的接口，然而现有的遥感图像引用分割基准只接受书面表达。为了填补这一空白，我们引入了\dataset，一个源自RISBench的口语查询基准，它在保留原始图像、掩码和数据划分的同时，添加了重音和语音多样化的语音。其困难评估集结合了旋翼、风力和混合干扰，并设置了三个信噪比水平。我们还提出了\model，一种高效的双边网络，结合了边界保持视觉路径、令牌保持语音编码、核线性跨模态注意力和分辨率细化头。该设计在两种尺度上调整视觉特征，无需实现密集的语音-视觉亲和矩阵，然后利用高分辨率视觉特征恢复精细边界。在干净测试集上，使用Swin-Base的\model实现了62.09%的平均交并比（mIoU）和68.22%的整体交并比（oIoU），分别比最强的音频自适应遥感基线高出5.38和2.08个百分点。它保持了54.09%的最佳困难集mIoU。据我们所知，这是对遥感图像进行完整句子口语查询引用分割的首个基准和模型研究。代码将公开提供。

## Abstract
Spoken language offers a natural, hands-free interface for specifying an arbitrary target in dense remote-sensing imagery, yet existing referring remote-sensing image segmentation benchmarks accept only written expressions. To bridge this gap, we introduce \dataset, a spoken-query benchmark derived from RISBench that adds accent- and voice-diverse speech while preserving the original image, mask, and data splits. Its hard evaluation sets combine rotor, wind, and mixed interference with three signal-to-noise levels. We also propose \model, an efficient bilateral network that combines a boundary-preserving visual path with token-preserving speech encoding, kernel linear cross-modal attention, and a resolution refinement head. The design conditions visual features at two scales without materializing a dense speech--visual affinity matrix, then restores fine boundaries using high-resolution visual features. On the clean test split, \model with Swin-Base achieves 62.09\% mean intersection over union (mIoU) and 68.22\% overall intersection over union (oIoU), outperforming the strongest audio-adapted remote-sensing baseline by 5.38 and 2.08 percentage points, respectively. It retains the best hard-set mIoU at 54.09\%. To the best of our knowledge, this is the first benchmark and model study of full-sentence spoken-query referring segmentation for remote-sensing imagery. The code will be made publicly available.

## 2. 方法论：AeroReformer2

### 2.1 总体架构
模型由三条路径组成：
- **上下文路径（Context Path）**：ResNet-101 或 Swin-Base 骨干，输出 1/4、1/8、1/16、1/32 多层特征。
- **细节路径（Detail Path）**：浅层卷积网络，在 1/8 分辨率保留边界信息。
- **语音路径（Speech Path）**：冻结的 wav2vec 2.0 提取语音 token 序列 \(A \in \mathbb{R}^{T \times D_a}\)，保留 token 级信息而非池化为单个句向量。

### 2.2 置信度门控令牌记忆（CGTM）
- 每个语音 token 通过 LN + SiLU + 线性层预测一个置信度标量：

\[
g_t = \sigma(W_2\, \text{SiLU}(W_1\, \text{LN}(a_t))), \quad g_t \in [0,1]
\]

- 有效权重为 \(w_t = m_t g_t\)（\(m_t\) 为 padding mask），权重同时作用于跨模态注意力统计量和全局 FiLM 条件分支。
- 该置信度是**学习得到的 token 效用度量**，不是校准概率，也无需 token 级标注。

### 2.3 语音-视觉核线性注意力（SV-KLA）
- 使用 ELU 特征映射 \(\phi(x) = \text{ELU}(x) + 1\)，将 query/key 映射到正空间。
- 先聚合语音端的充分统计量：

\[
S = \sum_{t=1}^{T} w_t k_t u_t^\top \in \mathbb{R}^{d \times d}, \quad z = \sum_{t=1}^{T} w_t k_t \in \mathbb{R}^{d}
\]

- 再对每个视觉 query 做关联归一化：

\[
y_i = \frac{q_i^\top S}{q_i^\top z + \epsilon}
\]

- 计算等价于 \(\phi(Q)(\phi(K)^\top U)\)，**从不实例化 \(N \times T\) 的亲和矩阵**。
- 复杂度：\(O((N+T)d^2)\) 计算量、\(O((N+T)d + d^2)\) 存储量，远优于标准 softmax 注意力的 \(O(NTd)\) 计算量和 \(O(NT)\) 存储量。

### 2.4 双尺度特征路由
- **1/16 尺度 SV-KLA**：粗粒度语义定位。
- **1/8 尺度 SV-KLA**：细粒度关系定位（将粗结果上采样后加到 1/8 上下文特征上）。
- 融合细节路径后，经过**残差视觉核注意力（VKA）**进行全局精修。
- 最后通过 **1/4 高分辨率细化头**（融合 top-down 上下文、上采样融合特征和独立细节路径）恢复精细边界，该阶段**不进行跨模态注意力**以避免在 1/4 网格上的高开销。

### 2.5 损失函数
\[
\mathcal{L} = \mathcal{L}_{\text{BCE}} + \left(1 - \frac{2\sum_p \sigma(\hat{m}_p) m_p + 1}{\sum_p \sigma(\hat{m}_p) + \sum_p m_p + 1}\right)
\]

即二元交叉熵 + soft Dice 损失。

## 3. 实验设计

### 3.1 数据集与基准：VoiceAeroRef
- **来源**：RISBench（源自 DOTA-v2 + DIOR，512×512 图像），原始 52,472 个三元组，剔除 6 个仅含标点符号的无效训练表达式后得到 **52,466 个可用三元组**。
- **划分**：
  - Train：26,294 个源样本 × 8 种口音-性别语音 = 210,352 条音频（每 epoch 每个源随机采 1 条）。
  - Validation：10,013 个样本 × 1 条语音（类别平衡分配）。
  - Test：16,159 个样本 × 1 条干净语音。
- **8 个 TTS 语音**：4 口音（美式/英式/澳式/印度）× 2 性别（女/男），均为 16 kHz 单声道 PCM WAV。
- **硬测试集**：仅针对测试集，将干净语音与旋翼噪声、风噪声、0.6/0.4 混合噪声交叉，含低/中/高三种严重程度（标称 SNR 15/7.5/0 dB，扰动 ±1.5 dB），共 **9 个条件**，每个测试单元 1,795–1,796 个样本。

### 3.2 对比方法
- **经典分割架构**：Audio U-Net、Audio FCN-ResNet101、Audio DeepLabV3-ResNet101（均使用池化音频 FiLM 条件化）。
- **RRSIS 模型音频适配版**：FIANet、SBANet、STDNet、LSCF（将文本 token 替换为 wav2vec 2.0 token，保留各模型的对齐/融合机制）。
- **自对比**：AeroReformer2-ResNet101（骨干控制）+ AeroReformer2-Swin-B。

### 3.3 训练设置
- 输入分辨率 352×352，音频长度上限 8 秒，wav2vec 2.0 base 冻结。
- 40 epochs，AdamW，batch size 8，weight decay 1e-4，余弦退火，AMP，梯度裁剪 1.0。
- 新初始化的音频融合和 decoder 参数学习率 2e-4；Swin-Base 预训练骨干单独以 2e-5 优化。
- 测试时 512×512 分辨率，概率阈值 0.5。

### 3.4 指标
- mIoU、oIoU、Pr@τ（τ ∈ {0.5, 0.6, 0.7, 0.8, 0.9}）。

## 6. 主要结论与发现

### 6.1 干净测试集
- **AeroReformer2-Swin-B 在所有指标上排名第一**：mIoU 62.09%、oIoU 68.22%、Pr@0.5 69.25%、Pr@0.9 27.49%。
- 对比最强非本文方法 LSCF adapter：mIoU 提升 **5.38 个百分点**（56.71% → 62.09%），oIoU 提升 2.08 个百分点。
- 对比 ResNet-101 版本：Swin-B 骨干额外带来 2.83 mIoU 提升。
- 对比 DeepLabV3-R101 和 U-Net：分别高出 10.22 和 34.25 mIoU 点，证明**池化级条件化不足以支撑实例级语音引用分割**。

### 6.2 硬测试集
- AeroReformer2-Swin-B 保持第一：mIoU **54.09%**，比 LSCF 高出 **5.63 个百分点**，比最强非本文 oIoU（SBANet）高 1.86 个百分点。
- 与干净集相比下降 8.00 mIoU 点，**声学干扰仍是实质性限制**。
- 在全部 9 个噪声条件单元格中均排名第一，高严重度（0 dB）下仍保持 3.70–5.02 点的优势。

### 6.3 消融发现
- **后融合视觉核注意力（VKA）是最关键的组件**，去掉后 mIoU 下降 4.50 点。
- 1/32 视觉 KLA 去掉后下降 1.01 mIoU 点。
- 置信度门控在整体 mIoU 上仅贡献 0.27 点，但在 Pr@0.9 上贡献 1.29 点，说明**它主要提升严格重叠率下的性能**。

### 6.4 效率发现
- AeroReformer2-Swin-B 在 5 个 Swin-Base 方法中**参数最少、峰值内存最低**。
- 对比 LSCF：快 10.9%、峰值内存低 13.7%、mIoU 高 5.38 点。
- SV-KLA 在 352×352 下将跨模态亲和状态减少 **1,890.62 倍**，注意力核心 MAC 降低 **37.58 倍**（512 分辨率下分别为 4,000 倍和 43.24 倍）。

### 6.5 定性发现
- 在处理"部分可见目标"、"微小目标"、"方向性短语（如 far left side）"等场景时，AeroReformer2 优势明显；对比方法往往分割出显著但不正确的目标。

## 7. 优点

### 数据/基准层面
- **首个**遥感图像全句口语查询引用分割基准，填补领域空白。
- 保留原始图像-掩码-划分不变，使文本与语音结果可直接对比，这是该基准的核心贡献。
- 训练集 8 种口音-性别语音的"每 epoch 采 1 条"采样策略，既实现说话人增强又不人为放大视觉样本权重（避免八倍过采样）。
- 硬测试集的设计（9 条件网格）提供了对声学鲁棒性的细粒度测量，同时保持每个源样本只出现一次（不膨胀评估量）。
- 含噪声级别的语音条件没有改变视觉/语言任务本身，且不使用外部噪声录音，可复现性好。

### 方法/架构层面
- SV-KLA 在数学上避免了稠密亲和矩阵，同时保留了 token 级语音信息（不将整句池化成单一向量），特别适合高分辨率遥感图像+长音频的场景。
- 双尺度跨模态融合分离了"粗定位"和"细接地"两个任务，路由逻辑清晰。
- 置信度门控与 FiLM 分支结合，使不同语音 token 的任务相关性可被学习，且无需额外标注。

## 8. 局限性

### 8.1 数据层面的局限
- **语音全部由 TTS 合成**，并非真实人类说话音频。TTS 在韵律、连读、情感、咳嗽/呼吸声、非母语口音等多方面与真实口语存在系统性偏差，因此 VoiceAeroRef 上的性能可能无法完全代表真实语音交互场景的表现。
- **噪声是人工合成的加性噪声**，只有旋翼噪声和风噪声，且未模拟混响、麦克风频响失真、多说话人重叠、信道压缩等实际部署中的声学变化，噪声鲁棒性结论的生态效度有限。
- **仅覆盖英语语音**。8 个 TTS 说话人虽然包含四种口音，但仍局限于英语；wav2vec 2.0 对其他语种（如中文、印地语、阿拉伯语）的迁移能力未做验证。
- **硬测试集每个源样本只对应 1 条语音**，虽有利于统计独立性，但也意味着同一图像无法考察多条语音带来的掩码稳定性；不同语音下对同一目标的引用一致性未被评估。

### 8.2 模型与评估层面的局限
- **消融实验不完整**，尤其缺少：
  - 对 1/4 高分辨率细化头的单独消融；
  - 双尺度 SV-KLA 中只保留 1/16 或只保留 1/8 的对比；
  - 硬测试集下置信度门控（CGTM）的独立消融，因此无法直接证明“置信度门控在噪声下抑制无关 token”这一设计动机。
- **缺乏跨数据集验证**。模型未在 RefSegRS、RRSIS-D 等文本基准的语音版本上（或直接迁移到文本任务上）测试，泛化性只靠单一基准支撑。
- **没有与文本查询结果直接对比**，尽管数据划分允许“图像-掩码-划分不变”下文本与语音的对比，但论文未给出如文本 RISBench 的 SOTA mIoU，无法量化“文本-语音性能差距”具体有多大。
- **没有真实用户交互实验**，未报告语音查询在无人机操控等实际使用场景中的任务完成率、用户满意度和交互延迟。
- **效率评估只报告单 GPU 推理**，没有训练成本、显存峰值随 batch 增长趋势、端侧（嵌入式/移动设备）部署数据，也没有报告吞吐量在噪声测试时的表现。

### 8.3 可复现性局限
- **训练算力信息缺失**：未说明训练所用 GPU 型号、卡数、总时长、总 FLOPs，给预算有限的复现者带来不确定性。
- wav2vec 2.0 采用冻结特征，虽然简化了训练，但为了适应新口音/新噪声需要替换整个前端；如何联合微调语音编码器与分割网络也未做讨论。

## 9. 总结与展望

### 9.1 总体评价
AeroReformer2 在“任务定义—基准构建—高效模型—系统评估”四个方面形成了闭环：它提出了一个合理且可复现的语音引用分割基准，并针对高分辨率遥感图像与长语音序列的融合设计了一套不实例化密集亲和矩阵的高效方案，在干净和噪声条件下都显著超过现有适配模型。作为该方向的第一个系统性工作，其贡献主要体现在**方法论上的启发性和基准的公共价值**，而非单纯刷高分数。

### 9.2 对后续研究的启示
- **数据侧**：可在此基础上扩展真实语音录制、多语言 TTS、真实旋翼噪声/机载音频采集；也可以尝试利用扩散/TTS 做更多样化的“伪真实”语音增强。
- **模型侧**：SV-KLA 的思路可以推广到其他长序列跨模态任务（视频-语言、音频-点云等）；“置信度门控”可继续探索为显式的词级/音素级监督或不确定性估计。
- **评估侧**：未来应补充文本-语音性能差距分析、跨数据集迁移测试、以及面向真实无人机交互的端到端评估。

总体而言，该论文作为语音驱动的遥感图像引用分割的起步性工作，值得被后续研究者作为基线和方法参考；其基准与高效注意力机制是有价值的公共贡献，但真实场景语音鲁棒性仍需更贴近实际的数据和更完整的消融来验证。
