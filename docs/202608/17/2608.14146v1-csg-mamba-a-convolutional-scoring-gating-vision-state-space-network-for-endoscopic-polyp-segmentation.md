## 摘要
精确的息肉分割对于计算机辅助结肠镜检查至关重要，然而内镜图像通常包含低对比度边界、黏膜纹理干扰、镜面高光以及设备相关的外观差异。视觉状态空间模型（SSM）以线性复杂度提供高效的长程建模能力，但现有的Vision Mamba分割模型通常将2D特征转换为1D扫描序列，这可能会削弱局部几何连续性并对不规则轮廓过度平滑。我们提出了CSG-Mamba，一种用于内镜息肉分割的卷积评分门控视觉状态空间网络。CSG-Mamba构建于VM-UNet风格的非对称U形编码器-解码器之上，在语义丰富的瓶颈处插入卷积评分门控（CSG）模块。CSG通过逐点和大核深度卷积生成局部空间评分图，并通过乘法门控重新校准状态空间特征。使用三个随机种子的实验表明，CSG-Mamba在Kvasir-SEG上达到0.9220 Dice和15.87 HD95，在CVC-ColonDB上达到0.7418 Dice和0.6570 mIoU，在大多数重叠和召回指标上优于基线，同时保持有竞争力的边界精度。

## Abstract
Accurate polyp segmentation is critical for computer-aided colonoscopy, yet endoscopic images often contain low-contrast boundaries, mucosal texture interference, specular highlights, and device-dependent appearance shifts. Vision State Space Models (SSMs) provide efficient long-range modeling with linear complexity, but existing Vision Mamba segmentation models typically convert 2D features into 1D scanning sequences, which may weaken local geometric continuity and over-smooth irregular contours. We propose CSG-Mamba, a convolutional scoring gating Vision State Space network for endoscopic polyp segmentation. Built on a VM-UNet-style asymmetric U-shaped encoder-decoder, CSG-Mamba inserts a Convolutional Scoring Gating (CSG) module at the semantically rich bottleneck. CSG generates a local spatial score map through pointwise and large-kernel depthwise convolutions and recalibrates state-space features by multiplicative gating. Experiments with three random seeds show that CSG-Mamba achieves 0.9220 Dice and 15.87 HD95 on Kvasir-SEG, and 0.7418 Dice and 0.6570 mIoU on CVC-ColonDB, outperforming the baselines on most overlap and recall metrics while maintaining competitive boundary accuracy.

## 1. 核心问题与研究动机

**背景**：息肉分割是计算机辅助结肠镜检查的基础任务。真实内镜图像面临多重挑战：

- **低对比度边界**：息肉与周围黏膜组织灰度接近，边界难以区分
- **黏膜纹理干扰**：肠道黏膜的纹理特征可能与息肉外观混淆
- **镜面高光与运动模糊**：内镜成像的固有噪声
- **跨设备外观差异**：不同医院、不同厂商的内镜设备采集的图像存在域偏移

**核心问题**：现有 Vision Mamba（视觉状态空间模型）分割方法存在关键缺陷——它们通过 SS2D 机制将 2D 特征图展开为 1D 扫描序列进行全局建模，这种序列化转换会破坏像素间的局部邻接关系，导致：

- 局部几何连续性被削弱
- 不规则轮廓被过度平滑
- 边界预测位移和欠分割

**研究目标**：在不显著增加参数和推理开销的前提下，为 Vision Mamba 补充局部卷积先验，提升息肉分割的边界质量和跨域泛化能力。

## 2. 方法论

### 2.1 总体架构

CSG-Mamba 采用 **VM-UNet 风格的非对称 U 形编码器-解码器**结构：

- **输入**：256×256×3 图像 → Patch Embedding（4×4 步长 4 卷积）→ 64×64×C 特征图
- **编码器**：4 个阶段，通道数为 96/192/384/768，深度为 [2,2,2,2]，通过 Patch Merging 降分辨率升通道
- **关键创新**：在语义最丰富的**瓶颈处**插入 CSG 模块（橙色虚线框内）
- **解码器**：深度 [2,2,2,1]，通过 Patch Expanding 恢复分辨率，含跳跃连接
- **最终投影**：4× 上采样得到分割掩码

### 2.2 VSS Block 与 SS2D 机制

**状态空间模型基础**：
- 连续形式：dh(t)/dt = Ah(t) + Bx(t), y(t) = Ch(t)
- 离散化后：hₖ = Āhₖ₋₁ + B̄xₖ, yₖ = Chₖ
- Mamba 引入输入依赖的选择性机制，使参数随输入内容动态调整

**SS2D 的操作**：
SS2D(F) = Merge(S→(F), S←(F), S↓(F), S↑(F))

即沿四个方向（左→右、右→左、上→下、下→上）将 2D 特征展开为 1D 序列分别扫描，再合并。作者指出，如图 3 所示，**原本相邻的边界像素在展开后可能被分离**，造成局部连续性损失——这是论文要解决的核心问题。

### 2.3 CSG 模块（核心贡献）

**设计动机**：瓶颈处语义信息最集中、空间分辨率最低（16×16），插入轻量卷积模块的计算开销最小，但对全局特征的调节作用最大。

**计算流程**：

1. **通道混合**：1×1 逐点卷积（无偏置），进行通道间信息融合
2. **局部上下文提取**：7×7 大核深度卷积（无偏置），扩大局部感受野（比 3×3 感受野更大，但计算量极低）
3. **归一化与激活**：BatchNorm + Sigmoid，生成空间评分图
4. **乘法门控**：将评分图与原始瓶颈特征逐元素相乘

**核心公式**：
- G = σ(BN(DWConv₇ₓ₇(PWConv₁ₓ₁(F))))
- Fout = F ⊙ G

**设计选择**：相比加法残差融合，乘法门控能**显式抑制不可靠的背景响应**，同时保留局部显著的边界或病变特征。

### 2.4 训练策略（零推理成本稳定化协议）

为公平比较 Mamba 类方法，所有模型统一采用以下训练策略：

- **联合损失函数**：Lseg = L_BCE + L_Dice
- **深度监督（Deep Supervision）**：在 16×16 和 32×32 解码器输出处附加辅助头，总损失 Ltotal = Lseg(Ŷ₀) + 0.5·Lseg(Ŷ₁) + 0.25·Lseg(Ŷ₂)，辅助头仅训练时使用，推理时移除
- **EMA（指数移动平均）**：衰减系数 0.999，推理时使用 EMA 权重
- **DropPath**：概率 0.3

这些策略**只影响优化过程，不增加任何推理开销**，因此称为"零推理成本"。

## 6. 主要结论与发现

### 6.1 域内性能（Kvasir-SEG）

CSG-Mamba 在**所有 5 项指标上均取得最优**：

- mIoU 0.8677、Dice 0.9220、HD95 15.87、Accuracy 0.9817、Sensitivity 0.9301
- 相比 VM-UNet：Dice 提升 0.0042，HD95 降低 2.38 像素
- 相比 TransUNet：参数量仅为其约 1/3，Dice 反而更高

### 6.2 零样本跨域（CVC-ClinicDB）

- 最佳 mIoU（0.7765）、Dice（0.8493）和 Sensitivity（0.8614）
- 相比 VM-UNet：mIoU +0.0076、Dice +0.0056、Sensitivity +0.0125
- HD95（25.62）略高于 VM-UNet（24.72），Accuracy 两者几乎持平

### 6.3 零样本跨域（CVC-ColonDB，更具挑战性）

- 最佳 mIoU（0.6570）、Dice（0.7418）、Accuracy（0.9676）和 Sensitivity（0.7519）
- 相比 VM-UNet：Dice 提升 0.0133，是跨域增益最明显的场景
- 相比 VM-UNetV2：HD95 降低 14.70 像素，Dice 提升 0.0205

### 6.4 消融结论

- **机制消融**：7×7 大核提供更宽的局部上下文；乘法门控优于加法融合，尤其在跨域场景下能避免放大域特定纹理
- **位置消融**：瓶颈处插入效果最均衡。编码器只插、解码器只插或全部插入都会在某个数据集上显著退化，且增加参数

### 6.5 核心发现

> **Vision State Space 模型需要与局部归纳偏置协同工作**，不能仅依赖序列化状态空间扫描。卷积评分门控以极低的参数开销，有效补偿了 SS2D 序列化造成的 2D 连续性损失，且对低对比度边界和跨域场景更鲁棒。

## 7. 优点

1. **问题定位精准**：明确指出 Vision Mamba 的 1D 序列化与 2D 分割任务之间的本质矛盾，通过图示（图 3）直观地展示了相邻像素在展开后被分离的问题

2. **方法设计简洁高效**：
   - CSG 模块仅由 1×1 点卷积 + 7×7 深度卷积 + BN + Sigmoid 组成，无注意力矩阵，计算开销极低
   - 参数增加仅 4.87M（27.43M → 32.30M），相比其带来的性能提升性价比很高
   - 乘法门控的设计具有明确的可解释性：抑制背景、保留局部显著特征

3. **实验公平性保障到位**：
   - 对 Mamba 类方法统一使用相同的训练协议（深度监督、EMA、DropPath），这是很多论文容易忽视的比较公平性问题
   - VM-UNet 被精确定位为"去掉 CSG 的严格消融对照"，使得性能差异可直接归因于 CSG 模块
   - 三个随机种子实验显著增强了结果的可信度

4. **消融设计科学**：2×2 因子设计将大核卷积和门控机制两个因素分别解耦验证，位置消融确认了瓶颈放置的合理性，结论有据可依

5. **零推理成本**：深度监督和 EMA 只影响训练，推理时无任何额外开销，实际部署友好

6. **代码开源**：提供了 GitHub 仓库，有利于复现和后续研究

4. **计算资源信息缺失**：未报告 GPU 型号、数量、单次训练时长等算力信息，不利于复现和横向效率比较

   - 数据集仅 3 个，且训练集仅来自 Kvasir-SEG（单中心数据）
   - 未在真实临床视频流、多种内镜设备、不同采集协议的大规模多中心数据上验证
   - 未讨论模型在实时检测场景中的推理速度（FPS）

7. **性能提升幅度有限**：相比强基线 VM-UNetV2，域内 Dice 提升仅 0.004（0.9180 → 0.9220），虽然边界指标 HD95 改善明显，但重叠指标的增益较小，CSG 的贡献主要体现在边界定位精度上，而非整体区域重叠

8. **消融实验缺少对辅助头单独贡献的量化**：论文提到深度监督、EMA 对训练稳定性有帮助，但没有单独消融这些组件，无法量化 CSG 与训练策略各自的贡献比例

---

## 总结一句话

CSG-Mamba 通过一个极轻量的大核卷积评分门控模块，在瓶颈处为 Vision Mamba 的全局状态空间建模补充了局部边界先验，在不显著增加参数的前提下，有效解决了 2D 到 1D 序列化导致的边界过度平滑问题，在息肉分割的域内精度和跨域泛化方面均取得了优于现有 Mamba 类方法的性能，但跨域边界精度仅部分占优，且缺乏算力信息和显著性检验是其报告上的明显短板。
