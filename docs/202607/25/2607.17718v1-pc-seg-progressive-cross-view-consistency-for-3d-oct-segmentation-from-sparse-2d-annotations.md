## 摘要
光学相干断层扫描（OCT）图像的体积分割对于诊断眼病至关重要，但需要耗费大量人力进行体素级标注。虽然半监督学习（SSL）可以降低标注成本，但大多数现有方法逐切片处理数据，未能利用固有的三维空间上下文。我们提出PC-Seg，一种渐进式跨视图一致性框架，可从稀疏二维标注中学习高精度三维分割模型。与传统的多视图方法不同，PC-Seg使用单个二维模型从标准B扫描和正交切片学习跨视图一致性，从而生成可靠的体积伪标签。这些伪标签随后被蒸馏到三维模型中，随后进入协同训练阶段，其中二维和三维模型通过集成伪标签相互优化。在MSHC和Duke DME数据集上的实验表明，PC-Seg在使用训练数据仅约0.7%的标注时即可达到与全监督学习相当的精度，优于最先进的半监督和视网膜层分割方法。我们的代码公开在https://github.com/gsisaoki/pc-seg-official。

## Abstract
Volumetric segmentation of optical coherence tomography (OCT) images is essential for diagnosing ocular diseases but requires labor-intensive voxel-wise annotations. While semi-supervised learning (SSL) can reduce annotation costs, most existing methods process data slice by slice and fail to exploit the inherent 3D spatial context. We propose PC-Seg, a progressive cross-view consistency framework that learns high-accuracy 3D segmentation models from sparse 2D annotations. Unlike conventional multi-view approaches, PC-Seg uses a single 2D model to learn cross-view consistency from standard B-scans and orthogonal slices, thereby generating reliable volumetric pseudo-labels. These pseudo-labels are then distilled into a 3D model, followed by a co-training stage in which the 2D and 3D models mutually refine each other through ensemble pseudo-labeling. Experiments on the MSHC and Duke DME datasets demonstrate that PC-Seg achieves accuracy comparable to fully supervised learning while using labels for only about 0.7% of the training data, outperforming state-of-the-art semi-supervised and retinal layer segmentation methods. Our code is publicly available at https://github.com/gsisaoki/pc-seg-official.

### 方法论：核心思想与关键技术细节

- **核心思想**：提出**PC-Seg（Progressive Cross-view Segmentation）** 框架，通过五阶段课程学习策略，逐步从稀疏2D标注提升至3D分割模型。利用单个2D模型学习标准B扫描（B-scan）与正交切片（Orthogonal slice）之间的跨视图一致性，生成可靠的3D伪标签，再蒸馏至3D模型，最后通过2D/3D协同训练相互优化。
- **关键技术细节**：
  1. **基线SSL框架**：采用UniMatch（弱到强一致性正则化），对未标注图像生成高置信度伪标签，计算弱-强扰动间的一致性损失。
  2. **五阶段流程**：
     - **Stage 1 (2D Warm-up)**：用稀疏标注和未标注B扫描训练2D模型，生成初始B扫描伪标签。
     - **Stage 2 (Adaptation to Orthogonal Slices)**：引入正交切片，利用Stage 1生成的伪标签训练，使2D模型适应正交视图。
     - **Stage 3 (Orthogonal Cross-teaching)**：在B扫描和正交切片之间进行交叉教学，互相生成伪标签，提升空间一致性。
     - **Stage 4 (Knowledge Distillation to 3D Model)**：将Stage 3生成的2D集成预测作为伪标签，训练3D模型（3D ResUNet）。
     - **Stage 5 (2D/3D Co-training)**：交替训练2D和3D模型，动态集成二者预测生成更新的伪标签，实现联合优化。
  3. **动态阈值调整**：在Stage 4/5中，对于病变类（如积液）降低置信度阈值至0.5，以增强学习效果。
  4. **模型架构**：均采用ResUNet（2D和3D版本，depth=4, base_channels=32），参数效率高。

### 主要结论与发现

- 在MSHC数据集上，PC-Seg仅用60张标注图像（约0.7%）即达到F-score 0.9174，与全监督方法（0.9193）几乎持平，显著优于所有半监督基线。
- 在Duke DME数据集上，PC-Seg在Fluid类上取得0.742 F-score，远超其他方法（0.3~0.6），表明3D上下文对复杂病理结构分割至关重要。
- 逐阶段消融显示，五阶段渐进式课程学习有效缓解了伪标签误差累积，正交切片和跨视图一致性是提升性能的关键。

### 优点

- **创新方法论**：提出基于课程学习的渐进式跨视图一致性框架，巧妙利用2D模型先学习平面内一致性，再扩展至正交视图和3D，避免了直接训练3D模型带来的计算开销和过拟合风险。
- **极高数据效率**：仅需约0.7%标注即可接近全监督性能，大幅降低标注成本。
- **鲁棒伪标签机制**：动态更新伪标签、集成预测、自适应阈值调整，有效抑制误差累积。
- **模型无关性**：框架可适配不同2D/3D骨干网络（本文使用ResUNet），具有一定通用性。
