## 摘要
可控红外与可见光图像融合旨在通过灵活的区域感知调制整合互补的热信息和结构信息，生成适应多样化用户需求和下游任务的融合图像。然而，现有方法通常依赖预定义的离散控制条件，导致稀疏空间无法支持细粒度调制需求。为此，我们提出ConFusion，一种新颖的框架，通过高斯条件的空间感知调制学习连续融合空间，实现实例级别的细粒度可控红外与可见光图像融合。ConFusion采用双分支架构，在联合重建和文本引导的语义对齐下解耦模态不变和模态特定表示。高斯条件的实例调制变量结合基于Grounded SAM的实例掩码，通过掩码引导的特定特征调制器指导实例级细粒度调制，而文本驱动的不变特征增强器提升语义一致性并增强融合。在推理阶段，多模态大语言模型将用户意图解析为实例级调制变量以引导图像融合。大量实验表明，ConFusion在融合质量和下游任务的多个指标上均达到最先进性能，同时支持细粒度可控图像融合。我们的代码可在https://github.com/HeyufeiAnto/Confusion获取。

## Abstract
Controllable infrared-visible image fusion aims to integrate complementary thermal and structural information with flexible region-aware modulation, producing fused images that adapt to diverse user requirements and downstream tasks. However, existing methods typically rely on predefined discrete control conditions, leading to a sparse space that fails to support fine-grained modulation demands. To address this, we propose ConFusion, a novel framework that learns the continuous fusion space via Gaussian-conditioned spatial-aware modulation, enabling instance-level fine-grained controllable infrared and visible image fusion. ConFusion employs a dual-branch architecture to disentangle modality-invariant and modality-specific representations under joint reconstruction and text-guided semantic alignment. Gaussian-conditioned instance modulation variables coupled with Grounded SAM-based instance masks guide instance-level fine-grained modulation through the Mask-Guided Specific Feature Modulator, while the Text-Driven Invariant Feature Enhancer improves semantic consistency and enhances fusion. During inference, the multimodal large language model parses user intents into instance-level modulation variables to guide image fusion. Extensive experiments show that ConFusion achieves state-of-the-art performance across multiple metrics in both fusion quality and downstream tasks, while supporting fine-grained controllable image fusion. Our code is available at https://github.com/HeyufeiAnto/Confusion

- **问题**：现有可控红外-可见光图像融合方法通常依赖**预定义的离散控制条件**（如固定文本/视觉提示），导致控制空间稀疏，无法支持**细粒度、实例级别的调制需求**。例如，对同一目标（如行人）输入语义相近但细微不同的文本（“高热量” vs “极高热量”），离散方法会产生几乎相同的融合结果。
- **动机**：用户需求多样（如热成像强调程度、多实例独立控制），需要**连续、可调的控制空间**来实现实例级精细调控，同时融合质量不下降。
- **意义**：首次提出**连续融合空间学习**，通过高斯条件空间感知调制，使融合模型能够根据用户意图实现实例级别的细粒度控制，增强了灵活性、适应性和下游任务性能。

## 2. 方法论
### 核心思想
- 学习一个**连续的融合空间**，用户意图（由大语言模型解析）映射为**实例-强度对**，通过调制实例特征实现细粒度控制。
- 采用**双分支架构**解耦**模态不变特征**（共享语义）与**模态特定特征**（红外热辐射、可见光纹理），并引入**文本引导的语义对齐**强化解耦。

### 关键技术细节
1. **训练阶段一：解耦表示学习**
   - 共享低层编码器提取浅层特征，然后通过双分支（特定编码器+不变编码器）分离 `F_sp` 和 `F_inv`。
   - 重建分支：自重建 + 交叉重建（交换不变特征）保证解耦。
   - **不变语义对齐**：利用Grounded SAM生成实例掩码，CLIP文本编码器提供文本嵌入，通过掩码平均池化提取视觉特征并与文本对齐（余弦相似度损失），使不变特征获取模态无关语义。
   - 解耦损失：最小化不变特征与特定特征的互协方差（Frobenius范数），促进独立性。

2. **训练阶段二：特征调制与增强融合**
   - **Mask-Guided Specific Feature Modulator (MGSM)**：对每个实例采样高斯变量 α_j ~ N(0.5,0.22)（截断），结合Grounded SAM掩码构建**空间感知调制掩码** M。通过卷积层将M映射为缩放/偏移参数，分别调制红外和可见光的特定特征（红外用M，可见光用1-M）。
   - **Text-Driven Invariant Feature Enhancer (TDIE)**：将融合后的不变特征与CLIP文本嵌入进行交叉注意力，增强语义一致性。
   - 损失函数：ROI约束损失（强制在实例区域保留红外强度、在互补区域保留可见光） + 背景重建损失（保持背景均衡）。

3. **推理阶段**
   - 用户输入自然语言，LLM解析为**实例-强度对**和实例文本 → Grounded SAM生成实例掩码 → CLIP编码文本 → 构建调制掩码 M 和文本嵌入 → 经融合网络生成最终图像。

### 公式/算法流程（文字说明）
- 实例级调制变量 `α_j` 从高斯分布采样 → 与掩码组合成 `M` → 对红外特定特征 `F_sp_ir` 进行仿射变换：`F_hat_sp_ir = f_ω * LN(F_sp_ir) + f_β`，其中 `(f_ω, f_β) = Conv(M)`；可见光类似但采用 `1-M`。
- 调制后的特征与不变特征经Restormer融合，再经TDIE增强，最后解码器重建融合图像。
